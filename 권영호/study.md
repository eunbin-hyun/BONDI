## 흐름

```text
08-26~28  점군 복원 파이프라인 (유물 한 점을 끝까지)
             ↓  "이 자료들을 팀이 어떻게 쓰지?"
08-31~09-04  1부 자료 서버 계획   — 결정 AS-01~09, artifact→variant→file
             2부 서버 설치 구성   — Nginx·systemd, 조용히 깨지는 설정
             3부 데이터 정리      — 142건 신원 확정, originals/restored/aihub
             4부 Unreal MCP      — 계산 결과를 OBJ로 만들어 에셋으로 임포트
             ↓  "설계한 것을 실제로 띄우고, 팀이 쓰게 하면?"
09-07~09-11  1부 배포            — nginx:80 + FastAPI(systemd), 수용시험 9/10
             2부 자동 배포        — Jenkins, 경로 제한과 권한 3겹 분리
             3부 쓰면서 드러난 것 — 즐겨찾기(팀 공용), 누운 유물 148건, 화면 개편
             4부 등록·삭제        — 원본·복원본 업로드, 휴지통 삭제
             5부 원인 추적        — libEGL, HTTP 캐시, ID 재사용, 밝기 실측
             ↓  "이 서버에 올릴 것을 내가 만들면?"
09-14~09-18  1부 화면 결함        — 전역 가시성 규칙, 시각 KST, 최신 등록순
             2부 8GB 진입         — 활성값 조각 연산 7,350 → 3,276 MiB
             3부 ERS 양방향 ★     — 투창 창 2→10, 697 → 473초
             4부 멀티 복원본      — variant 슬러그, 스키마 변경 없이
             5부 방향 고정        — 163건 전수 대조, 끊긴 장치를 이었다
             6부 채움 질감        — 원본 결의 통계로 합성 (표준편차 일치)
             7부 한계             — 얇은 판·저부조는 64³ 아래 (측정)
```

설계(08-31~09-04)와 운영(09-07~09-11)은 다른 기술이었다.
앞은 "무엇을 만들까", 뒤는 **"왜 안 보이지"** 였다.

그리고 09-14~09-18 은 **"내가 왜 틀리지"** 였다.
오진 네 번이 전부 같은 형태였다 — 그럴듯한 설명을 먼저 세우고 그걸 고치려 했다.
넷 다 실제로 재 보고서야 원인이 나왔다.

09-21~09-28 은 **"내가 맞다고 한 것이 맞나"** 였다.
"색 데이터가 없다"(있었다) · "인덱스로 나누면 명품이다"(형태로 다시) ·
"바로 섰나 물으면 답한다"(비교 선택으로 바꿔야 답했다) —
셋 다 검증을 통과시키는 과정에서 결론이 아니라 **설계가** 바뀌었다.
