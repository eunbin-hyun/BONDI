# 2026-08-26 학습 정리 — LAS 문화유산 점군 복원 파이프라인 설계

- 작성자: 권영호
- 학습 주제: 원형 토기편 LAS 점군의 결손 형상과 변색을 비학습 방식으로 복원하는 파이프라인 설계
- 대상 데이터: `RR_07_01_EA_028.las`
- 핵심 기술: LAS 파싱, 통계적 이상치 제거, 회전 대칭축 추정, 원통 좌표 전개, 결손 영역 분리

## 1. 프로젝트 목표

문화유산 3D 스캔 데이터의 원본 좌표를 보존하면서 파손된 형상과 변색된 색상을 복원하고, 결과를 VR·3D 뷰어에서 사용할 수 있는 형식으로 내보내는 것을 목표로 했다.

복원 결과와 원본이 섞여 출처를 알 수 없게 되는 문제를 막기 위해 다음 원칙을 세웠다.

- 원본 포인트 좌표는 수정하지 않는다.
- 새로 생성한 점과 색을 보정한 점을 별도 classification으로 기록한다.
- 유물의 의도적인 입구와 실제 파손부를 구분한다.
- 학습 데이터가 없는 상태이므로 우선 회전 대칭 기반 Track A를 구현한다.

## 2. 입력 데이터 분석

| 항목 | 값 |
|---|---:|
| LAS 버전 | 1.4 |
| Point format | 7 (RGB 포함) |
| 원본 점 수 | 179,294 |
| 경계 상자 | 약 0.646 × 0.624 × 0.352 m |
| RGB 저장 방식 | 16-bit |

형태를 확인한 결과 위쪽 중앙의 원형 구멍은 규칙적인 토기 입구이고, 아래쪽의 불규칙한 경계는 파손된 절단면으로 판단했다. 따라서 두 영역을 무조건 닫는 방식이 아니라 측면 결손만 선택적으로 채우도록 설계했다.

## 3. 파이프라인 설계

```text
01 전처리
→ 02 결손·변색 탐지
→ 03 대칭 기반 형상 완성
→ 04 색 복원
→ 05 LAS·PLY·GLB·OBJ 재조립
→ 06 가상 절단 정량 평가
```

### 3.1 원본 추적용 분류 코드

| classification | 의미 |
|---:|---|
| 0 | 보존된 원본 포인트 |
| 20 | 새로 합성한 결손 채움 포인트 |
| 21 | 색상을 보정한 원본 포인트 |

### 3.2 결손 탐지 방식

회전축을 기준으로 점군을 `(r, θ, h)` 원통 좌표로 변환하고, `θ-h` 격자에 펼쳐 점이 없는 내부 셀을 결손 후보로 탐지한다. 토기 입구와 하단 절단면은 격자 도메인 밖으로 처리해 보존한다.

## 4. 오늘의 결론

점군 복원에서는 단순히 모든 구멍을 닫는 것보다 **의도된 개구부와 파손부를 구분하는 과정**이 중요했다. 또한 문화유산 데이터에서는 복원 결과보다 원본과 생성 영역을 명확히 구분하는 것이 우선이라는 기준을 세웠다.

## 5. 다음 행동

1. 이상치 제거와 법선 계산을 구현한다.
2. 회전 대칭축과 원통 전개 격자를 시각화한다.
3. 측면 결손과 변색 영역을 탐지한다.
4. 결과를 단계별 중간 파일로 저장해 재실행 가능하게 만든다.
