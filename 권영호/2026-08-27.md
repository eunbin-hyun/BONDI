# 2026-08-27 학습 정리 — 회전 대칭 기반 토기 결손·색상 복원 구현

- 작성자: 권영호
- 학습 주제: 원형 토기편의 측면 결손 탐지, 형상 채움, LAB 기반 색상 복원
- 대상 데이터: `RR_07_01_EA_028.las`
- 핵심 기술: Open3D SOR, 원통 전개 격자, Fourier 반경장, kNN 색 전파

## 1. 전처리 결과

통계적 이상치 제거와 법선 추정 후 회전 대칭축을 계산했다.

| 원본 점 수 | 179,294 |
| 정제 후 점 수 | 175,371 |
| 제거한 이상치 | 3,923 |
| 평균 점 간격 중앙값 | 2.69 mm |
| 추정 축의 Z축 기울기 | 1.40° |
| 반지름 중앙값 | 약 0.275 m |

## 2. 결손 탐지

`θ-h` 점유 격자에서 관측 도메인 내부의 빈 셀을 찾고 작은 노이즈 성분을 제거했다. 상단 중앙 입구와 하단 절단면은 의도적으로 채우지 않았다.

- 측면 결손 셀: 1,372개
- 추정 결손 면적: 약 0.05656 m²
- 상단 고리 결손 셀: 0개

## 3. 형상 복원

높이별 반경을 단순 평균하지 않고, 각 높이 행에서 저차 Fourier 모델로 `R(θ,h)` 반경장을 추정했다. 주변 건전면의 실제 미세 요철을 donor texture로 다시 샘플링해 합성 영역이 지나치게 매끈해지지 않도록 했다.

- 신규 합성 포인트: 15,047개
- 합성 방식: 측면 원통 차트 15,047개
- 건전면 요철 표준편차: 1.830 mm
- 복원면 요철 표준편차: 1.576 mm

![원본과 합성 포인트 분류 결과](./images/2026-08-27-fill-points.png)

> 회색은 원본, 초록색은 새로 합성한 포인트다. 큰 측면 결손을 채우면서 상단 입구와 하단 파단 경계는 유지했다.

## 4. 색상 복원

RGB를 CIELAB로 변환한 뒤 주변 건전 포인트를 donor로 사용했다. 변색 영역은 원래 명도 구조를 유지하면서 건강한 표면의 색상 성분을 전파했고, 신규 포인트에도 주변 색 분포를 반영했다.

- 색 보정 포인트: 8,912개
- 신규 포인트 착색: 15,047개
- LAB 왕복 변환 최대 오차: 0
- 신규점과 최근접 건전점의 색 차이 중앙값: ΔE 5.775

![복원 실행 전후 비교](./images/2026-08-27-before-after.png)

> 실행 전후 점군 비교 화면이다. 측면의 큰 결손 영역에 합성 포인트가 추가되고 주변 형상과 연결되는 것을 확인했다.

## 5. 한계와 개선점

- 실제 결손부에는 정답 형상이 없으므로 결과가 역사적으로 유일한 정답이라고 볼 수 없다.
- 회전 대칭 가정이 강한 유물에 적합하며 비대칭 유물에는 별도 방식이 필요하다.
- 색 복원은 주변 건강한 색이 충분히 남아 있어야 안정적으로 동작한다.

## 6. 다음 행동

3. 건전한 부위를 가상으로 제거한 뒤 복원해 정량 평가한다.
