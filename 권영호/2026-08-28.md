# 2026-08-28 학습 정리 — 복원 결과 재조립·OBJ 출력 및 정량 평가

- 작성자: 권영호
- 학습 주제: 복원 점군의 LAS·PLY·GLB·OBJ 출력과 가상 절단 기반 성능 평가
- 대상 데이터: `RR_07_01_EA_028.las`
- 핵심 기술: LAS classification, Poisson mesh, OBJ vertex color, Chamfer Distance, F-score, CIEDE2000

## 1. 최종 재조립

정제된 원본 포인트, 색 보정 포인트, 신규 합성 포인트를 순서대로 병합했다. 원본 좌표가 변하지 않았는지 LAS를 다시 읽어 검증했다.

| 분류 | 점 수 |
|---|---:|
| 원본 classification 0 | 166,459 |
| 신규 채움 classification 20 | 15,047 |
| 색 보정 classification 21 | 8,912 |
| 전체 | 190,418 |

- LAS 좌표 왕복 최대 오차: `5e-7 m`
- RGB 왕복 최대 오차: 0
- 최종 LAS 크기: 약 6.47 MB

## 2. 3D 메시와 OBJ 출력

병합 점군의 법선을 바깥 방향으로 정렬하고 screened Poisson 방식으로 메시를 생성했다. 밀도가 낮거나 원본 점군에서 멀리 떨어진 정점을 제거해 토기 입구와 하단 파단면이 불필요하게 막히는 현상을 줄였다.

| 항목 | 결과 |
|---|---:|
| 메시 정점 | 521,761 |
| 메시 삼각형 | 1,040,905 |
| Poisson depth | 9 |
| OBJ 크기 | 약 62.4 MB |

출력 형식:

- `05_RR_07_01_EA_028_restored.las`
- `05_restored_points.ply`
- `05_restored_mesh.ply`
- `05_restored_mesh.glb`
- `05_restored_mesh.obj`

OBJ에는 정점별 RGB 값을 함께 기록했다. 다시 로드해 정점 521,761개와 면 1,040,905개가 유지되는지 검증했다.

## 3. 형상 복원 정량 평가

정답이 없는 실제 결손 대신, 건전한 측면 세 영역을 가상으로 제거한 뒤 같은 파이프라인으로 복원했다. 제거 전 원본을 GT로 사용해 Chamfer Distance와 F-score를 계산했다.

| 지표 | 제안 방식 | 단순 반경 중앙값 baseline |
|---|---:|---:|
| 평균 sqrt-Chamfer | 2.2597 mm | 3.2160 mm |
| F-score @ 9.58 mm | 1.0000 | 1.0000 |
| F-score @ 5.00 mm | 0.9986 | 0.9886 |
| F-score @ 2.50 mm | 0.9384 | 0.6705 |

세 평가 영역 모두 결손 셀 탐지율 100%를 기록했다. 특히 엄격한 2.5 mm 기준에서 단순 baseline보다 높은 형상 일치도를 보였다.

## 4. 색상 복원 평가

건전한 색상 패치 두 곳을 가리고 주변 색만 이용해 복원한 뒤 원래 색과 CIEDE2000으로 비교했다.

- 평가 포인트: 4,881개
- 평균 ΔE00: 2.5823
- 중앙값 ΔE00: 2.1738
- 95백분위 ΔE00: 5.9312
- CIEDE2000 공식 기준값 7쌍 자체 테스트 통과

## 5. 결론

비학습 회전 대칭 방식만으로도 원형 토기편의 측면 결손을 약 2.26 mm 수준으로 복원했고, 단순 반경 채움보다 안정적인 결과를 얻었다. 원본과 복원 영역을 classification으로 분리해 결과의 추적 가능성도 확보했다.

다만 이 결과는 관측된 주변 형상에서 얻은 **복원 가설**이다. 실제 문화유산 전시에서는 원본과 생성 영역을 구분해 보여주고 전문가 검토 결과를 함께 기록해야 한다.
