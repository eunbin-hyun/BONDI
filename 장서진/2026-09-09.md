한 줄 결론: **"conserved = 밝기 보존"이라는 v1 설계는 틀렸다.** 부식 얼룩은 밝기에 있고, 보존할 것은 밝기 전체가 아니라 *형상 음영과 무늬*다. v1.4는 그 둘을 각각 포락선 탈색과 구조 일관성으로 분리한다.

## 1. 왜 v1.1이 PoC보다 나빠 보였나

| PoC `refinish()` | v1.0~1.1 | 결과 |
| --- | --- | --- |
| 색도 이행 강도 0.85 고정 | 손상도 d = ΔE/30 가중만 | 목표에서 ΔE 5~10인 크림색 백자 텍셀은 d 0.2~0.3이라 거의 안 움직임 → "안 바뀐 것처럼" |
| 명도 재정규화 0.8 (평균 → 재질 L, 대비 gain ≤ 1) | 설계에서 "L 보존"으로 삭제 | 금동의 부식 얼룩 명암이 그대로 |
| 색 편차를 25 %로 압축 | 100 % 유지 | 초록·갈색 반점 잔존 |

PoC 그림이 더 하얗게 보인 데에는 **렌더 차이**도 있었다(PoC는 광택 있는 조명 렌더, 내 뷰어는 텍스처 원색). 뷰어에 "조명·재질 반영"을 넣어 같은 조건으로 비교하게 했다.

## 2. 금동 좌상 duk003312로 튜닝한 과정 (뷰어에 8버전 보존)

| 버전 | 설정 | ΔE 후 | 판정 |
| --- | --- | --- | --- |
| v1.1 | 암부 보호 all, 톤·탈색 없음 | 18.3 | 얼룩덜룩. 어두운 부식 34 %가 "장식"으로 보호됨 |
| 보호 끔 | — | 26.1 | 명암 얼룩 그대로 |
| pristine | 밝기 분포 매핑 | — | 건전부 0.2 %라 분포가 없어 평평한 겨자색. **건전부 3 % 미만이면 pristine 생성 안 함**으로 결정 |
| 탈색 0.85 | 포락선 리프트 | 25.8 | 얼룩 대부분 사라짐, 음영 유지, 어두움 |
| 톤 0.8 + 탈색 | | 8.2 | 밝지만 음영까지 눌려 평면적 |
| **v1.3** 톤 0.3 + 탈색 0.85 + 채도 0.85 + 편차 25 % | | 8.0 | 균형 좋음. 색 반점·잔여 얼룩 약간 |
| **v1.4** 탈색 1.0(창 1024) + 편차 10 %·(1 − d) + 무늬 노멀맵 | | **2.7** | 앞면 얼룩 없음 |

**탈색(destain)**: L을 1/8로 줄여 창 안 90 백분위(=주변 건전 표면 밝기) 포락선을 구하고, 손상 텍셀(d ≥ 0.5면 전부)을 그 높이로 올린다. PoC의 전역 톤은 얼룩을 못 없애서 새로 넣은 단계. 부작용: 어두운 텍셀에 금색 채도를 주면 sRGB 밖으로 나가 갈색 진흙이 됨 → `C ≤ 1.15·L` 채도 스케일.

## 4. v1.4 회귀 (PoC 자산 11건, 손상부 ΔE 목표까지 후)

| | v1.1 | v1.3 | v1.4 |
| --- | --- | --- | --- |
| 도자기 6건 | 2.8~7.3 | 0.6~1.7 | **0.6~1.4** |
| 금속 5건 | 10~18 | 1.8~8.0 | **0.7~4.2** |

목표색은 도자기 6건·금·금동 관모가 PoC와 Δ ≤ 1.3으로 일치. 금동 2건·청동 1건은 PoC가 녹청을 섞은 경우라 프리셋 유지(Δ 10~27). L-SSIM은 금속에서 0.5~0.8로 떨어지는데 얼룩 제거량이라 완료 기준에서 제외.

**배운 것.**

- 검수는 수치보다 뷰어가 빨랐다. ΔE는 v1.1에서도 "개선"이었지만 얼룩·무늬·상감은 숫자에 안 잡혔다. 육안 검수 항목(무늬 유지, 상감 유지, 얼룩, 마모부 색)을 완료 조건에 넣어야 한다.
- 텍스처 색만으로 못 가르는 것 세 가지가 확인됐다: 부식 반점 vs 무늬(→ 주파수 방향성), 마모 vs 그림(→ 메시 곡률), 접합선 vs 문양선(→ 메시 홈). 셋 다 **3D라서 쓸 수 있는 정보**로 풀었고, 그래도 남는 것(접합선 검출 누락, 상감 임계)은 세그멘테이션(설계 8절 A)이 맞다.
- 실수 기록: `git checkout -- file`로 미커밋 수정을 한 번 날려 다시 썼다. 배치가 1시간 멈춘 건 노트북 절전이었다(CPU 누적 148초).
