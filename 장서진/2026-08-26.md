# 260826 작업 정리 — 장서진

담당: AI · VR

## 1. 기획 조사
- 유물 3D 스캔 데이터셋(LAS 1.4, XYZ+RGB, CSV/JSON 메타) 구조·품질 조사
  - 대표 유물 기준 약 148만 포인트, 점 간격 0.82mm. 결손부는 "점이 없는 영역"으로 나타남
- VR 전시 후보 유물 9선 선정 (승탑·석등·조형물·토기류), PoC 대상으로 소형 석등(RR_07_01_PA_033) 확정

## 2. 결손 복원 기술 검증 (PoC)

### 시도 1: 딥러닝 완성 모델 PoinTr → 부적합
- ShapeNet-55 사전학습 PoinTr 추론 파이프라인 구축 (CUDA C++ 확장 없이 순수 PyTorch로 대체 실행)
- 실측 결과 복원 실패. 원인: ① 유물 형상 prior 부재(도메인 불일치) ② 출력 8,192점으로 해상도 부족 ③ 침식형 결손을 결손으로 인식 못 함
- 딥러닝 적용은 유물 데이터 파인튜닝이 전제 → 보류

### 시도 2: 기하 알고리즘 기반 대칭 복원 → 성공
- 전통 복원의 "온전한 대응 부위 참조" 원리를 알고리즘으로 구현 (딥러닝 미사용)
- 파이프라인 (`restore_window.py`):
  1. PCA로 대칭축 검출 → 육각 석등 60° 회전 대칭 확인
  2. 점유 격자(6mm)로 관통 결손 자동 검출 — 임계 30mm는 온전면/파손면 깊이 분포 실측으로 도출, 격자 장식 구멍은 성분 크기로 제외
  3. 회전 사본을 ICP로 정합 후 결손 셀에만 온전한 면의 점(좌표+색상) 이식
  4. DBSCAN + 이상치 제거, 복원점은 classification 12로 분리 (원본 무손상)
- 결과: 원본 1,488,637점 + 복원 53,410점. 창살 전체가 소실된 면에 격자 창살 복원 완료 (`diag_final.png` 전후 비교)
- 교훈: 수제 석조물은 대칭 오차 ~7mm라 거리 기반 판정은 고스트 발생 → **"표면과의 거리"가 아니라 "그 위치에 표면이 존재하는가(점유)"로 판정**해야 함

## 3. 학습 계획 (AI · VR)
- Open3D 심화 (ICP 정합, 법선 추정, DBSCAN) / Poisson Surface Reconstruction (포인트클라우드 → 메쉬)
- 복원 파이프라인 일반화: 대칭각 자동 탐지, 비대칭 유물(토기류) 대응
- Unreal: LiDAR Point Cloud 플러그인(LAS 직접 로드) vs 메쉬 변환(Nanite) 비교, VR 유물 관찰 인터랙션·성능(LOD)
