## 3. 의성 고운사 — 채택

숭례문과 같은 구조의 사건이 2025년에 반복됐고, 이쪽은 **데이터가 실제로 있다.**

- 2025년 3월 의성·안동 산불로 **보호구역·역사문화환경 보존지역 내 전체 49동 중 26동 전소.** 보물 **연수전**(2020.08.31. 지정)과 가운루가 함께 탔다.
- 보물 **석조여래좌상**(1963.01.21. 지정)은 공식 판정이 **「대좌 소실(불신, 광배는 이운조치)」.** 불신·광배는 2025.03.27. 국립경주문화유산연구소로 이운됐다.

> **오후에 조사로 위 두 줄을 고쳤다.** 처음엔 언론 보도만 보고 "30동 중 21동 전소", "석조여래좌상은 당일 오전 안동 이송으로 무사"라고 적었는데, 국가유산청 「2025년 제4차 건축문화유산분과 회의자료」의 건물별 피해 판정표가 동수·이운일·기관·대좌 상태를 모두 다르게 기록한다. 지정번호 표기(제2078호·제246호)도 2021년 제도 폐지 이후 공식 문서에서 쓰지 않는다. 상세는 [2026-09-11_고운사-화재후-자료조사.md](2026-09-11_고운사-화재후-자료조사.md) §0.
- 산불 피해 국가유산 33건 중 **3D 기록화가 돼 있던 것은 5건.**
- 국가유산청이 그 원형 3D를 「재해유산 3D / 기억유산」 glTF 뷰어(`digital.khs.go.kr/recommend/gltfViewer.do`)로 **로그인 없이 공개** 중. 총 11건 686 MB.

### 3.1 받아서 검증

`media/gltf/` 경로로 직접 서빙된다. Blender 5.2 Workbench로 렌더까지 확인. 둘 다 실측 스케일(m)의 포토그래메트리다.

| 항목 | 연수전 | 석조여래좌상 |
| --- | --- | --- |
| 파일 | 65.6 MB | 39.4 MB (`TR246_3.glb` — 파일명은 구 지정번호 표기) |
| 삼각형 | 690,610 | 300,000 |
| 정점 | 2,071,830 | 899,904 |
| 텍스처 | 8192² JPEG 18.2 MB | 8192² JPEG 8.5 MB |
| 실측 치수 | 18.43 × 24.11 m, 높이 8.82 | 1.55 × 1.55 m, 높이 2.05 |
| 생성 | Agisoft Metashape | Blender glTF I/O |
| 노멀 | **없음** (POSITION+UV만) | 있음 |
| 머티리얼 | baseColor 1장뿐, 노멀·러프니스 없음 | 같음 |

연수전은 건물만이 아니라 **문간채·돌담·마당 포장·계단·식생까지** 18.4 × 24.1 m 범위로 들어 있다. 야외 공간이 통째로 스캔돼 있어서 지면을 새로 만들 필요가 없다.

> 대안으로 본 사남고택(86.8 MB, 699,999 tri)도 전소라 토글이 성립하고 품질도 대등하지만, 스캔에 **에어컨 실외기와 빨간 플라스틱 잔해**가 찍혀 있어 연수전을 골랐다. 이후 대상을 연수전·석조여래좌상 둘로 고정.

### 3.2 텍셀 밀도 — 관람 거리 한계

UV 면적과 3D 표면적을 실제로 적분해서 계산.

| | 연수전 | 석조여래좌상 |
| --- | --- | --- |
| 메시 표면적 | 1,417.7 m² | 5.9 m² |
| UV 점유율 | 43.8 % | 68.4 % |
| **텍셀 밀도** | 144 texel/m → **6.9 mm/texel** | 2,799 texel/m → **0.4 mm/texel** |
| 삼각형 밀도 | 487 tri/m² (평균 변 4.5 cm) | 51,175 tri/m² (평균 변 0.4 cm) |

20 PPD급 헤드셋이면 픽셀 하나가 거리 *d*에서 `d × 0.000873 m`를 덮는다. 텍셀 6.9 mm와 맞아떨어지는 거리가 **약 8 m**.

| 거리 | 판정 |
| --- | --- |
| 8 m 이상 | 헤드셋이 텍스처보다 거칠어 차이가 안 보인다. 마당에서 전체를 보는 거리 |
| 2~3 m | 픽셀 1.7 mm vs 텍셀 6.9 mm → **텍스처가 4배 흐리다.** 기둥 앞에서 단청을 보면 뭉개짐 |

**결론: 둘러보는 전시로는 충분, 들여다보는 연출은 부적합.** 동선을 건물 2 m 이내로 끌지 않으면 된다. 석조여래좌상은 0.4 mm라 좌대 전시물로 과분한 품질.

## 4. 공공누리 유형 추적

서비스 전체는 공공누리 기반이지만 **유형이 자료마다 다르고**, 우리 계획은 유형에 따라 성립 여부가 갈린다.

| 유형 | 조건 | 우리 계획에 | 이유 |
| --- | --- | --- | --- |
| 제1유형 | 출처표시 | **가능** | 수정·재배포 허용 |
| 제2유형 | 출처표시 + 비상업 | **가능** | 비영리 교육이라 해당 |
| 제3·4유형 | + **변경금지** | **불가** | 감축·LOD·포맷 변환이 막힘. 무엇보다 **목조부 제거가 필수**라 변형 없이는 계획 자체가 성립 안 함 |

### 4.1 카탈로그는 유형을 표기한다

3D 데이터 카탈로그(`record/record3D.do`)에 **28,722건**이 있고 상세 페이지에 유형이 찍힌다. 무작위 **표본 17건 전부 제1유형(출처표시)**. 다른 유형은 한 건도 안 나왔다.

예: `국가민속문화유산_청송_송소_고택.zip` — 614.7 MB, obj, **20,002,903 폴리곤**, 2022, 공공누리 제1유형.

### 4.2 그런데 우리 대상 2건은 미등재

| 경로 | 고운사 연수전 / 석조여래좌상 |
| --- | --- |
| 3D 데이터 카탈로그 | **0건** (같은 지역 `의성`은 45건 — 탑리리 오층석탑·만취당 등) |
| 국가유산별 카탈로그 | **0건** — 유산 항목 자체가 없음 |
| 매체유형별 | **0건** |

사업 이력에는 있다. 둘 다 **의성군청 발주**이고 **공개 파일 0건**.

- 「고운사 석조여래좌상 정밀실측 용역」 2019
- 「고운사 연수전, 대곡사 범종루 정밀실측용역」 2022

즉 **기억유산 뷰어가 유일한 공개 경로이고 그 화면에 유형 표기가 없다.** 상세 페이지가 없으니 이용 신청 버튼도 없다. → 메일 문의가 유일한 경로.

### 4.3 절차

로그인은 SNS 또는 간편인증 + **휴대폰 본인확인**이 필요해 대리 진행 불가. 이용신청은 목적 심사 후 검토 1~2일, 승인 후 2주 내 다운로드. 대용량은 이메일 발송 또는 외장하드 택배·방문 수령.

신청서 목적 예시에 이게 명시돼 있어 승인 가능성은 높다고 본다.

## 5. 메시 분할 실험 — 소실 상태 만들기

토글의 "현재(소실)"는 공개 3D가 없어 직접 만들어야 한다. 다만 **기단·초석·담장·마당·지면이 원형 스캔에 이미 들어 있어서, 목조부만 덜어내면 된다.** 없는 것을 새로 만드는 작업이 아니다.

### 5.1 구조 분석 — 자동 분리가 왜 안 되는가

| 확인한 것 | 값 | 의미 |
| --- | --- | --- |
| 용접(1 mm) 후 정점 | 351,693 | |
| 연결 덩어리 | 585개, **최대 1개가 563,088 tri = 81.5%** / 1,360 m² | 건물·지면·담장이 한 덩어리. `Select Linked` 무용 |
| 수평면 면적이 몰린 높이 | −3.37 / −2.87 / −2.77 / −1.67 / −1.27 / **+1.43** m | **경사지 계단식 터.** 전역 절단 평면이 존재하지 않는다 |

### 5.2 색 기반 — 실패

처음엔 덩어리별 평균색을 봤는데 덩어리 하나가 81.5%라 무의미했다. **삼각형 단위로 다시** 측정(삼각형당 4점 UV 샘플 → HSV). 색 신호는 분명히 있었다.

| 분류 | hue | 면적 | 비율 |
| --- | --- | --- | --- |
| 청 — 기와 | 160~260° | 470.6 m² | 33.2 % |
| 주황 — 목재 | 20~45° | 117.7 m² | 8.3 % |
| 녹 — 단청·식생 | 70~160° | 131.1 m² | 9.2 % |
| 적 — 단청 | 0~20° | 37.6 m² | 2.7 % |
| 무채색 — 석재·지면 | sat < 0.15 | 571.9 m² | 40.4 % |

분류기(`기와 | 목재 | 단청`)를 만들어 갈랐더니 목조 추정 349,829 tri / 722.3 m²(50.9%). **렌더해보니 지붕이 통째로 남고 구멍만 뚫린 스위스 치즈.** 원인 두 가지:

1. **기와와 석재가 둘 다 청회색**이라 hue가 겹친다.
2. **색이 삼각형 단위로 튄다.** 포토그래메트리라 그림자·이끼·풍화가 섞여서 같은 지붕면인데 인접 삼각형이 다른 클래스로 갈린다. 공간 평활화 없이 임계값만 걸면 무조건 이렇게 된다.

### 5.3 지면 대비 높이 — 성공

0.5 m 격자로 셀별 Y 5퍼센타일을 지면 고도로 잡고(빈 셀은 근접 전파 30회), 그 위 높이로 자름. **경사지라 전역 평면은 안 되지만 지면 대비로는 지형이 알아서 처리된다.**

| 지면 위 높이 | 면적 | 비율 |
| --- | --- | --- |
| 0 ~ 0.3 m | 524.1 m² | 37.0 % |
| 0.3 ~ 1.0 | 257.3 m² | 18.1 % |
| 1.0 ~ 1.8 | 165.2 m² | 11.6 % |
| 1.8 ~ 2.6 | 127.4 m² | 9.0 % |
| 2.6 ~ 3.5 | 244.3 m² | 17.2 % |
| 3.5 ~ 5.0 | 99.4 m² | 7.0 % |

`h < 1.8 m`로 자르니 459,501 tri / 946.6 m² 잔존. **지붕과 상부 구조가 깨끗이 걷히고 담장·기단·마당 포장·계단이 그대로 남았다.**

이어서 작은 섬 제거(2 m² 미만)를 붙였는데 **19.3 m²(2.0%)밖에 안 지워졌다.** 절단 후 덩어리 241개 중 2 m² 이상이 6개 = 927.3 m². → **떠 있어 보이는 처마 조각들이 실은 본체에 연결돼 있다.**

### 5.4 남은 문제와 권고

| 문제 | 원인 |
| --- | --- |
| 처마 조각 잔존 | 처마 끝이 지면 대비 1.8 m 아래로 내려오고, 본체와 연결돼 있어 섬 제거로 안 빠짐 |
| 기둥 그루터기 | 1.8 m 지점에서 잘림 |
| 기단 상면 구멍 | 마루에 가려 스캔되지 않은 부분. 목조 제거 시 노출 |

**권고: 전역 높이 하나로 자르지 말고 「건물 풋프린트 마스크 + 기단 상면」으로 간다.**

1. 높은 지오메트리 분포로 건물 풋프린트를 잡고, 처마 내민 만큼 약 1.5 m 확장
2. **풋프린트 안쪽에서만** 기단 상면 높이로 절단 → 처마와 기둥 그루터기가 함께 제거
3. 풋프린트 바깥(담장·마당·계단)은 전부 유지
4. 기단 상면 구멍은 평면으로 덮고 인접 석재 UV 부여

여기까지 전부 Blender 없이 numpy로 돌렸다(연결성은 scipy). Blender는 렌더 확인용으로만 썼다. 실제 작업도 무겁지 않다.

## 6. 토글 설계

### 6.1 연수전 — 기존 유물과 방향이 반대

| 상태 | 내용 | 출처 | `provenance` |
| --- | --- | --- | --- |
| **현재** | 건물 없음. 기단·초석·담장·마당만 | 원형 메시에서 목조부 제거 | `ai_inferred` |
| **기록** | 전소 전 원형 | 국가유산청 실측 3D | `observed` |

명세 3.1 기준으로 **원형이 관측이고 소실이 추정**이다. 유물(손상=관측, 복원=추정)과 반대다. UI는 `manifest`의 `provenance`를 따르므로 구현은 같지만 **패널 문구는 따로 써야 한다**(`NFR-ETH-003`).

기본 표시는 "현재". 포털을 나오면 빈 터에 서고, 토글하면 같은 자리에 원형이 올라온다.

### 6.2 석조여래좌상 — 부분 토글 (정정)

처음엔 "피해 없음 → 토글 없음"으로 판단했는데 **틀렸다.** 공식 판정은 **「대좌 소실(불신, 광배는 이운조치)」**이고 의성군 예산에 「석불 좌대 보존처리」가 편성돼 있다. 우리 glb에는 **대좌까지 온전히 들어 있어서** 그대로 세우면 현재 상태와 다르다.

| 상태 | 내용 | `provenance` |
| --- | --- | --- |
| 현재 | 불신·광배는 현장에 없고 대좌는 소실 | `ai_inferred` |
| 기록 | 불신 + 광배 + 대좌가 제자리 | `observed` |

경계는 연수전과 달리 명확하다 — 대좌는 기하적으로 분리된 하부 구조다. 실내 전시실 좌대에 올린다(높이 2.05 m).

두 전시물이 한 문장으로 묶인다 — **불신과 광배는 옮겨서 살았고, 옮길 수 없었던 대좌는 소실됐고, 옮길 수 없었던 건물은 3D 기록으로만 남았다.** 무엇을 옮길 수 있었는지가 무엇이 남았는지를 정했다.
