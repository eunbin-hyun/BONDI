## 1. 색 맞춤 단계 — `ai/3d-to-3d-color/color_match.py`

**문제.** 2D→3D 생성 모델이 만든 굽다리바리 GLB의 텍스처(갈색)가 입력 사진(회청색 경질토기)과 색이 다르다.

**방법.** 사진은 rembg로 배경을 지운 유물 픽셀만, 모델은 표면을 면적 가중으로 200만 점 샘플링해 실제로 보이는 텍셀만 취해 CIE Lab에서 분포를 맞춘다. base color 텍스처 한 장만 바꾸고 메시·UV·다른 텍스처는 건드리지 않는다(정점 좌표 차이 0 확인).

| 방식 | 내용 | 쓰는 곳 |
| --- | --- | --- |
| `reinhard` | 채널별 평균·표준편차 일치 | 무광 재질 기본 |
| `hist` | 채널별 분위수 일치 | 더 강하게 |
| `chroma` | a·b 전체 + L 평균만 | 텍스처 명암 유지 |
| `hue` (오후 추가) | a·b **평균만** 이동, L 그대로 | **금속** |

**결과(굽다리바리).** Lab 평균 모델 L41/a2.9/b8.1 → 사진 L62/a0.5/b7.1과 일치, 평균색 ΔE 21.4 → 0. 차이의 대부분은 색조가 아니라 **밝기**였다.

**한계.** 전역 분포 변환이라 사진의 특정 얼룩을 특정 위치로 옮기지는 못한다. 사진 조명이 그대로 목표가 된다. 텍스처 없는 정점색 출력(TripoSR OBJ)은 아직 미지원.

## 2. 높이맵·노멀맵 — `relief_maps.py`

- 메시를 늘리지 않고 질감을 올리는 표준 방법은 **노멀맵**(빛 방향만 속임)이다. glTF 재질에는 노멀맵 칸만 있고 범프맵(높이맵) 칸이 없다.
- 순서는 **높이맵을 마스터로** 만들고 노멀맵은 기울기로 파생(정확, 손실 없음). 반대 방향(노멀→높이)은 적분이라 근사. 높이맵을 남겨두면 나중에 디스플레이스먼트에 재사용 가능.
- 높이는 색 텍스처 밝기(Lab L)의 1~16 px 대역만 취해 "주변보다 어두우면 낮다"로 추정. **UV 아틀라스 조각 경계에서 가짜 능선**이 생겨, 메시가 실제로 쓰는 텍셀(아틀라스의 69 %) 안에서만 필터하고 바깥은 가장자리 값으로 채워 해결.
- 세기는 기울기 상위 5 %가 25°가 되게 자동 결정(계수 5.2). 뷰어 슬라이더(normalScale)로 실시간 조절 후 굽는 값 확정 예정.
- 이 요철은 색에서 추정한 것이라 `ai_inferred`. JSON에 명시.

## 3. 비교 뷰어 — `out/viewer.html`

three.js(jsdelivr CDN). 모델 전환(원본/reinhard/hist/chroma/노멀맵), 조명 끄기(텍스처 원색), 노멀맵 켜기·세기 슬라이더, 배경색. 로컬 서버(`python -m http.server 8765`)로 열어야 한다.
Blender에서 열 때 "OpenGL 4.3 required" 오류가 한 번 났는데, 같은 세션에서 직접 WGL 컨텍스트를 만들면 Intel Arc OpenGL 4.6이 잡혔다. SPAR3D가 VRAM 8.3 GB로 넘칠 때 Intel 드라이버가 Error 상태로 보고된 시점과 겹쳐 일시적 문제로 판단. Blender를 NVIDIA GPU로 지정해 둠.

## 4. 금관(금속·유광) 검증 — Jira 예정 항목 선행

`crown.jpg` + `crown.glb`(metallic 1.0, roughness 텍스처 평균 0.46)로 `color_match.py` 실행.

| 발견 | 원인 | 조치 |
| --- | --- | --- |
| reinhard 결과가 어둡고 얼룩짐 | ① 투조 구멍 사이 **검은 배경 픽셀 8.1만 개**가 유물 영역에 남아 목표 밝기를 끌어내림 | `--bg-reject`(기본 ΔE 12): 유물 바깥 영역 중앙값을 배경색으로 추정해 그 근처 픽셀 제거 |
| 배경 제거 후에도 갈색·얼룩 | ② 금속의 base color는 **반사율**이고 사진 밝기는 조명·반사. L 분포(표준편차 26 vs 8)를 복사하면 텍스처 노이즈가 3배 증폭 | `hue` 방식: a·b 평균만 이동, L 유지 |

| 방식 | Lab 평균 L/a/b | 평균색 ΔE | 눈 |
| --- | --- | --- | --- |
| 사진 | 54.8 / 14.4 / 43.0 | – | 붉은 기 금 |
| 원본 | 68.8 / −3.5 / 60.1 | 28.4 | 초록빛 노란 금 |
| reinhard | 54.6 / 14.0 / 42.9 | 0.4 | 어둡고 얼룩. 금속 부적합 |
| chroma | 54.8 / 14.4 / 42.8 | 0.2 | 균일하나 어두움 |
| **hue** | 68.8 / 14.3 / 43.0 | 14.1 | 밝기 유지, 색조만 금. **금속 추천** (ΔE 14는 의도한 밝기 차) |

결론: **재질별로 방식이 갈린다.** 무광 토기 reinhard, 금속 hue. 다음은 GLB의 metallic 값을 읽어 자동 분기. 점 렌더는 광택을 못 그리므로 최종 판단은 PBR 뷰어에서.

## 5. TRELLIS.2 설치 — `현은빈/sam3d-trellis2-image-to-3d.md` 기준

Windows 8 GB 포크 `IgorAherne/TRELLIS.2-stableprojectorz v22`를 `C:\ai\trellis2`에 설치. 설치 zip 772 MB, 첫 실행 약 50분, 총 33 GB(가중치 21 GB).

| 막힌 것 | 원인 | 해결 |
| --- | --- | --- |
| `gradio-internal.bat`을(를) 찾을 수 없음 ×3 | 자동화 셸의 `NoDefaultCurrentDirectoryInExePath=1` → cmd가 현재 폴더 `.bat`을 못 찾음 | 변수 제거 후 실행. 더블클릭은 해당 없음 |
| 가중치 다운로드 `WinError 1314` | 개발자 모드 꺼짐 → huggingface_hub 심볼릭 링크 실패 | `HF_HUB_DISABLE_SYMLINKS=1` 후 재실행, 완료 플래그 덕에 이어받음 |
| 다운로드 연결 끊김 1회 | 네트워크 | 설치기 자동 재시도로 통과 |
| EXR 로딩 오류 (현은빈 문서 5절) | 재현 안 됨 | 문서대로 첫 실행 전 `opencv-python-headless==4.11.0.86` 고정. OpenEXR 빌드 확인 |

문서와 다른 점: **웹 UI 포트가 8080**(문서 7860). `Running on local URL` 줄은 로그 버퍼링으로 안 찍히고 `[WORKER] Pipeline ready.` 뒤 포트로 확인. 파이프라인은 CPU RAM 19 GB에 상주, 대기 VRAM 0.3 GB.

**첫 생성 (API, 512).** 청동검 `test-images/sword.jpg`(배경 제거 296×2348) → image_to_3d 45 s + extract_glb 202 s = 248 s, **피크 VRAM 3.2 GB**, GLB 15.7 MB(정점 16.4만, base color 2048² + metallic/roughness). 날의 마름모 단면과 손잡이 마디까지 형상이 나옴. 문서의 "생성 미검증" 항목 해소.

**두 번째 생성 (API, 512).** 금관 `crown.jpg`(배경 제거 1528×2550) → 43.6 s + 28.0 s = 72 s, **피크 VRAM 3.6 GB**, GLB 17.2 MB(정점 20.5만). 사진에 없는 뒷면까지 **원형 관테를 온전히 완성**하고 세움장식·드리개를 만들었지만, 드리개 아래쪽은 떨어진 조각들로 흩어짐. 원인의 절반은 입력: rembg(u2net)가 드리개를 배경으로 잘라 입력 PNG에 회색 잔상만 남았다. TRELLIS.2에 내장된 RMBG-2.0을 쓰도록 원본 사진을 그대로 넣어 재시도할 것. GLB 추출이 청동검(202 s)보다 훨씬 빠른 이유는 미확인.

환경 메모: 세션 임시 폴더에 만들어 두었던 평가용 가상환경들(`venv`, `sf3d_venv`, `spar3d_venv`)의 `Scripts\` 실행 파일이 오후에 사라졌다. 평가·색 맞춤·요철 스크립트용 가상환경을 `C:\ai\venv-3dtools`(numpy·scipy·trimesh·pillow·scikit-image·matplotlib·rembg·onnxruntime)에 다시 만들었다. 임시 폴더에 환경을 두지 말 것.

저장소: `chore/ai-trellis2-setup` 브랜치에 `ai/2d-to-3d/trellis2/README.md`(설치·실행·주의·라이선스·이 PC 기록)와 `setup_trellis2.ps1`(다운로드·해제·패치·실행 자동화, 위 환경변수 포함). 미커밋.

라이선스 메모: TRELLIS.2는 MIT. 설치기가 받는 RMBG-2.0(BRIA)은 비상업 라이선스라 배경 제거 결과를 전시 자산에 쓸 때 확인 필요.
