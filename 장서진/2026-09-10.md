## 1. SAM 2 반자동 마스크 (설계 8-A 1단계)

`segment_masks.py`. ultralytics `sam2.1_b`, 텍스처 아틀라스 2K 축소본에서 프롬프트 → 8K 마스크. 환경 `C:\ai\venv-sam2`(torch cu128, RTX 4070 8 GB), 1건 15~60 s.

| 케이스 | 결과 | 판정 |
| --- | --- | --- |
| 청자 don000498 ① 마모부 | 자동 프롬프트(볼록 상위 15 %의 갈색 덩어리 bbox 29개) → 유효 면적 0.45 %, 21덩어리 | **쓸 만함**. 덩어리라 SAM에 맞다 |
| 토기 ssu022891 접합선 | 점 프롬프트는 **파편(차트) 전체**를 선택(32 %). 박스로 바꿔도 가는 조각만 2,038 텍셀 | **이득 적음**. 거친 결의 3~5 px 균열은 SAM이 객체로 안 본다 |

교훈: 아틀라스에 점을 찍으면 SAM은 차트를 통째로 잡는다. 프롬프트는 반드시 **작은 박스**로.

## 2. 접합선이 왜 안 지워졌나 — 측정

| 항목 | 접합선 근처 | 그 외 |
| --- | --- | --- |
| 원본 텍스처 L (테두리 8 px / 안쪽) | 67.7 | 73.6 |
| 면 사이 이면각 | **12.0°** | 7.7° |
| v1.5 정점 이동 평균 | 0.023 mm (물체 383 mm) | — |

색 차이는 5 L뿐인데 기하에는 확실한 홈·턱이 있다. 조명을 켜면 홈 가장자리가 빛을 받아 밝은 선이 된다(조명 끄면 거의 안 보임과 일치). **텍스처만 고치는 접근이 실패한 이유.**

## 3. v1.6 — 메우기

- **쌍조화 홈 메우기**: 접합선 정점 + 2~3링(약 7~11 mm)을 자유 변수로 두고 나머지를 고정한 채 min‖L x‖²로 다시 푼다(구멍 메우기와 같은 연산). 이면각 **12° → 2.8°**, 이동 평균 0.8 mm.
- **조각 경계 띠 밝기**: 파편 사진마다 테두리가 안쪽보다 어둡다. v1.5의 교차 조화는 양쪽 *차이*만 없애서 둘 다 어두운 띠는 남았다. 테두리 24 px 띠의 저주파 색을 안쪽 국소 평균으로 치환(고주파는 유지).
- 8K에서 색 평탄화 블러가 30분 넘게 걸려 **블록 평균 다운샘플**로 계산하도록 고침(σ 340 px → 1/32 해상도).

## 4. 이상화 회전체 (별도 노선, `idealize_revolution.py`)

회전체 그릇은 축 + 반지름 곡선 하나로 제작 당시 형상이 정해진다. 스캔을 고치는 대신 **새 메시를 만들고 무늬를 전사**하면 접합선·균열·결손이 기하에서 아예 사라진다.

| 단계 | 방법 |
| --- | --- |
| 축·프로필 | 바깥 향한 면 중심을 8 mm 슬라이스마다 원 적합(Kasa+MAD) → 중심선 PCA. 반지름 중앙값을 Savitzky–Golay로 다듬음 |
| 바닥 | 아래 25 mm + 스캔 최저 정점(r ≈ 10 mm)에 원호 적합 |
| 벽 두께 | 슬라이스별 (바깥 20백분위 − 안쪽 80백분위) 중앙값 = **7.5 mm** |
| 전사 | 스캔 삼각형을 (θ, z)로 펴서 소프트웨어 래스터(z-버퍼 = 반지름), 색은 v1.6 텍스처, 요철은 **반지름 잔차**(±2.5 mm)를 노멀맵으로 |
| 채움 | 접합선·균열·구멍은 행 보간 + 거울 복사 |

**1차 실패와 수정**: 바닥을 직선 연장했더니 원본보다 19 mm 뾰족했고(→ 원호), 벽 두께를 안팎 중앙값 차로 재서 11.5 mm로 과대(→ 백분위 차 7.5 mm, 파단면이 섞여 있었음), 구연부가 평평한 고리(→ 반원).

한계: 안쪽 벽의 균열·라벨 스티커는 남는다. 회전체가 아닌 유물엔 못 쓴다. 결손부 무늬는 추정이라 VR에서 구분 표기 필요.

## 5. v1.7 — 메운 자리에 무늬 되살리기

메우면 표면이 매끈해져 빗살이 끊긴다. 무늬가 실제로 사라진 자리(균열 채움 + 조각 경계 1.5 mm 고리)를 **핵**으로 잡고, 3 mm까지 페더되는 가중치로 고주파를 **교체**한다. 교체값은 온전한 영역 가장자리 **바깥으로 대칭인 텍셀**(q = 2·최근접 − p)의 고주파. 복사 원본은 같은 UV 조각으로 제한(옆 파편 무늬 방지).

기하에도 넣었다: 메시를 강하게 스무딩한 사본까지의 거리(= 실제 요철)를 텍스처로 굽고, 같은 거울 복사로 띠를 채운 뒤 정점을 법선 방향으로 민다(평균 0.04 mm, 상한 0.6 mm).

| 접합선 띠 28 px vs 안쪽 | v1.5 | v1.6 | v1.7 |
| --- | --- | --- | --- |
| 밝기 차 | −1.45 | −1.03 | **−0.53** |
| 띠 고주파 표준편차 | 3.00 | 2.81(너무 평평) | **2.84** (안쪽 2.73) |

**실수**: 처음엔 고주파를 *더했다*. 띠가 온전한 텍스처와 겹쳐서 대비가 4.19로 주변(2.73)보다 커졌다. 교체 방식으로 고침.

## 6. 파편 안쪽 균열 자동 검출 — 3종 시도 후 보류

메시 요철에는 균열이 또렷하다. 그런데 **깊은 마름모 장식띠**와 규칙으로 갈리지 않았다.

| 판별식 | 결과 |
| --- | --- |
| 밝기(석고가 밝다) | 성분별 국소 ΔL 중앙값 +1.3, 장식 홈도 밝아 분포가 겹침 |
| 폭(빗살 1 mm vs 균열 2~4 mm) + 이력 임계 | 진짜 균열 다수를 찾지만 장식띠도 함께 |
| 주변 홈 밀도(장식은 반복, 균열은 고립) | 표면 전체가 빗살이라 0.00~0.20으로 몰림 |

→ `--geom-cracks` 옵션(기본 꺼짐, 마스크 검수 필수)으로만 남기고, 실사용은 사람이 지정하는 쪽으로.

## 7. 마스크 붓 — 모델 위에 직접 칠하기

뷰어에 붓을 넣었다. **칠하기**를 켜면 좌드래그가 붓, 우드래그가 회전. 붓 자국은 화면이 아니라 클릭 지점의 **UV**(4096² 아틀라스)에 기록되므로 저장하면 그대로 `--crack-mask` 입력이 된다. 서버(`serve_viewer.py`, `python -m http.server` 대체)가 저장·불러오기·복원 실행 API를 갖는다.

구현에서 걸린 것:

| 문제 | 처리 |
| --- | --- |
| 파편 경계를 넘겨 드래그하면 아틀라스에서 도약 → 직선이 엉뚱한 조각을 가로지름 | 붓 반지름 4배(최소 48 px) 넘는 도약이면 획을 끊음 |
| 이상화 회전체·PoC 변형은 UV 배치가 달라 못 칠함 | 경고 띄우고 막음 |
| 되돌리기에 4096² 스냅샷을 쌓으면 무거움 | 획 목록을 갖고 다시 그림 |
| **"이 마스크로 복원"이 화면보다 나쁜 결과를 냄** | 이전 SAM·손 마스크를 빼고 검출 파라미터도 기본값으로 돌았음(균열 성분 104 → 18개, 채움 2.36 % → 0.37 %). 마스크를 합치고 `crack_params`를 JSON에 기록해 되넘김 |
| 10분 넘게 로그가 비어 멈춘 것처럼 보임 | 자식 stdout이 파이프에서 블록 버퍼링 → `PYTHONUNBUFFERED` + 경과 시간 표시 |
| 두 번 빨리 누르면 작업 2개 시작 | 요청 안에서 잠금 걸고 자리 선점(작업 스레드가 채우는 값을 검사하고 있었음) |
| 작업 스레드 예외 시 영원히 "실행 중" | 예외 포착 후 rc −1과 로그 |

검증: 실제 포인터 이벤트로 19,450 텍셀 저장·재로드 왕복, 그중 93.5 %가 아틀라스 섬 안. 가짜 인터프리터로 시작·중복·실패·재시작 4경로 확인.

**실사용 결과**: 사용자가 칠한 10획(유효 텍셀의 0.19 %)을 이전 마스크와 합쳐 재실행 → 균열 성분 104개, 채움 2.36 %, 거울 복사 성공률 98.3 %. 앞면을 가로지르던 밝은 접합선이 조명 아래에서 사라짐.

## 8. 배운 것

- **증상이 색으로 보여도 원인이 색이 아닐 수 있다.** 접합선은 텍스처 5 L 차이인데 이면각은 12°였다. 재보기 전까지 텍스처만 세 버전(v1.3~1.5) 손봤다.
- **자동화가 안 되는 지점을 인정하고 사람 입력을 설계에 넣는 게 빨랐다.** 균열 검출에 반나절 쓰고 못 갈랐는데, 붓은 한나절에 되고 결과가 확실하다.
- **UI 버튼은 "돌아간다"로 끝나지 않는다.** 재현성(마스크·파라미터 승계)과 진행 표시가 없으면 사용자에겐 고장난 것과 같다.
- 8K 파이프라인은 한 건 12~15분. 파라미터 시험은 2K에서 먼저(30초), 래스터 캐시(`--reuse-raster`)로 반복 비용을 줄임.
