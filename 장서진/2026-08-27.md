# 260827 작업 정리 — 장서진

담당: AI · VR

## 1. 기획 조사
- 국립박물관 소장품 3D 구축 데이터(공개분) 구조·품질 조사 — 유물 10건(부품 12점) 확보
  - 유물 1건 = 3종 세트: 디지털콘텐츠 OBJ(+8K 디퓨즈/노멀/알파맵) · 스캔 PLY · 프린트 STL
  - 품질 이슈 실측: MTL 절대경로 깨짐, OBJ-MTL 재질명 불일치, 좌표 단위 혼재(mm/m), 변형 바이너리 STL(Magics계), 아틀라스 배경색 상이(흑/백), 스캔 PLY 정점색 더미(전부 흰색) 다수, CP949 파일명·중첩 zip → **전처리 정규화 계층이 필수**
- 검증 유물: 금동미륵보살반가사유상, 청동검, 금동보살좌상, 금제 과판(터키석 감장), 투각 금동장식, 청동보살입상, 청자 향로 2건, 백자 철화 매죽문 항아리, 매병(색 정보 없음)

## 2. 가상 복원 기술 검증 (PoC)

### 규칙 기반 "제작 당시 모습" 복원 파이프라인 → 10유물/5재질군 관통
- 실제 보존처리 절차(상태조사→부식물 제거→재마감→형상 안정화→기록)를 CIELAB 영상처리로 구현. 딥러닝 미사용
- 파이프라인 (`pipeline.py`):
  1. UV 삼각형 래스터라이즈로 유효영역 산출 — 배경색 추정 없이 아틀라스 형태 무관
  2. 건전부(잔존 원표면) 자동 검출 — 금속은 "밝고 노란 잔존면", 도자기는 "지배 유약색에 가까운 밝은 면" (상위 15% 분위수, 조명·노출 불변)
  3. 부식 암점 클리닝 + 재질 프리셋 7종(금동·청동·철·은·금·청자·백자) 목표색으로 **명암(조각 음영) 보존한 채 색도만 이행**
  4. 장식 보호 — 투각 구멍(알파맵)·음각 문양·철화 그림을 근흑색/고정 임계로 보호 (투각 장식 20.4%, 철화백자 59.3% 보호 실측)
  5. 형상 안정화 — Taubin 스무딩 + 정점 이동 상한을 바운딩박스 대각선의 0.07%로 클램프 (91cm 불상 0.77mm, 최소개입)
  6. 복원 텍스처를 스캔 PLY 정점색으로 역투영 (KD-트리 최근접 정점, 브루트포스 시 39GB 거리행렬 회피)
- 부식 타임라인 (`timeline.py`): "지금 녹이 심한 픽셀 = 먼저 부식된 곳" 가정으로 현재 녹 분포를 발현 순서 지도로 사용, t∈[0,1] 임의 시점 재구성 — 청동검 t=0.35→녹 26%, t=0.70→82%
- 검증: 유물별 before/after 텍스처·3D 비교 자동 렌더 + Blender 5.2 비교 씬 11개(헤드리스 EEVEE로 픽셀 검증 후 GUI 납품)
- 교훈:
  - **음영은 조각의 시각 정보다** — 명도까지 평탄화(pristine)하면 형태가 사라져 보임. 색만 이행하는 conserved 모드를 기본으로 확정
  - **장식은 부식이 아니다** — 명도 임계로는 "확실히 어두운" 장식까지만 보호됨. 터키석 상감이 금색으로 오염색된 실패 사례 확보 → 부식/장식/결손/상감 **의미론적 세그멘테이션이 AI 1순위**라는 근거
  - 규칙 기반 산출물(손상지도·건전부/보호 마스크·복원 텍스처 페어)이 그대로 학습용 약지도/의사 GT → **프로토타입 = 데이터 생성기**

### 결손 형상 복원 방향 수정
- PoinTr 부적합 판정(8/26)은 이번 OBJ 데이터에도 동일 적용 — **파일 포맷(LAS/OBJ)은 도메인과 무관**, 입력은 결국 정규화 점군
  - PoinTr 도메인 = ShapeNet-55 합성 CAD의 ① 카테고리 형상 prior ② partial-view 크롭형 결손 분포(침식·박락형 아님) ③ 출력 8,192점 고정·XYZ-only(색 미지원)
  - 단, 매병·향로 등 **회전체 그릇류는 ShapeNet의 jar/vase/bottle/bowl 카테고리와 근접**해 전역 실루엣 완성은 승산 있음. 인물상·동물상은 카테고리 자체가 없어 석등과 같은 실패 예상
- 방침: 대칭 유물은 8/26의 기하(점유 격자+ICP) 방식 이식. 딥러닝은 이번 온전 스캔 12점에 **합성 결손을 만들어 (partial, complete) 파인튜닝 페어 생성** — 그릇류부터, 해상도 한계는 결손부 주변 패치 단위 완성으로 우회 (AdaPoinTr/SeedFormer 계열 검토)

## 3. 학습 계획 (AI · VR)
- AI: 손상/장식 세그멘테이션(U-Net·SAM 파인튜닝, 이번 약지도 활용) → 재질 조건부 diffusion inpainting으로 재마감 단계 대체 → 재질 자동 분류기(현재 수동 프리셋 선택 대체)
- VR: Unreal 입문(첫 사용) — 에디터 구조·레벨·블루프린트 기본, 에셋 임포트/머티리얼/라이팅 동작 원리, VR 템플릿 실행까지 기초 학습 선행 → 이후 복원 산출물(OBJ+8K 텍스처+PBR 재질) 임포트 파이프라인, 복원 전후·부식 타임라인 비교 관찰 인터랙션 설계
