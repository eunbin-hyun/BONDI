# 유물 복원 평가 지표 — GT 가 없을 때

> **출처 구분.** §1 은 외부 정리 자료를 공세민이 2026-09-18 가져와 옮긴 것이다.
> 지표 정의와 방향(낮을수록 우수 등)은 원문 기술을 그대로 옮겼고 **내가 문헌으로
> 대조하지는 않았다.** §2 이하는 이 프로젝트 데이터로 직접 확인한 내용이다.
>
> 원문은 **2D 이미지 복원**을 기준으로 쓰였다. 우리 대상은 **3D 메시**이므로
> 그대로 쓸 수 없는 항목이 있다. §2 에 대입 검토를, §3 에 3D 용 대체 지표를 붙였다.

---

## 1. 원문 — GT 없는 평가 방법론 네 갈래

GT 가 없을 때는 특정 정답과의 비교 대신 ① 복원물 자체의 물리적 품질 ② 동일
카테고리 유물 집단과의 통계적 유사성 ③ 다운스트림 태스크 성능 ④ 도메인 전문가
검증을 조합해 다각도로 평가한다.

### 1-1. 무참조(No-Reference) 이미지 품질 지표

비교할 원본 없이 이미지 자체의 노이즈·블러·왜곡·깨짐을 수학적으로 계산해 점수화한다.

| 지표 | 무엇을 하나 | 방향 |
|---|---|---|
| **NIQE** (Natural Image Quality Evaluator) | 자연 이미지의 고유 통계 모델을 세워 두고, 복원 이미지가 그 모델에서 얼마나 벗어났는지 측정 | 낮을수록 우수 |
| **BRISQUE** (Blind/Referenceless Image Spatial Quality Evaluator) | 국소 휘도 정규화 계수를 분석해 인위적 노이즈·압축 손실·블러를 잡는다 | 낮을수록 우수 |
| **PIQE** (Perception based Image Quality Evaluator) | 인간 시각 민감도를 반영해 왜곡이 심한 블록을 찾아 점수화 | 낮을수록 우수 |

### 1-2. 분포 기반 도메인 유사도

개별 GT 는 없지만 "잘 보존된 정상 유물 뭉치" 가 있을 때 쓰는 통계적 방식.

| 지표 | 무엇을 하나 | 방향 |
|---|---|---|
| **FID** (Fréchet Inception Distance) | 복원 결과 N장의 특징 벡터 분포와 정상 유물 N장의 분포 사이 거리 | 낮을수록 우수 |

개별 정답은 비교하지 못하지만 *"복원 결과물들이 실제 유물 세계의 특징을 전반적으로
따르고 있는가"* 를 보일 수 있어 생성 분야에서 가장 널리 쓰인다.

### 1-3. 다운스트림 태스크 기반 검증

*"올바르게 복원했다면 다른 비전 모델이 더 잘 인식해야 한다"* 는 논리의 우회 평가.

| 태스크 | 판단 근거 |
|---|---|
| 유물 분류 · 객체 탐지 | 복원 전에는 인식 못 하다가 복원 후 기종·문양을 맞히면(Top-1 상승) 복원이 타당 |
| 텍스트 판독률 (OCR) | 고문서 복원에서 문자 인식률 개선(CER 감소) 확인 |

### 1-4. 물리적 가이드라인 · 안티할루시네이션

AI 가 상상해 그린 '그럴듯한 가짜' 를 걸러내는 규칙 기반 평가.

| 항목 | 무엇을 보나 |
|---|---|
| **대칭성 · 연속성** | 복원 영역이 잔존 영역의 중심축 · 곡률 · 선의 연속성을 수학적으로 위배하지 않는지 |
| **마스킹 영역 보존율** (Input Preservation) | 훼손되지 않고 입력으로 들어간 영역이 복원 과정에서 변형되지 않았는지 픽셀 일치율 확인 |

### 1-5. 원문이 제안한 3단계 하이브리드

```
[1단계 기술 검증]  NIQE / BRISQUE      — 자연스러운 고화질인가
      ↓
[2단계 분포 검증]  정상 유물셋과 FID    — 진짜 유물 스타일을 따르는가
      ↓
[3단계 정성 평가]  보존과학자·미술사학자 3~5인 블라인드 — 역사적 오류가 없는가
```

## 2. 이 프로젝트에 대입하면

### 먼저 — 우리에게 없는 GT 가 무엇인지 층을 갈라야 한다

원문은 "GT 가 없다" 를 한 덩어리로 다루는데, 우리 경우엔 **두 층**이다.

| 층 | GT 가 있나 | 무엇으로 평가하나 |
|---|---|---|
| **합성 파손 → 복원** | **있다.** `06_신제재현` 을 정답으로 고정하고 일부러 깼다 | 직접 오차 측정. [방법과결과](2026-09-18-복원벤치마크-방법과결과.md) 가 그것이다 |
| **실제 유물의 손상 전 원형** | **없다.** 손상 전 스캔이 존재하지 않는다 | 원문의 방법론이 필요한 자리 |

즉 원문은 **아래 층(실물 배포)** 에 적용된다. 위 층은 이미 GT 기반으로 재고 있고,
그 결과가 우리 벤치마크다. 두 층을 섞어 적으면 "GT 없이 평가했다" 는 잘못된 서술이
된다.

### 항목별 적용 가능성

| 원문 항목 | 우리에게 | 이유 |
|---|---|---|
| NIQE · BRISQUE · PIQE | **부적용** | 2D 이미지 지표다. 렌더 이미지에 적용하면 **렌더러·조명·샘플 수**를 재게 되고 형상 오차와 무관하다. 우리 대상은 메시 표면이다 |
| FID | **부적용 (현 시점)** | 표본이 없다 — 빗살무늬토기 완형 3D **1점**, 굽다리바리 참고 3D 는 팀 문서 기준 42~43점 중 **완형 9점**뿐이다. FID 는 통상 수천 표본에서 안정하고 소표본에서는 분산이 값을 지배한다 |
| 다운스트림 (분류·탐지) | **조건부** | 우리 다운스트림은 VR 전시다. 기종 분류기를 만들 수는 있으나 **유물 1점으로는 정확도가 의미를 갖지 못한다.** 유물 확보가 먼저다 |
| OCR | **해당 없음** | 문자 유물이 아니다 |
| 대칭성 · 연속성 | **적용. 부분적으로 이미 한다** | §4 참고 |
| 마스킹 영역 보존율 | **적용. 이미 한다** | 잔존 셀 최대 변화 **0.00mm** 로 전 방법 확인 |
| 전문가 블라인드 | **적용. 아직 안 했다** | 유일하게 "역사적으로 말이 되나" 에 답하는 단계다 |

> **요약:** 원문 4갈래 중 2갈래(무참조 이미지 품질, 분포 기반)는 우리 대상·표본 수에
> 맞지 않는다. 남는 2갈래(물리 가이드라인, 전문가 검증)가 실제로 쓸 수 있는 것이고,
> 그중 물리 가이드라인은 이미 일부 측정하고 있다.

## 3. 3D 에 맞는 무참조 지표 — 원문에 없는 것

메시에는 이미지의 NIQE 에 해당하는 **구조 무결성 검사**가 있다. 이쪽이 우리에게
실제로 쓸 수 있는 "참조 없는 품질" 이다.

| 지표 | 무엇을 잡나 | 우리 상태 |
|---|---|---|
| **watertight · genus · 성분 수** | 구멍 · 터널 · 떠다니는 조각 | 정답 확인: watertight · **genus 0** · 성분 1개 (정점 927,152) |
| **법선(winding) 일관성** | 뒤집힌 면 | **정답조차 `False`** — 무참조 검사로만 잡히는 실제 결함이다 |
| **경계 연속성 G0 / G1** | 채움면이 잔존부와 값·기울기 모두 이어지나 | 이중조화(`Δ²u = 0`)가 **구조적으로 G1 을 보장**한다 — 그래서 쓴다 |
| **회전대칭 잔차** | 축 중심 이탈 · 비대칭 왜곡 | 중앙 **0.3174mm** = 반지름 108mm 의 **0.29%** (p95 1.27mm) |
| **벽 두께 타당성** | 실측 범위(10.3~21.8mm) 밖으로 나가나 | **미검사.** 복원 패치 두께는 잔존 벽에서 읽어 넣는다 |
| **자기교차** | 면이 서로 관통 | **미검사** |
| **곡률 연속성** | 채움면 곡률이 경계에서 튀나 | **미검사** |
| **프로파일 단조성** | 회전체 실루엣이 물리적으로 말이 되나 | 고배는 비단조 5회·13회로 기록됨 (굽다리 때문) |

**미검사 셋(벽 두께 · 자기교차 · 곡률 연속성)이 다음에 붙일 것이다.** 셋 다 GT 가
필요 없고 계산이 싸며, "AI 가 상상해 그린 것" 을 걸러내는 데 직접 쓰인다.

## 4. 우리가 이미 재고 있는 것

| 원문 항목 | 우리 측정 | 값 |
|---|---|---|
| 마스킹 영역 보존율 | 잔존 셀 최대 변화 | **0.00mm** (전 방법. 회전대칭 채움은 구조상 전면 교체라 제외) |
| 대칭성 | 회전대칭 잔차 | 중앙 0.3174mm = 반지름의 **0.29%** |
| 연속성 | 이중조화 해의 G1 보장 | 경계의 값·기울기를 이어받는다 |
| 위상 무결성 | genus · watertight | 정답 genus 0 · watertight |

여기에 GT 기반 지표(커버리지 · F-score@δ · Chamfer · 반지름 MAE)가 더해진다 —
그건 합성 파손 층에서만 가능하고, 수치는
[방법과결과](2026-09-18-복원벤치마크-방법과결과.md) §4 에 있다.

## 5. 우리 경우의 권장 조합

원문의 3단계를 우리 대상에 맞게 바꾼 것이다.

| 단계 | 무엇 | 지금 |
|---|---|---|
| **1. 구조 무결성** (GT 불필요) | 보존율 0mm · watertight · genus · G1 연속성 · **벽 두께 · 자기교차 · 곡률** | 앞 넷은 함. **뒤 셋 추가 필요** |
| **2. 합성 파손 벤치마크** (GT 있음) | 정답을 깨서 직접 오차 측정 | **완료** — 820 표본 · 7방법 · 지표 3종 |
| **3. 기종 형태 통계와의 편차** | FID 대신 **프로파일 PCA 거리** — 소표본에서도 해석 가능 | 유물 수 확보 후. 팀 `shape-prior/` 가 그 자리 |
| **4. 전문가 블라인드** | 보존과학자·미술사학자 3~5인 | **미실시.** "역사적으로 말이 되나" 에 답하는 유일한 단계 |

### 원문과 갈리는 점 둘

**하나 — 렌더 이미지에 NIQE·BRISQUE 를 적용하지 않는다.** 그 값은 렌더러 설정과
조명을 재는 값이고, 같은 메시를 다르게 렌더하면 점수가 바뀐다. 형상 품질과 인과가
없다.

**둘 — FID 자리에 PCA 거리를 넣는다.** FID 는 소표본에서 못 쓴다. 같은 기종 유물의
반지름 프로파일을 PCA 로 줄여 **주성분 공간에서의 마할라노비스 거리**를 재면, 표본이
수십 점이어도 "이 형태가 이 기종 분포 안에 있나" 를 해석 가능한 수치로 말할 수 있다.
분포 검증의 취지는 그대로 살린다.
