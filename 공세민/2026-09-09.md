# 2026-09-09 학습 정리 — Quest 2 손 추적 상호작용을 실측으로 잡고, 메인 홀·테마관·포털 공간 구조를 세우기

- 학습 주제: (1) OpenXR 손 추적 데이터가 UE 5.8 블루프린트에 실제로 어떤 경로로 들어오는지 확인하고, 손끝 버튼·핀치 집기·관절 손 표시를 Quest 2 + SteamVR에서 동작하게 만들기 (2) 팀 결정 D-54(메인 홀 + 유물별 테마관 + 포털 텔레포트 + 서브레벨)를 명세에 확정하고 레벨로 1차 구현하기
- 배경: 어제(09-08) 버튼 판정을 "실제 손끝 좌표"로 바꿨는데 필드 테스트에서는 손바닥 아래쪽으로 겨우 눌리고, 핀치로는 토기가 안 잡혔다. 손 추적 자체는 잘 됐으므로 문제는 데이터가 아니라 좌표·판정·시각화였다. 오후에는 공간 구조가 "홀 + 테마관"으로 바뀌어 명세와 레벨을 함께 고쳤다
- 확인 기준: Quest 2(ALVR + SteamVR OpenXR)에서 직접 눌러 보고 잡아 본 것, 에디터 캡처로 확인한 것만 적었다. 손 추적 3건은 dev에 병합됐고(`fix/vr-fingertip-hand-tracking`, `chore/vr-spheres-only`, `docs/spec-hall-theme-rooms`), 공간 구조 2건은 MR 대기다(`feat/vr-room-scoped-interaction`, `feat/vr-hall-theme-rooms`)

## 1. 핵심 결론

**1) 손 관절은 `GetHandTrackingState` 한 함수로만 들어온다.**

UE 5.8 OpenXR에서 `LeftIndexTip` 같은 관절 모션 소스는 항상 `IsTracked=false`이고, `GetHandJointPosition`은 OpenXR 핸드 트래킹 플러그인이 구현하지 않았다.
XRBase의 `GetHandTrackingState`가 26개 관절의 월드 위치·회전(쿼터니언)·반지름을 한 번에 준다. 인덱스는 Palm 0, Wrist 1, ThumbTip 5, IndexTip 10, MiddleTip 15.
`bValid`는 한 번 true가 되면 그대로 남는 값이라 판정에는 `TrackingStatus == Tracked`를 써야 한다.

**2) SteamVR은 컨트롤러를 쥐고 있어도 손 관절을 합성해 준다.**

"손 모드 / 컨트롤러 모드" 분기가 실질적으로 의미가 없다. 그래서 손 표시를 관절 구체 하나로 통일하고 템플릿 장갑 메시는 항상 숨겼다.
컨트롤러를 쥔 상태의 검지 끝은 고정 포즈이므로 그때만 눌림 지점을 앞으로 9 cm 보정한다.

**3) 판정 값은 추정하지 말고 재서 정한다.**

"버튼이 손바닥 아래서 눌린다"의 원인 후보가 셋(좌표계, 관절 인덱스, 버튼 크기)이었다.
엄지끝–검지끝 거리가 0.4~12.2 cm 사이로 살아 움직이는 것을 로그로 먼저 확인해 "관절 데이터는 진짜다"를 확정하고, 그다음 버튼 지름 6→10 cm, 측면 허용 4.5→5.5 cm를 바꿨다.
추정으로 고친 것은 두 번 다 틀렸고, 재서 고친 것은 한 번에 맞았다.

**4) Live Link 장갑은 "축 보정" 하나가 남은 상태로 보류했다.**

뼈 이름 매핑 21/26, 회전만 리타겟(`bRetargetRotationOnly=true`)까지 되고 손가락도 굽는다.
그러나 OpenXR 관절 축과 Manny 뼈 축이 달라 손허리뼈·엄지가 뒤로 꺾인다. 남은 일은 리맵 에셋의 `SwizzleX/Y/Z/W` 보정뿐이라 에셋(`LLRA_HandLeft/Right`, `LLP_HandTracking`)은 커밋해 두고 구체 손으로 갔다.

**5) 공간 구조는 "메인 홀 + 유물별 테마관", 이동은 포털, 레벨은 서브레벨(레벨 인스턴스).**

D-54로 명세에 확정했다. 레벨 파일 하나가 LFS 락 단위이므로 "방 = 레벨 = 담당자"가 되어 동시 작업 충돌이 사라진다.
방 안 상호작용은 전역 태그 검색 대신 "가장 가까운 유물"로 스코핑해서 방이 여러 개여도 서로 간섭하지 않는다.

**6) MCP로 에디터를 조작할 때는 쓴 뒤 반드시 되읽는다.**

`set_actor_transform`에 scale만 보내면 위치·회전이 원점으로 리셋되고(버튼이 사라졌던 원인), 클래스 핀에 값을 넣으면 성공을 돌려주면서 아무것도 바뀌지 않는 경우가 있다. 6절에 모았다.

## 2. 손 추적 상호작용 — 증상 → 원인 → 조치

| 증상 (필드 테스트) | 원인 | 조치 |
| --- | --- | --- |
| 버튼이 손끝이 아니라 손바닥 아래쪽으로 눌림 | 관절 좌표를 Palm(0) 근사로 쓰고 있었음 | `HandKeyLocations[10]`(IndexTip) 사용. 컨트롤러 폴백 시 `FingerOffset` 9 cm |
| 겨우 오른쪽으로 밀어야 눌림 | 버튼 지름 6 cm에 측면 허용 4.5 cm — 손끝 반지름(~1 cm)과 트래킹 흔들림을 못 받아 줌 | 지름 10 cm(스케일 0.10), `LateralLimit` 5.5, `TriggerDepth` 0.9, `MaxTravel` 1.2 |
| 핀치로 토기가 안 잡힘 / 최하단만 잡힘 | `BP_GrabComponent`가 토기 바닥(피벗)에 있어 손이 닿는 몸통과 멀었음 | 그랩 컴포넌트를 중심(상대 z 19)으로, `GrabRadius` 25. 핀치는 엄지끝–검지끝 거리 `PinchOn/Off` 2.5/4.0 cm |
| 잡은 뒤 물체가 손과 다른 속도로 따라옴 | 앵커를 매 틱 `SetWorldLocation`(스윕)으로 옮겨 보간이 끼어듦 | `bTeleport=true`로 이동. 앵커 회전에 손바닥 쿼터니언(`HandKeyRotations[0]`) 적용 → 회전도 따라옴 |
| 구체가 노트북 미러 화면에서 어긋나 보임 | HMD 안에서는 맞음. 미러(스펙테이터) 화면은 시점이 달라 어긋나 보임 | 위치 판정은 HMD 안에서만 한다 |
| 컨트롤러를 쥐면 장갑이 잠깐 보이다 구체로 바뀜 | 템플릿 `BP_XRPawn`이 손 메시를 그대로 그림 | `BP_HandGrab`이 매 틱 `GetHandLeft/Right`를 `SetVisibility(false)`. 폰은 안 건드림(`BP_XRPawn`은 김신정 담당) |

구조는 두 블루프린트다.

- `BP_StageToggle`(버튼): `UpdateButton`이 양손 검지끝을 `GetHandTrackingState`로 읽고 `ConsiderTip`으로 눌림 깊이를 계산한다. 손이 없으면 컨트롤러 위치 + 9 cm로 폴백.
- `BP_HandGrab`(레벨에 1개): 첫 틱에 손바닥 앵커 2개 + 관절 구체 26×2를 만들고, 매 틱 위치·반지름(`HandKeyRadii`)을 갱신한다. 핀치가 켜지면 `Artifact` 태그 액터의 그랩 컴포넌트에 `TryGrab`, 풀리면 `TryRelease`.

## 3. 손 시각화 — Live Link 시도와 보류

Live Link 소스 추가 순서(에디터에서 손으로 하는 부분):

1. Window → Virtual Production → Live Link → **+ Source** → **Windows Mixed Reality Hand Tracking Source**. 이름은 WMR이지만 OpenXR 손 추적 공용 소스다. 서브젝트 `LeftHand` / `RightHand`가 생긴다.
2. 서브젝트별 Remap Asset에 `UOpenXRHandTrackingLiveLinkRemapAsset` 파생 에셋을 지정한다. 속성은 `HandTrackingBoneNameMap`(OpenXR 관절 → 스켈레톤 뼈 이름), `bRetargetRotationOnly`, `SwizzleX/Y/Z/W`.
3. `ABP_MannequinsXR`(Content/XRMannequins/Meshes)에 Live Link Pose 노드를 끼우고 Output Pose 앞에 연결한다.
4. 프리셋으로 저장해 `DefaultGame.ini`의 `[/Script/LiveLink.LiveLinkSettings] DefaultLiveLinkPreset`에 등록하면 에디터 시작 시 자동 연결된다.

결과:

| 설정 | 현상 |
| --- | --- |
| `bRetargetRotationOnly=false` | 뼈가 공간으로 날아감. 관절 위치까지 적용돼 Manny 뼈 길이와 충돌 |
| `bRetargetRotationOnly=true` | 손가락은 굽는다. 그러나 손허리뼈·엄지가 뒤로 꺾임 — 뼈 이름이 아니라 축 문제 |

스위즐 4개 조합을 보정해야 하는데 오늘 시간 안에 못 맞춰 보류했다. **결정: 관절 구체(26개)만 표시, 장갑은 항상 숨김.**
ABP는 원래 상태(Output Pose ← Mirror)로 되돌렸고, 리맵 에셋·프리셋은 커밋해 뒀다.

부수 사고: HMD가 검은 화면이 됐는데 SteamVR 재시작으로 해결됐다. 노트북 화면은 나오는데 HMD만 까맣으면 SteamVR부터 재시작한다.

## 7. 한계와 다음 할 일
