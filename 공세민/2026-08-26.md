## 1. 핵심 결론

3D 유물 복원은 생성 모델 하나로 완형을 만드는 문제가 아니라 다음의 하이브리드 파이프라인으로 접근해야 한다.

```text
정밀 촬영·스캔
→ 관측 형상 재구성
→ 디지털 클리닝과 축·표면 분석
→ 기하학 기준선 생성
→ AI가 복수의 결손 후보와 불확실성 예측
→ 물리·기하 검증
→ 관측부와 추정부를 분리해 보존
```

실행을 재현할 수 있다는 것과 사라진 역사적 형상이 실제로 맞다는 것은 별개의 문제다. 따라서 AI 결과는 **복원 정답이 아니라 검증 대상인 가설**로 다뤄야 하며, 원본 관측값을 생성 결과로 덮어쓰면 안 된다.

## 2. 조사한 주요 기술

| 목적 | 기술 | 판단 |
| --- | --- | --- |
| 사진 기반 현존 형상 기록 | COLMAP + OpenMVS, Meshroom | 재현 가능한 계측 기준선으로 적합 |
| 점군 정합·기하 검증 | Open3D | ICP, 거리 계산, 충돌 검사 등에 활용 |
| 회전대칭 토기 파편 조립 | Structure-from-Sherds++ | 토기에는 가장 먼저 재현해볼 후보 |
| 일반 도기·석기·골편 조립 | GARF | top-k 자세 후보를 만든 뒤 기하 검증 필요 |
| 결손부 별도 메시 생성 | DeepJoin | 원본과 분리된 수선부 가설 생성에 적합 |
| 범용 점군 완성 | SymmCompletion, AdaPoinTr/PoinTr | 문화재 데이터로 별도 검증·미세조정 필요 |
| 전시용 자유 시점 표현 | NeRF, 3D Gaussian Splatting | 시각화에는 유용하지만 실측 형상 master로는 부적합 |

이번 데이터는 하나의 축대칭 토기 점군이므로, 파편 재조립보다 **축대칭 형상 제약과 자기지도 학습을 이용한 결손 복원**에 집중하는 것이 적절하다.

## 3. 데이터 점검 결과

`RR_07_01_EA_028`의 점검 결과는 다음과 같다.

| 항목 | 결과 |
| --- | --- |
| 포인트 수 | 179,294개 |
| 컬럼 | X, Y, Z, R, G, B |
| 결측·무한값·중복 좌표 | 없음 |
| 대략적인 크기 | 0.646 × 0.624 × 0.352 m |
| 점 간격 중앙값 | 약 1.61 mm |
| 색상 | 색상 보정 정보가 없는 8-bit RGB |

주의할 점은 다음과 같다.

- LAS의 실제 포인트는 정상이나 헤더 bounds가 0이고 CRS·단위·장비 정보가 없다. 원본은 보존하고 CSV를 좌표 기준으로 삼는 편이 안전하다.
- 중앙의 약 12 cm 빈 영역은 실제 파손부, 원래 입구, 스캔 사각, crop 누락 중 무엇인지 파일만으로 확정할 수 없다.
- 완형 ground truth가 없기 때문에 이 파일 하나만으로 범용 AI를 학습하거나 실제 결손의 정확도를 평가할 수 없다.
- 이 데이터는 전처리 파이프라인 개발과 실제 데이터 blind demo에 사용하고, 성능 평가는 관측된 영역에 합성 결손을 만들어 수행해야 한다.

## 4. 디지털 클리닝과 형상 분석

### 원본 보존과 정규화

- CSV·LAS·JSON 원본은 읽기 전용으로 보존한다.
- 중심을 원점으로 이동하고 토기의 주축을 Z축에 맞춘다.
- 좌표 변환 전후를 연결하는 4×4 행렬과 단위 정보를 별도로 기록한다.
- 원본, 클리닝 결과, outlier 후보를 각각 다른 파일로 유지한다.

### 클리닝 시작값

| 처리 | 권장 시작값 |
| --- | --- |
| Voxel downsampling | 1.5~2.0 mm |
| Statistical outlier | 이웃 24~30개, `std_ratio=2.5~3.0` |
| Radius outlier | 반경 5~7 mm, 최소 4~6점 |
| Normal 추정 | 반경 8~12 mm, 최대 이웃 30~50개 |
| 단면 slice | 3~5 mm |

Outlier는 즉시 삭제하지 않고 먼저 별도 색으로 표시해 확인해야 한다. 파단 경계의 낮은 밀도를 노이즈로 오인할 수 있고, 과도한 smoothing은 실제 표면 흔적을 지울 수 있기 때문이다.

### 회전축 추정

결손이 있는 점군에서는 단순 PCA 축이 약 12.6° 기울어졌다. 따라서 각 높이의 단면에 RANSAC 원 맞춤을 수행하고, 원 중심들을 직선으로 맞춰 강건한 회전축을 구하는 방식이 더 적합하다.

```text
(x, y, z) → (θ, z, r)
```

원통 좌표로 변환하면 높이별 반경과 각도별 관측 범위를 분리해 분석할 수 있다.

## 5. 기준선과 AI 복원

### 기하학 기준선

AI보다 먼저 높이별 외곽 반경 `r(z)`를 강건하게 추정하고, B-spline 또는 이동평균으로 완화한 뒤 회전시켜 surface-of-revolution을 생성한다. 작은 구멍에는 제한적인 RBF, Ball Pivoting 등을 사용할 수 있지만, 큰 결손을 Poisson으로 무조건 닫으면 원래 구조까지 바꿀 위험이 있다.

기하학 복원은 전체 관측 표면을 교체하는 것이 아니라 **결손 후보 영역에만 삽입**해야 한다.

### AI 복원

최종 실험에서는 유물 전용 자기지도 좌표 신경망 2개를 사용했다.

- 총 파라미터: 3,682개
- 외벽 모델: `r = f(높이, 각도)`
- 상부 모델: `h = g(반경, 각도)`
- 참고 구조: SIREN 계열 좌표 신경망
- 학습·평가 방식: 관측 표면 일부를 가린 synthetic holdout

후속 개선에서는 신경망이 예측한 곡면 프로파일을 그대로 메시로 만들지 않고 다음의 domain prior를 함께 적용했다.

- 회전대칭 제약: 토기의 전체 축대칭 구조를 유지한다.
- 저주파 제약: 관측 노이즈나 국소적인 진동이 전체 형상으로 증폭되는 것을 막는다.
- 평활 제약: 표면 프로파일과 곡률이 급격하게 끊기지 않도록 한다.

이 구성은 단순 생성형 AI가 아니라 **Geometry-prior AI reconstruction**이다. 신경망은 관측된 굴곡을 예측하고, 기하 제약은 결과가 토기의 구조적 특성을 벗어나지 않도록 제어한다.

| 평가 항목 | 기하학 baseline | AI 복원 |
| --- | ---: | ---: |
| 홀드아웃 셀 | 1,219칸 | 1,219칸 |
| MAE | 5.16 mm | 1.24 mm |
| 개선율 | - | 75.9% |
| 표시 메시 최대 비대칭 | - | 0.71 mm |

재학습한 메시와 가중치의 SHA-256이 동일해 재현성도 확인했다. 다만 **1.24 mm는 관측 표면 재구성 오차**이며 역사적 완형의 고증 정확도가 아니다. 생성 메시 역시 전시 비교용 비수밀 메시이므로 바로 3D 프린팅에 사용할 수 없다.

이 경험은 반도체 직무에서도 `AI 예측 + 물리·공정 제약 기반 가상계측`이라는 문제 해결 구조로 연결해 설명할 수 있다. 다만 프로젝트 자체의 목표는 유물 복원과 검증에 두고, 직무 연결은 사용한 역량과 접근 방식 중심으로 제시하는 편이 자연스럽다.

최초 AI 결과가 관측된 세부 굴곡을 적극적으로 표현했다면, 기하 제약 결과는 토기의 큰 회전대칭 구조를 유지하면서 제한된 범위 안에서 AI 예측을 반영한다. 두 결과를 함께 두면 데이터 적합도와 구조적 안정성 사이의 차이를 비교할 수 있다.

웹 UI도 구현했지만 빠른 비교라는 사용 목적에는 정적 비교 이미지가 더 적합했다. 사용자 경험은 기능 수보다 **핵심 차이가 즉시 보이는 가장 단순한 표현 방식**을 선택하는 것이 중요하다는 점을 확인했다.

## 7. 검증 항목

시각적으로 그럴듯한 결과만으로는 부족하므로 다음 지표를 함께 측정해야 한다.

- Chamfer distance
- 95% Hausdorff distance
- 높이별 반경 MAE
- normal angular error
- 파단 경계 gap과 곡률 연속성
- 관측 영역 변형량
- 결손 비율별 성능 저하
- uncertainty interval coverage
- 가능하다면 복제품 fit test와 출력물 재스캔 편차

특히 `observed region displacement`는 거의 0이어야 한다. AI가 남아 있는 실제 유물 표면까지 바꾼다면 복원 시스템으로서는 실패다.

## 8. 배운 점

1. 실측 데이터에서는 결측과 실제 구조를 먼저 구분해야 한다.
2. 원본 관측값, 기하학적 보간, AI 생성 결과를 별도 레이어와 파일로 관리해야 한다.
3. 물리·형상 prior를 사용하면 작은 데이터에서도 해석 가능한 기준선을 만들 수 있다.
4. AI 모델은 반드시 단순한 기하학 기준선과 비교해야 개선 효과를 설명할 수 있다.
5. 합성 결손 평가는 모델 성능을 측정할 수 있지만 실제 역사적 완형의 정확도를 보장하지 않는다.
6. 해시, 환경, 변환 행렬, seed를 기록해야 재현 가능한 실험이 된다.
7. 결과 전달에서는 복잡한 UI보다 비교 목적에 맞는 단순한 시각화가 더 효과적일 수 있다.
8. 신경망 예측에 회전대칭·저주파·평활 같은 domain prior를 결합하면 데이터 적합도와 구조적 타당성을 함께 제어할 수 있다.

## 9. 다음 단계

- 완형 토기 여러 개에서 결손 유형과 비율을 다양하게 합성한다.
- 포인트 단위가 아니라 유물 개체 단위로 train/validation/test를 분리한다.
- B-spline, 좌표 신경망, SymmCompletion, AdaPoinTr를 동일한 holdout에서 비교한다.
- 회전대칭·저주파·평활 제약을 하나씩 제거하는 ablation으로 각 제약의 효과를 측정한다.
- 중앙 빈 영역은 `원래 개구부 유지`와 `결손 복원` 두 가설로 나눠 제시한다.
- 관측부, 기하학 보간부, AI 생성부, 불확실성 영역을 색상과 파일로 분리한다.
- 불확실성 heatmap과 추가 촬영 방향 추천 기능을 구현한다.
- 최종적으로 수밀 메시 생성과 복제품 fit test를 통해 물리적 검증까지 확장한다.
