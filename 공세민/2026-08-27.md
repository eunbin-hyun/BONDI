# 2026-08-27 학습 정리 — AI 기반 3D 유물 복원 사례 조사

- 학습 주제: 문화유산·유물의 3D 디지털 복원에서 AI를 활용한 국내외 사례와 기술 성숙도
- 조사 범위: 파편 재조립, 점군 결손 보완, 단일 이미지 기반 3D 재현, 생성형 복원, 비파괴 가상 판독
- 조사 기준: 실제 문화유산 데이터 적용 여부, 현장 실증 수준, 전문가 검증 여부, 생성 결과의 역사적 신뢰성

## 1. 핵심 결론

AI는 이미 다음 영역에서 실질적인 성과를 내고 있다.

1. 기존 파편 사이의 접합 후보 탐색과 순위화
2. 스캔 과정에서 생긴 점군 구멍·노이즈·가림 영역 보완
3. CT 내부 구조의 분할과 가상 전개
4. 과거 사진에서 제한적인 깊이와 표면 형상 추정

반면 완전히 소실된 부분을 생성형 AI로 채우는 기술은 아직 **원형의 발견**이 아니라 **가능한 복원 가설의 생성**에 가깝다. 따라서 관측 데이터와 AI 생성 영역을 분리하고, 전문가가 근거와 불확실성을 검토하는 human-in-the-loop 구조가 필수다.

```text
정밀 스캔·사진·CT
→ 관측 데이터 기반 3D 재구성
→ AI가 접합·결손 후보와 불확실성 제시
→ 전문가 검증
→ 가상 조립·충돌 검사
→ 필요한 경우에만 가역적인 실물 개입
```

## 2. AI 3D 복원의 유형

| 유형 | AI의 역할 | 역사적 증거성 |
| --- | --- | --- |
| 파편 재조립 | 실제로 남은 파편의 접합 후보와 자세를 계산 | 비교적 높음. 다만 마모된 파단면에서는 후보가 여러 개일 수 있음 |
| 스캔 결손 보완 | 가림·노이즈로 측정하지 못한 표면을 주변 형상으로 추정 | 중간. 실물은 존재하지만 직접 측정하지 못한 영역임 |
| 소실 형상 생성 | 유사 유물·양식·사진을 학습해 없어진 형상을 생성 | 낮음. 결과는 고고학적 가설로 취급해야 함 |
| 신경 렌더링 | 여러 사진에서 자유 시점의 외관을 재현 | 관측된 외관에는 유용하지만 정밀 계측 master는 아님 |
| 가상 전개 | 3D CT 내부의 층과 문자를 비파괴적으로 분리·평탄화 | 원본 내부 구조를 관측하므로 증거성이 높음 |

## 3. 대표 사례

### 3.1 EU RePAIR — 폼페이 프레스코 파편

RePAIR는 현재 공개 근거상 가장 현장 실증에 가까운 AI 유물 재조립 사례다.

- 대상: 폼페이의 `House of the Painters at Work`와 `Schola Armaturarum` 프레스코 파편
- 입력: 파편별 고해상도 3D 형상, 색상, 표면 무늬, 고고학 메타데이터
- AI 역할: 형상·표면·문양을 분석해 접합 후보와 배치 가설을 제안
- 물리 작업: 전문가가 후보를 검증한 뒤 소프트 그리퍼가 달린 양팔 로봇이 파편을 이동·배치
- 성과: 디지털화, AI 매칭, 전문가 검증, 로봇 보조를 실제 문화유산 환경에서 통합 실증

다만 수천 개의 파편을 AI가 완전히 무인 복원한 것은 아니다. 침식, 유사한 무늬, 유실 파편 때문에 전문가의 오류 수정과 감독이 계속 필요하다.

### 3.2 SPPD — 진시황릉 병마용 파편 재조립

SPPD는 실물 병마용 파편의 3D 파단면을 이용한 딥러닝 기반 매칭 사례다.

- `SiamesePointNet`: 두 파단면 점군이 서로 맞는지 유사도 계산
- `PCA + Deep Closest Point`: 파편의 초기 자세와 정밀 정합 계산
- 2,048점 입력 조건의 분류 정확도: 약 96.6%
- 360개 정합 쌍 실험의 정합 성공률: 53.89%
- 49개 실물 파편에서는 7개 중간 조립체를 생성했으나 9개 파편은 수작업이 필요

분류 정확도와 실제 조립 성공률 사이에 큰 차이가 있다는 점이 중요하다. 파단면이 심하게 손상됐거나 부분적으로 비슷하면 높은 분류 성능만으로 실제 복원 성공을 보장할 수 없다.

### 3.3 보로부두르 사원 숨은 부조

보로부두르 사원의 일부 부조는 구조 보강 과정에서 돌벽 뒤에 가려졌고 1890년대의 단일 흑백사진만 남아 있다.

- 입력: 숨은 부조의 단일 흑백사진
- AI 역할: soft-edge 정보를 이용한 CNN으로 픽셀별 깊이 추정
- 출력: 부조의 3D 점군
- 활용: 현재 보이는 사원 영역의 3D 스캔, 기초 CAD 데이터와 결합한 투시 시각화
- 보고 성능: 현재 관측 가능한 유사 부조 검증 데이터에서 약 97% 재구성 정확도

그러나 97%는 숨은 부조 자체의 정확도가 아니다. 실제 숨은 부조는 현재 측정할 수 없어 ground truth가 없기 때문에 최종 결과는 검증된 측정값이 아니라 학습된 형상 추정이다.

### 3.4 고운사 가운루·연수전 디지털 재현

2025년 경북 의성 산불로 소실된 고운사 가운루와 연수전을 시민 기록사진으로 재현한 국내 사례다.

- 입력: 전문 실측 자료가 아닌 개인 기록사진
- 모델: 생성형 Image-to-3D 모델 `TRELLIS.2`
- 후처리·검토: Blender와 Google Earth Pro
- 의의: 정밀 스캔이 남아 있지 않은 재난 문화유산도 시민 기록을 기반으로 3D 아카이브화할 수 있음을 확인

단일 사진에서 보이지 않는 면을 추론하므로 구조 왜곡과 비례 불균형이 발생했다. 연구도 이 결과를 물리적 복원의 대체재가 아니라 기억·전시·시민 참여형 아카이빙을 위한 보완 자료로 평가한다.

### 3.5 CPDC-MFNet — 병마용 점군 결손 생성

조건부 확산모델을 이용해 불완전한 병마용 점군에서 팔·몸통·다리의 결손 좌표를 생성한 연구다.

- 데이터: 0.05 mm 해상도로 스캔한 병마용 78점
- 학습 방식: 완전한 스캔에서 5~20%를 인위적으로 제거해 결손 데이터 생성
- AI 역할: 불완전 점군을 조건으로 완전한 점군 후보 생성
- 성과: 확산 단계의 샘플 수를 5분의 1로 줄이면서 경쟁력 있는 복원 성능 유지

실측 유물을 사용했지만 평가용 결손은 인공적으로 만든 것이다. 따라서 모델이 실제로 사라진 역사적 형상을 정확히 복원했다기보다, 학습 분포 안에서 그럴듯한 완형을 생성했다고 해석해야 한다.

### 3.6 IberianVoxel — 이베리아 도자기 완형 생성

IberianVoxel은 작은 도편에서 완전한 토기 형태를 생성하는 3D Autoencoder-GAN 연구다.

- 데이터: 이베리아 회전성형 토기 프로파일 기반 3D 복셀 모델 1,001개
- 입력: 크기별로 인공 파손한 토기 복셀
- 출력: 전체 토기 형상
- 검증: 정량 지표와 이베리아 문화유산 전문가 평가를 함께 사용

대규모 유물 전용 생성 데이터셋과 전문가 평가를 결합했다는 의미가 있다. 하지만 실제 발굴 파편이 아니라 완형 프로파일에서 만든 합성 파편이고, 낮은 복셀 해상도와 비대칭·접합부 오류가 남아 있다.

### 3.7 Oltenia Museum 도자기 — Stable Diffusion + NeRF

루마니아 Oltenia Museum의 손상 도자기에서 생성형 이미지 복원과 신경 렌더링을 결합했다.

- Stable Diffusion: 여러 시점 이미지의 결손부를 semantic inpainting
- NeRF: 복원된 다중 시점 이미지로 자유 시점의 3D 시각물 생성
- 결과: 박물관 디지털 전시용 회전 영상과 사실적인 3D 대리물

소실부의 실제 정답이 없으므로 결과는 논문 표현대로 현실적이고 개연성 있는 `surrogate`다. 전시·교육에는 유용하지만 학술적 고증이나 실물 복원의 직접 근거로 사용하면 안 된다.

### 3.8 Vesuvius Challenge — 헤르쿨라네움 두루마리

탄화되어 펼칠 수 없는 고대 두루마리를 3D X선 CT와 AI로 읽는 비파괴 가상복원 사례다.

- 3D CT: 두루마리 내부를 voxel volume으로 촬영
- geometry processing: 종이층 분할, 메시 생성, 평탄화
- 머신러닝: 탄소 잉크가 남긴 미세한 표면 차이를 탐지
- 성과: 두루마리를 물리적으로 펼치지 않고 고대 그리스어 문장을 판독

2026년에는 `PHerc. 1667`의 현존 부분 전체에서 약 1.5 m, 20개 열의 텍스트를 가상 전개했고, Oxford의 `PHerc. 172`에서도 70개 이상의 열을 복원했다. 다만 종이층이 밀착되거나 찢어진 구간의 분할은 아직 반자동이다.

## 4. 국내 기술 동향

### 한국 문화유물의 3D Gaussian Splatting 기록

국내 연구진은 DUSt3R, SAM2, 3D Gaussian Splatting을 결합해 박물관 유물의 정렬 오류와 복잡한 배경을 줄이고 고품질 3D 기록을 만드는 방법을 연구했다.

이 방법은 관측된 유물의 디지털 기록과 자유 시점 시각화에는 유용하지만, 사라진 역사적 형상을 자동으로 복원하는 기술은 아니다. 특히 3DGS 결과를 보존용 정밀 메시나 치수 측정 기준으로 바로 사용하는 것은 주의해야 한다.

### 훼손 도자기 원형복원 시뮬레이션 R&D

KAIST, KIST 등은 3D 스캔 점군과 지능형 매칭을 이용해 훼손 도자기의 파편 분류, 가상 접합, 전체 배치 최적화, 3D 출력까지 연결하는 국가 R&D를 수행했다.

연구 논문, 특허, 시제품은 확인되지만 공개 자료만으로는 박물관 현장의 상시 운영이나 완전 자동 복원 성능이 충분히 검증됐다고 보기 어렵다. 따라서 상용 서비스보다는 정부 연구시제품으로 분류하는 것이 적절하다.

## 5. 기술별 성숙도 판단

| 기술 | 현재 수준 | 적합한 활용 |
| --- | --- | --- |
| 3D 파단면 매칭 | 현장실증·연구시제품 | 후보 쌍 축소, 전문가 접합 판단 지원 |
| 점군 hole filling | 연구시제품 | 스캐너 가림과 작은 표면 구멍 보완 |
| 단일 이미지 깊이 추정 | 제한적 적용 | 부조처럼 깊이 변화가 작고 정면성이 강한 대상 |
| 생성형 3D completion | 연구 단계 | 전시용 복원 가설, 복수 후보 제시 |
| NeRF·3DGS | 기록·전시 활용 단계 | 자유 시점 시각화와 빠른 디지털 아카이빙 |
| CT 가상 전개·잉크 탐지 | 실제 성과 확인 | 펼칠 수 없는 문서의 비파괴 판독 |
| AI+로봇 물리 조립 | 현장 통합실증 초기 | 전문가 감독 아래 반복적인 이동·배치 지원 |

## 6. 복원 결과 관리 원칙

문화유산 복원에서는 다음 데이터를 별도 레이어와 파일로 유지해야 한다.

1. 원본 사진·스캔·CT와 메타데이터
2. 측정값만으로 구성된 관측 모델
3. 전통적인 기하 보간 영역
4. AI가 생성한 결손 영역
5. 전문가가 수정·승인한 영역
6. 각 후보의 불확실도와 참고 근거

AI 생성 영역은 원본 관측값과 다른 색상·재질로 표시하고, 모델명, 버전, 학습 데이터, seed, 프롬프트, 변환 행렬을 기록해야 한다. 이는 문화유산 디지털 시각화의 출처와 방법을 문서화하도록 요구하는 London Charter의 원칙과도 부합한다.

## 7. 주의해야 할 용어

- 3D 스캐닝과 사진측량은 데이터 취득 기술이며 그 자체로 AI가 아니다.
- ICP, PCA 기반 정합과 일반적인 mesh hole filling도 자동화 기술이지만 반드시 AI인 것은 아니다.
- NeRF와 3D Gaussian Splatting은 관측된 사진 사이의 새로운 시점을 합성하는 학습 기반 표현이다.
- NeRF·3DGS가 보이지 않는 역사적 형상을 자동으로 고증하는 것은 아니다.
- Stable Diffusion, GAN, 확산 기반 point completion처럼 학습된 분포에서 결손을 생성할 때 환각 위험이 커진다.

## 8. 배운 점

1. 가장 신뢰도 높은 AI 활용은 존재하는 파편과 내부 구조의 탐색·정렬을 돕는 것이다.
2. 생성형 AI 결과는 단일 정답보다 복수의 후보와 불확실성으로 제시해야 한다.
3. 높은 benchmark 정확도가 실제 현장 조립 성공률을 보장하지 않는다.
4. 스캔 누락 보완과 역사적 결손 복원은 목적과 검증 기준이 다르다.
5. 전문가 승인 과정이 포함되지 않은 완전 자동 복원은 현재 보존 실무에 적용하기 어렵다.
6. 전시용 시각화 모델과 학술·보존용 계측 모델은 별도로 관리해야 한다.
7. 원본, 알고리즘 보완, 생성 영역의 provenance를 기록해야 결과를 재평가할 수 있다.
