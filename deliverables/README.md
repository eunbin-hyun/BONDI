## 내려받기

GitHub 웹에서는 각 파일을 열어 내려받을 수 있습니다. 저장소를 복제한 경우 Git LFS가 설치되어 있어야 실제 바이너리를 받을 수 있습니다.

```bash
git lfs install
git lfs pull
```

LFS를 사용하지 않으면 파일 대신 작은 포인터 텍스트만 내려받아질 수 있습니다.
