# 이미지 유도형 3D 패칭 개관

> 문서 상태: 2026-09-16 감사 중인 연구 기록
> 현재 결과는 최종 복원이나 사람 검토 승인 후보로 확정되지 않았다. canonical/base는 수정하지 않았다.

## 한 줄 정의

**이미지 유도형 3D 패칭(image-guided donor grafting)**은 사진에서 결손의 위치와 보이는 윤곽을
정하고, 여러 3D 생성 결과에서 가져온 조각을 그 위치에 제한적으로 배치·변형한 뒤 원본 메시와의
교차, 위상 안전성, 고정 카메라에서의 투영을 검사하는 복원 후보 생성 방식이다.

사진 픽셀만으로 새로운 3D 형상을 직접 만드는 방식은 아니다. 사진은 **어디를 고칠지와 화면에서
어떻게 보여야 하는지**를 제공하고, 패치의 깊이와 입체 형상은 TRELLIS donor 메시에서 가져온다.

## 왜 이 방식을 사용했는가

TRELLIS가 생성한 전체 모델은 사진의 전체 외형은 비슷해도 국소 파단면, 능선 개수, 깊이가 맞지
않을 수 있다. 전체 모델을 재생성하거나 통째로 교체하면 이미 쓸 수 있는 부분까지 바뀐다.

따라서 다음 원칙을 사용했다.

1. 기존 base 메시와 canonical 파일은 그대로 보존한다.
2. 사진에서 문제가 보이는 영역만 작업 대상으로 제한한다.
3. 여러 TRELLIS seed에서 관련 조각만 추출한다.
4. 조각별 위치와 경계를 제한된 예산 안에서 조정한다.
5. 원본 침범, 자기 교차, 잘못된 위상이나 화면 이탈이 있는 후보는 기각한다.
6. 자동 검사를 통과해도 사람의 사진 오버레이 검토 전에는 채택하지 않는다.

## ROI 용어를 구분해서 사용한다

ROI는 `Region of Interest`, 즉 작업 대상으로 지정한 관심 영역이다. 이번 기록에서는 서로 다른
단위를 모두 ROI라고 부르면서 혼동이 생겼으므로 다음처럼 구분한다.

| 용어 | 의미 | 주의점 |
|---|---|---|
| 2D ROI | 사진에서 지정한 픽셀 영역 | 카메라가 바뀌면 대응 3D 영역도 바뀜 |
| removed face component | removed face의 연결 성분 | 연결 성분 하나가 물리적 결손 하나라는 뜻은 아님 |
| macro-ROI | 여러 face component를 하나의 물리적 작업 영역으로 묶은 후보 | 병합 임계값에 민감하므로 안정성 검사가 필요 |
| current ROI footprint | 현재 패치가 들어가도록 허용한 removed face 집합 | 전체 removed 영역을 자동 허용하면 안 됨 |

```text
사진의 결손 영역
        ↓ 고정 카메라 투영
2D ROI
        ↓ base partition과 대응
현재 ROI의 removed footprint
        ↓ donor 추출·제한 변형
패치 draft
```

ROI는 LLM이나 자동 스크립트가 정상 영역까지 건드리지 못하도록 제한하는 작업 울타리다. 다만
connected component 수를 그대로 물리적 결손 수로 해석해서는 안 된다.

## 입력과 역할

### 사진과 고정 카메라

- 결손이 보이는 위치와 화면상 윤곽을 제공한다.
- 모든 후보를 같은 카메라에서 비교한다.
- 후보마다 카메라를 다시 맞춰 나쁜 후보를 좋아 보이게 만드는 일을 금지한다.
- 현재 71489 카메라는 고정해 재사용하고 있지만 `DRAFT`이며 `VALIDATED`가 아니다.

### TRELLIS donor

- 패치의 3D 표면과 깊이 후보를 제공한다.
- seed마다 형상이 다르므로 여러 seed를 비교한다.
- 전체 생성 모델을 채택하지 않고 연결 컴포넌트 단위로 잘라 쓴다.

### Base 메시와 partition

현재 71489에서 복원한 face partition은 다음과 같다.

- 전체 base: 248,938 faces
- retained: 245,760 faces
- removed footprint: 3,178 faces

`retained`는 패치가 침범하면 안 되는 표면이다. `removed`는 과거 base에서 교체 대상으로 분류한
face 집합이지만, 현재 패치가 전체 removed 영역 어디에나 들어가도 된다는 허가는 아니다.

### 안전검사 코드

- LLM이나 렌더의 육안 판단을 기하학적으로 검산한다.
- 정확한 triangle SAT, triangle AABB broad phase, boundary loop, connected component,
  self-intersection 검사를 사용한다.
- 수치 검사를 통과했다는 사실과 고고학적으로 맞는 복원이라는 판단을 분리한다.

## 처리 단계

### 1. 카메라와 작업 영역 고정

고정 카메라에서 사진 ROI, base의 removed footprint, donor 후보가 같은 위치를 가리키는지 먼저
검증한다. glTF Y-up과 Blender Z-up 변환도 이 단계에서 명시적으로 확인한다.

### 2. 후보 추출과 독립 정합

seed01/03/06/07을 base의 공유축에 정렬한 뒤 후보 컴포넌트를 추출한다. 각 후보는 공통 이동값이
아니라 독립적인 theta/slide를 사용하며 trial마다 대응점을 다시 계산한다.

### 3. Topology-clean trim

현재 footprint에 들어오는 면을 선택하고 BFS로 연결성을 유지한다. 경계 정점 degree가 2가 아닌
지점은 국소 복구한다. 선택한 source face 수와 export face 수가 같은지도 검사한다.

### 4. 제한 conform

패치 내부 전체를 자유롭게 스컬프하지 않는다. 경계와 좁은 collar만 변형하고 retained 교차가 다시
생기지 않는 범위에서만 이동한다. 안전 예산 안의 변형이 육안상 아무 효과가 없으면 수치 통과와
별개로 시각적 미해결로 기록한다.

### 5. 안전 게이트

다음 항목을 분리해 검사한다.

- retained intersection = 0
- protected/veto on retained = 0
- current ROI footprint 밖 교차 = 0
- patch-to-patch intersection = 0
- self-intersection = 0
- 단일 컴포넌트와 폐합 경계
- 고정 카메라의 실제 depth render에서 patch 투영과 coverage가 유효함

removed footprint 위의 과거 protected/veto 태그는
`REMOVED_REGION_MASK_OVERLAP_REVIEW`로 남기되 retained 충돌과 섞지 않는다.

### 6. 사람 시각 검토

수치가 모두 통과해도 떠 있는 판, 가느다란 spike, 비정상적인 깊이처럼 보이면 채택하지 않는다.
사진 오버레이, depth-shaded seam close-up, target/patch mask를 함께 본다.

## 71489의 현재 감사 상태

### Step K seed01 3-patch draft

이전 자동 검사에서는 다음 결과가 나왔다.

- depth-aware coverage: 8.73% → 10.74%
- overflow proxy: 500px → 305px
- retained intersection: 0
- patch-to-patch intersection: 0
- self-intersection: 0

당시에는 `SAFE_PATCH_SET_CANDIDATE_READY_FOR_HUMAN_REVIEW`로 기록했지만, 후속 정책 매핑에서
이 상태를 철회했다. rank1·rank2가 `roi-002`와 교차한다는 것은 확인됐으나, 기존 계산은
`roi-002`의 대표 segment 라벨을 교차 face 전체에 적용했고 패치 전체가 아니라 교차한 일부 face만
분류했다. 따라서 “100% junction 정책 위반”도 아직 확정할 수 없다.

현재 상태는 다음과 같다.

`HUMAN_REVIEW_HOLD_PENDING_FACE_LEVEL_POLICY_REMAP`

필요한 후속 검사는 교차한 base face 각각의 segment 분류, 모든 patch triangle의 closest-surface
지원 영역, 면적 가중 segment 비율과 unsupported 비율 계산이다.

### 56개 connected component와 macro-ROI

removed 3,178 faces는 56개 connected face component로 나뉜다. 이것을 56개의 독립된 물리적
결손으로 해석한 1차 배치 분류는 폐기한다.

후속 single-link 클러스터링에서는 55개 component가 macro-000, `roi-011` 하나가 macro-001로
묶였다. 그러나 병합 조건이 `d_close = median edge × 8`, `d_far = median edge × 25`이며 retained
collar face 하나만 공유해도 병합되므로 연쇄 병합 가능성이 있다. 임계값을 바꾼 민감도 검사와
색상 구분 렌더 전에는 “물리적 결손이 정확히 두 개”라고 확정하지 않는다.

현재 상태는 다음과 같다.

`PENDING_CLUSTER_SENSITIVITY_REVIEW`

### macro-001 seed06 후보

fresh-fit에서 retained/self-intersection 검사를 통과한 189-face 후보가 하나 남았지만, 선택된 후보의
기록은 `patch_px = 0`, coverage 0이다. 같은 실행에서 화면 bbox 좌표계 불일치가 확인됐고 실제
Blender fixed-camera depth render는 만들지 않았다. 그러므로 coverage 0을 시각적 실패로 확정할 수
없다.

현재 상태는 다음과 같다.

`PROJECTION_INVALID_OR_OFF_TARGET_PENDING_FIXED_CAMERA_RENDER`

### 전체 판정

현재 확정 가능한 전체 상태는 다음과 같다.

`PARTIAL_REUSED_CANDIDATE_SCREEN_ONLY`

현재 `SAFE_PATCH_SET_CANDIDATE_READY_FOR_HUMAN_REVIEW`로 확정된 신규 후보는 없다. weld, bridge,
boolean, canonical 채택은 수행하지 않았다.

## Blender MCP와 LLM을 붙일 경우

MCP는 복원 알고리즘이 아니라 LLM이 Blender를 조작할 수 있게 하는 인터페이스다.

```text
LLM의 판단
  ↓
MCP 명령
  ↓
Blender 선택·제한 스컬프·bridge preview
  ↓
렌더와 메시 상태 반환
  ↓
외부 안전검사로 재검산
```

권장 역할 분담은 다음과 같다.

- 자동 파이프라인: 후보 추출, 정합, trim, 교차·위상 검사
- MCP + LLM: 통과한 소수 후보의 비정형 seam과 국소 스컬프 preview
- 외부 검사기: MCP 수정 결과의 retained 교차, non-manifold, 뒤집힌 normal,
  self-intersection, 고정 카메라 투영 검증
- 사람: 고고학적 타당성 및 최종 채택 결정

즉, **LLM은 작업자, MCP는 손, Blender는 작업대, 안전검사 파이프라인은 자와 보호장치**다.

## 이 방식이 할 수 없는 것

1. 단일 사진에서 보이지 않는 뒤쪽 깊이를 정확히 결정할 수 없다.
2. donor에 없는 형상을 자동으로 발명해 정확한 복원이라고 주장할 수 없다.
3. coverage가 높다는 이유만으로 고고학적으로 맞는 복원임을 증명할 수 없다.
4. openwork 다리처럼 높이마다 구조가 달라지는 부위에 단순 회전 프로파일이나 동일 패칭 규칙을
   그대로 적용할 수 없다.
5. 숫자상 안전한 패치가 시각적으로도 자연스럽다고 보장할 수 없다.
6. 최종 weld/bridge에는 별도 승인과 수정 후 안전검사가 필요하다.

## 현재 결론

이 연구가 확정한 것은 **사진·고정 카메라·3D donor·base partition을 함께 사용해 국소 패치 후보를
만들고 기하학적으로 기각하는 절차**다. 특정 Step K 패치나 macro-ROI 구성을 최종 복원으로 확정한
것은 아니다.

다음 판단은 face-level 정책 재매핑, macro 클러스터 민감도 검사, macro-001 fixed-camera Blender
렌더가 끝난 뒤 갱신한다. 그 전까지 canonical/base와 기존 draft GLB는 수정하지 않는다.
