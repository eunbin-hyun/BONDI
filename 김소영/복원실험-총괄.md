# 유물 복원 실험 총괄 — 무엇을 해봤고, 무엇을 이어갈 것인가

> 2026-09-11 기록 확인 기준. **상세 실험 보고서가 아니라 결과·이미지·후속 작업을 연결하는 총괄 목차**다. 기존 문서·코드·이미지는 수정하지 않았다. 이번 요청의 ‘지금까지 실험’에 맞춰 기존 STUDY 기록과 미커밋 후속 실험을 함께 다룬다. 이 문서 자체는 신규 작성이며 커밋·푸시하지 않았다.

## 읽는 순서

**연구 계열·유물별로 묶고 → 각 묶음 안에서 시간순**으로 읽는다. 날짜만으로 나열하면 서로 다른 유물의 점수를 같은 실험으로 오해하기 쉽기 때문이다.

**읽을 때 지킬 구분**

- ‘원본 보존’의 원본은 대부분 **TRELLIS가 사진에서 만든 입력 메시**다. 실측 3D 원본이라는 뜻이 아니다.
- **보기 좋아짐 / 축 교란에 안정적 / 실제 유물과 정확함**은 서로 다른 결과다. 마지막 항목은 아직 검증되지 않았다.
- ‘보존’, ‘기각’, ‘보류’는 해당 실험의 처리 상태다. 프로젝트 전체의 성공·실패 판정이 아니다.
- 표의 수치는 연결한 기록의 요약이다. 이번 문서 작성에서 모든 실험을 다시 실행하거나 해시를 재검증하지는 않았다.
- 날짜는 명시된 실행·기록 날짜를 우선한다. 정확한 날짜가 없는 실험은 Phase 순서만 사용한다. 파일 수정 시각을 실험 시각으로 단정하지 않는다.

## 3. A — 참고유물 검색·형상 예측

대상은 [참고유물 실험][ref-doc]의 내부 ID `11`, `08`, `15H` 등이다. **71489와 같은 개체라고 연결하지 않는다.** 이 계열은 ‘내 유물의 잔존면을 잇기’가 아니라 ‘다른 유물의 형상이 빈 부분을 제약하는가’를 묻는다.

| 순서 | 실험 | 결과 / 기록 수치 | 판단·남길 것 |
|---|---|---|---|
| A1 · Phase 0 | 18점 사진의 raw / foreground / silhouette 검색 | 색·사진 톤과 형태 검색이 다름. raw↔silhouette 상관 −0.02 | 사진 유사도를 기하 적합성으로 쓰지 않음 |
| A2 · Phase 0.5→1A | 투창을 외곽 마스크에서 제외, 몸통·굽·높이 따로 검색 | 굽 검색의 형식 일관성 개선. 파손 질의는 마스크에 민감 | 단일 통합 순위 대신 축별 후보 목록 |
| A3 · 3D 대조 | 5점 TRELLIS 생성·정렬·부위/근거 태깅 | 질의 `11`과 후보 굽각·몸통 폭 불일치, 기하 게이트 통과 0개 | 이 코퍼스의 직접 기하 기증자 사용 기각 |
| A4 · 비파괴 패치 | `11` / `08` 잔존 경계에서 별도 패치 | `11`은 얇은 crown, `08`은 상부 대부분 추정. 직접 donor mesh 미사용 | 파이프라인 시연. 참고 기하의 기여는 입증 못 함 |
| A5 · 소규모 LOO | 평균·최근접·PCA·선형 연장, 엄격 자격 5점 | PCA RMSE 0.085 vs 평균 0.087, rim·band 결과는 불리 | PCA 우위 근거 없음. 작은 표본의 예비 결과 |
| A6 · 실제 대상 baseline | `08` / `15H`에 최근접 Top-3 적용 | 상부 편차 0.144 / 0.112, 참고 선택에 민감 | 단일 정답처럼 출력하지 않음 |
| A7 · 확장 코퍼스 | prior 39점, 잠근 테스트 12점, 합성 상부 절제 | **uniform kNN-5 RMSE 0.0698**, 전역평균 0.135 대비 약 48% 감소 | 이 계열의 기준 방법. 사진 프로파일 내부 평가에 한정 |
| A8 · 복잡한 결합 비교 | 밴드 투표·잔차 전이·softmax·2-cluster | 균등 kNN 대비 견고한 추가 이득 없음. post-hoc 최적값은 확증 결과와 분리 | 복잡성 추가 보류 |
| A9 · 실제 `08` / `15H` 적용 | uniform kNN-5 상부 + 이웃의 10–90% 폭 | 결손부 폭 0.134 / 0.123, 상부 형상 불일치 | 보정 안 된 **축대칭 외피 가설**로 보관 |

수치의 단위는 원문 정의를 따른다. A5–A9의 정규화 프로파일 오차를 mm, 3D Chamfer 또는 71489 복원 정확도로 바꾸어 읽지 않는다.

## 5. C — 굽다리바리 71489: 부위별로 살리기

이 절은 **진행 순서와 갈림길만** 기록한다. `local_bracket` 상세 수치·축 강건성·아티팩트 분석은 작성 중인 [굽다리바리 부위별 라우팅][pedestal-doc] §5–8을 기준 링크로 둔다. 별도 후속 MD가 확정되면 이 링크만 갱신한다. 현재 문서의 상세 내용을 복제하거나 덮어쓰지 않는다.

| 순서 / 시점 | 실험 | 관찰 결과 | 처리 상태 |
|---|---|---|---|
| C1 · 선행 | 전역 회전 프로파일 / 원통 미관측 셀 채움 | 복합 그릇·대·굽과 의도적 투창을 한 규칙으로 처리하기 어려움 | 기존 partial candidate를 완성본으로 승계하지 않음 |

## 7. 어떻게 이어갈까

**우선순위는 ‘71489 원본 보존 + 눈에 보이는 실제 개선’이다.** 합성·새 모델·참고 검색을 다시 확장하기 전에 현재 패치의 원인을 좁힌다.

| 순서 | 다음 작업 | 끝났다고 할 기준 | 안 풀릴 때 |
|---|---|---|---|
| 1 · 체크포인트 | 입력·후보·축·설정·렌더·민감도 기록 연결, 채택/기각 표시 | 최신 상세 MD에서 정확한 후보를 다시 열 수 있음 | 후보 이름·해시부터 정리, 새 실험 추가 보류 |
| 2 · 원인 확인 | 좌하단 혹을 지나는 **수직 단면**에 carried 외벽·선택 도너·패치 중첩 | 보간 문제인지, 잘못된 도너/내외벽/구간 문제인지 구분 | 원인이 불명확하면 수직 arc를 해결책으로 단정하지 않음 |
| 3 · 하나씩 개선 | 원인에 맞춰 수직 보간 또는 도너 제한 한 항목만 변경 | 같은 bracket·격자·축에서 돌출 감소, 원본 불변 | 효과 없으면 그 변경 기각. 여러 토글 동시 변경 금지 |
| 4 · 경계 정리 | filled 경계만 투영·평활, 정확 점-삼각형 거리 측정 | 시각적 틈·계단 감소, 교차/겹침 증가 없음, 원본 좌표·면·재질 유지 | carried를 깎아 해결하지 않음. 패치 범위 축소 검토 |
| 5 · 후보 채택 | front/side/rear/close-up + 교란 전후 + provenance 비교 | 형태 개선과 보존·안정성이 함께 확인됨 | 90–110°도 자동 채택하지 않고 중간 후보로 남김 |
| 별도 후속 · 투창/받침 | 카메라 정합·개구부 근거·음성 대조 확보 | 의도적 개구부 보호와 불확실 셀 기권 확인 | 현 veto 유지. 손상 받침 복원을 별도 설계 |
| 별도 후속 · 정확도 | 사용 가능한 실측 스캔·이용조건·축/ROI 확정 후 합성 손상 평가 | 제거 영역 오차 + 의도적 개구부 false fill + 고정/재추정 축 비교 | TRELLIS 내부 실험으로 대체하면 반드시 proxy라고 표기 |

계속 보류할 것: N-fold 검출기 확장, 근거 없는 구연부/받침 완성, 새 참고 코퍼스 대량 수집. A의 kNN 외피를 C의 국소 패치와 섞으려면 먼저 역할을 ‘외피 가설’로 분리해야 하며, 실물 복원 정답처럼 붙이지 않는다.

### 재개할 때 전달할 짧은 요청

> 71489 local_bracket의 최신 후보와 원본을 열고, 좌하단 혹의 수직 단면부터 진단한다. carried는 변경하지 않는다. 도너·외벽·패치의 관계를 그림으로 보여주고, 원인을 확인한 뒤 한 가지 수정만 비교한다. 현재 전용 MD의 실험을 중복 실행하거나 다른 유물의 축을 가져오지 않는다. 최종 채택은 같은 시점 이미지, 원본 보존, 경계 거리, 교란 민감도를 함께 보고 결정한다.
