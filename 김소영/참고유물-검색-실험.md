# 참고유물 검색 실험 — 손상 굽다리바리 복원에 기존 유물이 쓸모 있나

**질문**: 손상 유물 1점을 넣으면, 복원에 참고할 만한 유물과 그 근거를 3D로 보여줄 수 있나.

**결과**: 사진 검색 → 3D 생성 → 기하 대조 → 비파괴 패치까지 파이프라인은 작동한다.
그러나 이 18점 코퍼스는 두 손상 질의(`11`, `08`)의 **기하 기증자로 쓸 수 없었다. 순기여 ≈ 0.**

## 8. 제약된 프로파일 앙상블 — leave-one-out 검증 (불합격)

논문 조사 후 방향 전환: 범용 3D 완성 모델 대신, 토기 축대칭성을 이용한 **1D 프로파일 posterior**.

- **prior** : 근완형 11점(`mostly_present`)의 2D generatrix 프로파일 (마스크 v2, 좌우 대칭화, `r/rMax`)
- **모델** : plain PCA (분산 mode1 52% / mode2 28% / mode3 15%)
- **채움** : 관측 빈 조건부 linear-Gaussian posterior (관측잡음 R>0), 10–90% 해석적 band
- **정답 (엄격)** : 상부 40% 좌우 실루엣 차 < 0.08 **AND** mask-sweep sd < 0.05, 같은 형식(발).
  자격 = `03 04 10 13 17H` (5점). `00`(고리형 부착물)·`16`(비대칭 0.11) 등은 정답 미달 → 첫 시도의
  검증셋(13/16/04/00)은 부분 오염이었음.
- **한계** : n=5 → **정확도 보정 아님, feasibility 예비 실험.**

![프로파일](images/ref-retrieval/pe-profiles.png)

**결과** (엄격 정답 5점 LOO, m=3, 낮을수록 좋음 / 적중률 높을수록 좋음):

| 방법 | 결손빈 적중률 | RMSE (r/rMax) | rim 오차 | 배부름 위치 오차 |
|---|---|---|---|---|
| 평균 프로파일 | **0.96** | 0.087 | **0.135** | **0.031** |
| 최근접 단일 프로파일 | 0.87 | 0.090 | 0.137 | 0.033 |
| PCA posterior | 0.60 | **0.085** | 0.154 | 0.034 |
| 선형 연장 | 0.15 | 0.347 | 0.848 | 0.236 |

**PCA posterior가 평균·최근접을 못 이김.** RMSE 차이(0.085 vs 0.087)는 n=5 노이즈, rim 오차는 오히려
더 나쁨, band는 여전히 과신(적중률 0.60). **가장 좋은 것은 그냥 "평균 프로파일".**
m=2/3/4 모두 같은 방향. 원인: prior 곡선 11개가 너무 적고 이질적.

**feasibility 판정**: 완전히 가망 없진 않음(RMSE ~0.085 = 상부 반경 8.5% 오차, 쓰레기는 아님).
그러나 **정교한 방법이 평균보다 나은 게 없음.** 코퍼스를 확장한다면 확장할 방법은 "맞는 하위형식의
평균/최근접 프로파일"(단순)이지 PCA posterior가 아님. 그마저도 **잠근 테스트셋 + 실제 보정** 전에는
정확도 주장 불가.

## 9. 최근접 프로파일 baseline — `08`/`15H` 적용 (부록, 1회)

§8에서 지지 못 얻은 방법(최근접, 관측 빈 고정)이 실제 대상에서 뭘 내는지만 시연. 복원 아님.

- 결손 구간 출처 : `08` = 3D 스테이징 섹터별 파단(평균 61% 잔존), `15H` = 완전도 라벨(상부 약 2/7 잔존)
- 관측 빈 원본 유지, 결손 빈만 최근접 프로파일, 접합부 짧은 taper, 별도 객체
- `geometryStatus: uncalibrated_nearest_profile_baseline`
- Top-1이 아니라 **Top-3를 따로** 출력 (선택 민감도 확인)

![baseline](images/ref-retrieval/pe-baselineB.png)
(검은 점 = 관측 하부, 색선 = Top-3 후보별 상부 복원)

| 대상 | 결손 | Top-3 (관측부 거의 동률) | Top-3 상부 편차 | 판정 |
|---|---|---|---|---|
| `08` | 40% | `00` / `10` / `03` | **0.144** | **참고 선택 불안정** |

## 10. 부분 매칭 재검토 — 단순 균등 혼합 vs 학습 결합 (확장 코퍼스 A′)

§8이 "정교한 방법이 평균을 못 이긴다"로 끝났으나, 그때 비교한 것은 **전체 곡선을 하나의 blob으로**
본 것이었다. "하부가 닮은 참고 A, 상부가 닮은 참고 B"를 부분별로 나눠 보면 다른가 — 를 확인한다.

**코퍼스**: 경주박물관 e뮤지엄 굽다리바리 스크레이프 → A/B/C 등급(§9 grades.json 방식) →
prior 39점(A 9 + B 19 + batch1 11), GT 후보 A+B 28점. **잠근 테스트 12점**(개발 중 절대 미사용),
개발 16점. 유물당 n=1 (topcut 25/30/40% 평균). GT 유물은 자기 prior에서 제외.
합성 상부 절제 실험이며 실제 파편 복원 정확도가 아니다.

### 10.1 게이트 — 하부가 상부를 예측하나 (`profile_partwise.py`)

| | RMSE (상부 결손 구간) |
|---|---|
| 전역 상부 평균 (baseline) | 0.142 |
| 오라클 (참 상부로 kNN) | 0.045 |
| 하부 전체 최근접 kNN-5 | 0.098 |
| 밴드별 가중 결합 (6 fine + 3 coarse) | 0.100 |

- 모든 밴드 Spearman(하부거리, 상부거리) `0.43–0.62` — **어느 띠든 대체로 같은 "전체 폭·벌어짐"을
  반복 측정.** 독립적 형식 특징을 보는 밴드가 없음.
- 곡률항(raw `r″`) γ=0 과 γ=1 동급 → GrabCut 외곽선의 2차 미분은 마스크 노이즈에 지배됨. 폐기.
- 밴드 가중 결합(0.100)이 단순 하부 최근접(0.098)을 **못 이김** — 약한 밴드를 섞어 희석.

→ 하부→상부 예측 신호는 있으나(전역평균 대비 개선), **밴드 투표 구조는 이득 없음.**

### 10.2 잔차 전이 — 실패 (`profile_residual_transfer.py`)

`r̂_q(h) = L_q(h) + Σ wⱼ·Δrⱼ(h)`, `Δrⱼ` = 후보 실제상부 − 후보 자기 선형연장.

| 거리 변형 | recall@5 | recall@10 |
|---|---|---|
| d_raw (관측 r) | 0.48 | 0.54 |
| d_seam (r − r[seam]) | 0.44 | 0.50 |
| d_seamslope (추세 제거) | 0.19 | 0.46 |

- **seam 정규화가 검색을 악화**시킴 — 오프셋·기울기를 빼면 진짜 형식 정보도 같이 버려짐.
- 옳은 상부가 하부 Top-5에 있는 경우가 **절반뿐**, 46%는 Top-10에도 없음.
- 실패 원인: 선형 연장 `L`이 이 기종 backbone으로 최악(linext 단독 RMSE `0.327`, rimErr `0.760` —
  굽다리바리는 구연부에서 급격히 벌어지거나 닫혀 직선이 크게 오버슛). 나쁜 backbone 위 잔차는
  이웃의 자기 곡률을 그대로 쓰는 것보다 나쁨.

### 10.3 확증 결과 — 사전등록 주 방법

**`uniform kNN-5` (seam 고정)**: 하부 관측 곡선으로 raw 거리 kNN → 이웃 5점의 실제 상부를
seam에서 오프셋 정렬 → **균등 평균**.

| 지표 (잠근 테스트 n=12, k=5) | 값 |
|---|---|
| RMSE (결손 구간) | **0.0698** |
| 정규화 rim 반경 오차 (평균) | **0.102** |
| seam 기울기 오차 | 0.317 |
| seam 곡률 점프 | 0.008 |

- 전역 상부 평균 대비 RMSE 약 **48% 감소** (0.135 → 0.070).
- whole-nearest(0.095) · PCA m=3(0.123) · 선형연장(0.327)보다 낮은 오차.
- `rimErr 0.102` = "±10% 보장"이 아니라 **정규화된 rim 반경 오차의 평균**.

### 10.4 Post-hoc — 잠근 테스트를 본 뒤 추가한 설정 (`profile_direct_blend.py`)

거버넌스: 아래는 §10.3 사전등록 결과를 관측한 **후**에 추가·튜닝했으므로 탐색적 민감도로만 표기.

- **direct softmax kNN** (`wⱼ = softmax(−dⱼ/τ)`, 실제 상부 직접 가중): 잠근 RMSE `0.0698 → 0.0657`.
  그러나 개발셋 차이는 `0.003`뿐, 유물별 승패 3승 1패 8무, k3에서는 uniform과 사실상 동일
  (uni 0.0628 / dir 0.0631). **k 선택 효과(Δ0.011)가 direct 효과(Δ0.004)보다 큼 → 견고한 개선 근거 없음.**
- τ=0.01에서 유효 이웃 수 `N_eff = 1/Σwⱼ² ` 평균 **4.45** (중앙값 4.97/5) — 선택된 τ에서 softmax는
  사실상 균등 가중으로 붕괴. direct blend ≈ uniform인 이유.
- **2-cluster 다중가설** (선택 없이 hyp_A/hyp_B 둘 다 출력): 유의미 분리율 1.0, 두 가설 발산 0.149.
  hypA 0.112 / hypB 0.117 (각 단독은 uniform보다 나쁨), best-of-2 0.076 (정답 클러스터를 알아도
  uniform 0.070 못 넘음). coverage(정답이 두 가설 사이) 0.67, ±0.05 band 0.88 — **보정된 확률이
  아닌 탐색적 기술값**.
- **k-sweep**: post-hoc 민감도에서 k=3이 더 낮았으나(0.0628), 개발셋이 선택한 **k=5를 사전등록
  결과로 유지**한다.

### 10.5 §10 결론

> 하부 프로파일로 검색한 다섯 이웃의 상부 형상을 seam 정렬 후 **균등 평균**하는 단순 방법은
> 합성 상부 절제 실험에서 전역평균·단일 최근접·PCA·선형연장보다 낮은 오차를 보였다. 반면
> 밴드 투표, 선형 backbone 기반 잔차 전이, 거리 기반 softmax 가중, 2-cluster 다중가설은 균등
> kNN 대비 **견고한 추가 이득을 보이지 않았다.** 따라서 현재 표현과 코퍼스에서는 복잡한 학습
> 결합보다 단순한 균등 국소 앙상블을 기준 방법으로 채택한다. 이 결과는 사진 기반 프로파일의
> 합성 절제에 대한 내부 검증이며, 실제 파편 `08`/`15H`의 복원 정확도를 보장하지 않는다.

즉 "참고 혼합이 실패했다"가 아니라 — **단순 균등 혼합(uniform kNN-5)은 유효했고, 그보다
복잡한 혼합은 추가 가치가 없었다.**

### 10.6 확증 방법을 실제 타깃에 1회 적용 (`profile_apply_0815.py`)

## 최종 결론

1. 파이프라인은 end-to-end 작동하고, 산출물은 **근거 수준이 태깅**된다.
2. **정교한 참고 결합 방식은 이득 없음** — 네 가지 독립 검증이 같은 결론:
   - 하드게이트(§6) : `06/13/16` 굽각·형태 불일치 → 기증자 부적격
   - 단일 회전면 패치(§7) : `11`은 자체 관측으로 충분, `08`은 파편적이라 검사 불가 → 코퍼스 기여 0
   - PCA 프로파일 앙상블(§8) : 최근접·평균 baseline보다 개선 없음
   - 밴드 투표·잔차 전이·softmax 가중·2-cluster 다중가설(§10) : 균등 kNN 대비 견고한 이득 없음
3. **단, 단순 균등 국소 앙상블은 유효**(§10.3): 확장 코퍼스(A′, 잠근 테스트 12점)에서
   `uniform kNN-5`(seam 고정)가 전역평균 대비 RMSE 약 48% 감소, PCA·whole-nearest보다 우수.
   정규화 rim 반경 오차 평균 `0.102` — 검증된 복원이 아니라 **거친 축대칭 외피**.
4. §9 최근접 baseline은 **참고 선택(Top-3)에 민감** — 소규모 코퍼스에서 단일 답 불안정.
5. 이 규모·품질의 사진 코퍼스로는 손상 굽다리바리의 **정확도 보장 가능한 prior를 얻을 수 없다.**
   되려면 같은 형식의 **실측 프로파일 수십~수백점**이 필요.
6. 생성물은 전부 **복원이 아니라 거친 시각적 가설** (`AXISYMMETRIC_ENVELOPE_HYPOTHESIS`).
