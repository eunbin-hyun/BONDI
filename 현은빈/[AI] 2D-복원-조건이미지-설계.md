## 0. 한 줄 요약

**사진을 이미지 공간에서 채우지 말고, 원통 전개 `(y, θ)` 공간에서 채운 뒤 되돌린다.**

이미지 공간의 "같은 행"은 그릇의 "같은 높이"가 아니다. 그 착각이 v11 을 168조각으로 만들었다.

---

## 1. 왜 필요한가 — 조건이 6.7배를 좌우한다

coords·채움·시드를 고정하고 **조건 이미지만** 바꾼 통제 실험이다.

| 조건 | 채움 화소 | 조각수 | 원형도 |
| --- | ---: | ---: | ---: |
| 원본 사진 (v7) | 0 | **25** | 9.2% |
| 미러 합성 — 실제 화소 이동 (v9) | +23,084 | **22** | 12.8% |
| 복원 투영 — 행 복사 (v10, 크롭 428) | +28,775 | 110 | 16.2% |
| 복원 투영 — 행 복사 (v11, 크롭 407) | +23,917 | **168** | 13.7% |

**25 → 168.** 조건은 약한 레버가 아니다.

이유는 §3.3 정정에 적었다 — coords 는 *어느 복셀에* 표면이 있는지만 정하고,
**복셀 안 어디를 지나고 이웃과 어떻게 만나는지는 잠재값**이며 그 잠재값을 이미지 조건이 몬다.
채움 자리에서 사진이 "파단면"을 보여주면 모델은 그 표면을 *조각의 끝*으로 기술한다.

---

## 2. 실패에서 배운 것

### 2.1 실루엣 완성도가 아니라 질감 그럴듯함이 관건이다

v11 은 실루엣이 v9 보다 완전한데 결과는 7배 나빴다. 갈린 것은 **채움 화소를 어떻게 만들었나**다.

| | 방식 | 결과 |
| --- | --- | --- |
| v9 | 반대편의 **실제 화소**를 옮김 | 질감 온전 → 22조각 |
| v11 | **같은 행의 최근접 화소** 복사 | 가로 줄무늬 → 168조각 |

v11 의 경계엣지가 **0**인 것이 방증이다 — 찢어진 면이 아니라 **168개의 닫힌 껍질**이다.
모델이 가로 줄무늬를 층층이 분리된 껍질로 재현했다.

### 2.2 왜 행 복사가 틀렸나 — 이 문서의 핵심

이미지의 **같은 행(row)** 은 그릇의 **같은 높이**가 아니다.

- 카메라가 pitch 13° 로 내려다본다 → 화면 한 행이 그릇 앞면과 뒷면의 다른 높이를 함께 지난다
- 그릇이 회전체라 좌우로 갈수록 표면이 급격히 기울어 화소 밀도가 달라진다
- 굽다리와 배신이 한 행에 같이 들어오는 높이대가 있다

그래서 "같은 행의 최근접 화소"는 **엉뚱한 높이의 표면을 가로로 늘여 붙인다.** 줄무늬가 나온 이유다.

> **회전대칭은 `(y, θ)` 공간에서만 성립한다.** 이미지 공간에서 흉내내면 안 된다.

### 2.3 크롭은 원인이 아니었다

v10(크롭 428) → v11(크롭 407) 로 맞췄는데 110 → 168 로 **더 나빠졌다.**
다만 크롭이 어긋나면 조건과 좌표의 스케일이 안 맞으므로 **맞추긴 해야 한다.** 필요조건이지 충분조건이 아니다.

## 3. 설계 — 원통 전개 공간에서 채운다

```text
원본 손상 사진
  ├─ 배경 제거 → RGBA                                    (RMBG-2.0, 설치본)
  │
  ├─[1] 카메라 정합
  │     손상 메시 투영 실루엣 ↔ 사진 알파의 IoU 최대화
  │     yaw·pitch·scale·tx·ty 5개. **IoU 가 곧 검증치**   (실측 85.5%)
  │
  ├─[2] 화소 → (y, θ) 언랩
  │     복원 메시의 각 정점에 (y, θ) 를 달아 투영
  │     → 화소마다 그릇 표면의 어느 높이·각도인지 알게 된다
  │     → 사진에서 **관측 텍스처 맵** T(y, θ) 를 얻는다
  │
  ├─[3] 맵에서 결손 칸 채움  ← 여기가 회전대칭이 성립하는 유일한 공간
  │     같은 높이 h 의 다른 각도들에서 가져온다
  │     단순 최근접이 아니라 **여러 각도의 중앙값** (특정 얼룩 복사 방지)
  │     경계는 값을 이어 붙여 이음매를 없앤다
  │
  ├─[4] 채워진 맵 → 화상으로 되투영  ([2] 의 역방향)
  │
  └─[5] 합성
        원본 화소는 **한 톨도 안 바꾼다**. 결손 자리에만 [4] 를 넣는다
        채움을 **원본 알파 bbox 안으로 제한** → 정사각 크롭이 원본과 같아진다
```

**[1]·[2] 는 이미 있다** — `make_render_photo.py` 의 카메라 정합(IoU 85.5%)과 `skeleton_cyl.py` 의 원통 전개.
새로 만들 것은 [2] 의 화소↔`(y,θ)` 대응과 [3] 의 맵 채움이다.

### 3.1 [3] 을 어떻게 채우나 — 세 단계로 올린다

| 단계 | 방법 | 근거 | 위험 |
| --- | --- | --- | --- |
| a | 같은 높이 여러 각도의 **중앙값** | 회전대칭 | 평균이라 뭉갠다 |
| b | **패치 기반 합성** (같은 높이대에서 조각을 떠와 이어붙임) | 회전대칭 | 이음매 |
| c | 자기지도 U-Net 을 **색에** 적용 | 회전대칭 (그 유물 자신) | MSE 뭉갬 (요철에서 진폭 45%였다) |

**a 로 시작한다.** v9(미러, 실제 화소)가 22조각을 냈으므로 "실제 화소를 옮기는 것"만으로 충분할 수 있다.
a 가 여전히 뭉개 보이면 b 로 올린다.

### 3.2 근거는 그대로 유지된다

| 무엇 | 어디서 | manifest |
| --- | --- | --- |
| 완형 실루엣 | 회전대칭 복원 메시를 투영 | **회전대칭 가정** |
| 채움 색 | 같은 높이 다른 각도의 관측 화소 | **회전대칭 가정** |
| 원본 화소 | 안 건드림 | observed |

**생성 모델을 쓰지 않으므로 "AI 추정"으로 떨어지지 않는다.** 결정론적이고 시드 의존도 없다.

## 4. 한계

- **자연유는 비대칭이다.** 가마 안에서 재가 떨어진 방향이라 같은 높이라도 각도마다 다르다.
  회전대칭으로 옮기면 없던 자리에 녹색이 생긴다. 채움부에 한정되지만 기록해야 한다
- **뒷면은 사진에 없다.** `(y, θ)` 맵의 절반이 비어 있고, 그 영역은 앞면에서 가져온다
- **카메라가 정사영 근사**다. 원근이 크면 IoU 가 떨어진다 — 그때 이 경로를 쓰면 안 된다
- **좌우가 같은 높이에서 깨졌으면** 가져올 각도가 없다. 미러가 IoU 52.6% 로 부족했던 이유와 같다

## 5. 검증

만들면서 확인할 것과 통과 기준이다. **하나라도 실패하면 다음 단계로 가지 않는다.**

| # | 확인 | 기준 |
| --- | --- | --- |
| 1 | 카메라 IoU | ≥ 0.80 (실측 0.855) |
| 2 | 되투영 왕복 오차 — 관측 화소를 언랩했다 되돌리면 제자리인가 | 중앙 ≤ 1화소 |
| 3 | 합성 실루엣이 완형인가 | 구연부가 원주로 이어짐 |
| 4 | **크롭 변이 원본과 동일** | 407 (§2.3) |
| 5 | 원본 화소 무수정 | 변경 화소 0 |
| 6 | **최종 — TRELLIS 조각수** | **< 22** (v9 미러가 22, 원본이 25) |

6번이 진짜 판정이다. 22 를 못 넘으면 조건 경로의 천장이 거기라는 뜻이고,
[회전대칭-메시-직접-복원.md](%5B%EC%88%98%ED%95%99%5D%20%ED%9A%8C%EC%A0%84%EB%8C%80%EC%B9%AD-%EB%A9%94%EC%8B%9C-%EC%A7%81%EC%A0%91-%EB%B3%B5%EC%9B%90.md) 경로가 답이 된다.

## 6. 대안 — 생성 인페인팅

§7.10 이 이 대안의 근거를 강화했다. 조건 질감이 결과를 6.7배 좌우하니 **좋은 인페인팅 모델이 실제로 값어치가 있다.**

| 모델 | 크기 | 8GB | 근거 영향 |
| --- | --- | --- | --- |
| LaMa | ~200MB (CPU 가능) | ✓ | **결정론적, 형태를 안 만듦** |
| SD 1.5 inpainting | ~2GB | ✓ | 시드 의존 |
| SDXL inpainting | ~6.9GB | 순차 실행 | 시드 의존 |
| FLUX.1 Fill | 12B | 양자화 필수 | 시드 의존 + 비상업 라이선스 |

현재 venv 에 `diffusers` 도 가중치도 없다. 다운로드부터 시작해야 한다.

**LaMa 를 1순위로 본다** — 실루엣을 회전대칭이 주면 LaMa 는 주변 질감을 연장만 한다.
새 형태를 안 만들고 결정론적이라 근거 훼손이 제한적이다.

다만 §3 이 실패한 뒤에 꺼낼 카드다. §3 은 새 의존성이 없고 근거도 안 바뀐다.

## 7. 적용

조건 이미지가 완성되면 SLAT 주입 경로에 그대로 넣는다. **파이프라인 변경은 없다** —
`restore_run.py --image <합성본>` 이면 된다. v7·v9·v10·v11 과 같은 자리다.

```powershell
& "...\python.exe" "...\restore_run.py" `
  --image out\cond2d\composite.png --pipeline 512 `
  --fill-npz out\cyl\fill_cyl.npz --decimation 400000 --texsize 2048 --tag v17-cond2d
```

coords·채움·시드를 고정하면 **조건 이미지만 다른 통제 실험**이 되어 v7(25)·v9(22)와 직접 비교된다.
