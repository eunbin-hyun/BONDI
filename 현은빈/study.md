# 현은빈 학습·설계 문서

기획 조사, 포지션별 학습 계획, 복원 파이프라인 설계.
문서 이름 앞의 대괄호가 **분류**다.

| 분류 | 무엇을 다루나 | 판단 기준 |
| --- | --- | --- |
| **(없음)** | **뼈대 하나** | [복원 일반화 로드맵](%EB%B3%B5%EC%9B%90-%EC%9D%BC%EB%B0%98%ED%99%94-%EB%A1%9C%EB%93%9C%EB%A7%B5.md) 하나뿐이다. 축 넷을 다 다루므로 어느 분류에도 안 들어간다 |
| **`[AI]`** | 생성 모델을 **쓰는** 이야기 | TRELLIS·U-Net·SAM 3D·LaMa 같은 모델의 구조·설치·입력 설계 |
| **`[수학]`** | 모델 없이 **기하로 푸는** 이야기 | 원통 전개, 이중조화 풀이, 푸리에 주기 탐지. AI 가 안 들어간다 |
| **`[VR]`** | 언리얼·Quest·전시 | 복원 결과를 **보여주는** 쪽 |
| **`[회고]`** | 돌아보며 정리 | [AI 프로젝트 규모와 알아야 할 것](%5B%ED%9A%8C%EA%B3%A0%5D%20AI-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EA%B7%9C%EB%AA%A8%EC%99%80-%EC%95%8C%EC%95%84%EC%95%BC%ED%95%A0%EA%B2%83.md) — GPU·시간·비용 실측과 교훈 |

## 파이프라인에서의 위치

```text
   사진 한 장
      │
   ┌──┴────────────────────────────────────────┐
   │  [AI]   TRELLIS.2 → 손상 3D (메시 + PBR)   │   A단계. 형상 생성은 여기까지다
   └──┬────────────────────────────────────────┘
      │
   ┌──┴────────────────────────────────────────┐
   │  [수학] 원통 전개 → 결손 판정 → 이중조화   │   회전대칭·n-fold 가정 하나로 푼다
   │         채움 → 투창 카빙 → 2노드 GLB       │   "AI 추정"이 아니라 "가정"으로 쓸 수 있다
   └──┬────────────────────────────────────────┘
      │
   ┌──┴────────────────────────────────────────┐
   │  [AI]   TRELLIS.2 텍스처링 → 채움 재질     │   형상에 일절 개입하지 않는다 (S10)
   └──┬────────────────────────────────────────┘
      │
   ┌──┴────────────────────────────────────────┐
   │  [VR]   언리얼 반입 → 전시실 → 정보 패널   │
   └───────────────────────────────────────────┘
```

**형상 복원에 AI 가 안 들어가는 것이 이 설계의 값어치다.** AI 가 들어가는 자리는 A단계와 재질 둘뿐이고,
`region_carried`(관측)와 `region_filled`(추정)가 별도 노드로 나뉘어 `NFR-ETH-003` 을 만족한다.
**무엇을 어떤 순서로 바꿀지는 아래 뼈대 문서가 정한다.**

> **SLAT 주입 경로는 조각 수가 22 아래로 안 내려갔고, 2026-09-11 에 종결했다.**
> 처음에는 *"O-Voxel 이 복셀 안의 표면 위치를 잠재값으로 정하므로 이웃이 어긋나면 면이 안 만난다"* 로
> 설명했는데 **그 메커니즘은 틀렸다** — 정점은 항상 공유되므로 면이 찢어질 수 없다.
> 실제로는 `intersected` 이진 플래그가 꺼지거나 2×2 복셀이 안 차서 **쿼드가 빠지는** 것이고,
> 임계를 ±3 흔들어도 조각 수가 안 바뀐다(logit 중앙 12.156). 자세한 것은 위 문서.
> 형상 복원은 `[수학]` 으로 옮겼고, TRELLIS 의 역할은 **A단계(사진→손상 3D)와 재질**로 확정했다.

```powershell
# 이 유물(굽다리바리 경주 신수 71489)의 표준 명령
& "...\python.exe" "...\restore\build_mesh_direct.py" `
  --glb out/probe/A_normal.glb --out out/v24-cyl+biharm+n6+nn+up2 --ny 96 --ntheta 144 `
  --openwork-max-deg 50 --nfold 6

# 2 재질 - 채움면에만 TRELLIS 텍스처 (관측부는 1의 것을 그대로 쓴다)
& "...\python.exe" "...estore	exture_from_mesh.py" encode
& "...\python.exe" "...estore	exture_from_mesh.py" texture
#   -> out/v28-cyl+biharm+n6+trellisfill+up2  (v24 관측부 + v27 채움 재질)
```

**출력 폴더 이름이 곧 방법이다** — `v<번호>-<형상>+<채움>+<개구>+<재질>[+<추가>]`.
규칙과 전체 매핑은 [복원 일반화 로드맵](%EB%B3%B5%EC%9B%90-%EC%9D%BC%EB%B0%98%ED%99%94-%EB%A1%9C%EB%93%9C%EB%A7%B5.md) §7 에 있다.
