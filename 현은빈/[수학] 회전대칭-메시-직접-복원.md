## 0. 한 줄 요약

**TRELLIS 는 사진에서 손상 3D 를 만드는 데까지만 쓴다.** 그 뒤 결손 채움은 원통 전개 맵 `r(y, θ)` 에서
메시를 직접 만든다. 인접 격자 칸이 정점을 공유하므로 **면 연속성이 정의상 보장**된다.

> 이 경로에는 SLAT 주입도, coords 주입도, 조건 이미지도 없다.
> 앞 문서에서 11개 버전을 들여 싸운 실패 양상(점선·가로 띠·떨어진 조각)이 **구조적으로 존재하지 않는다.**

## 1. 왜 바꿨나

SLAT 주입 경로에서 메시 조각 수가 **22 아래로 내려가지 않았다**(손상본은 2개).

| 시도 | 조각수 |
| --- | ---: |
| 손상 (기준) | 2 |
| 채움 방식 6가지 (v1~v7) | 22~115 |
| 마스킹 샘플링 (v8) | 54 |
| 조건 이미지 3가지 (v9~v11) | 22~168 |

원인은 **표현 자체**다.

- 채움 설정 9가지 전부 **복셀은 26-연결 1덩어리**인데 메시는 갈라졌다
- O-Voxel 은 복셀 *안*의 표면 위치를 잠재값이 정한다 → 이웃 잠재값이 어긋나면 복셀이 붙어 있어도 면이 안 만난다
- 조건 이미지만 바꿔도 25 → 168 로 6.7배 흔들린다

`(y, θ)` 격자에서 메시를 만들면 이 문제가 **발생할 수 없다.** 인접 칸이 같은 정점을 쓰기 때문이다.

## 2. 파이프라인

```text
원본 손상 사진
  └─[A] TRELLIS.2 ──→ 손상 GLB (메시 + PBR 텍스처)
                        │
                        ├──────────────────────────→ region_carried  (무수정)
                        │
                        └─[B] 원통 전개
                              ├─ fit_axis            최소제곱 원피팅 + 슬라이스 중앙값
                              ├─ classify_surfaces   면 법선으로 내·외면 분리
                              ├─ radial_grid         (y, θ) → r 격자
                              ├─ fill_profile        높이별 프로파일
                              └─ fill_grid           결손 칸 2D 반복 채움
                                    ↓
                            [C] 채워진 맵 → 메시 직접 생성
                                  격자 칸 = 정점 / 인접 칸 = 사각형 2삼각형
                                  + 내면 복제 + 경계 옆면 → 두께
                                    ↓
                            [D] 색 전사 (최근접 잔존 표면)
                                    ↓
                                region_filled
                        ▼
              GLB 2노드 + manifest.json
```

**TRELLIS 의 역할이 A 하나로 줄었다.** 형상 복원에는 관여하지 않는다.

### 2.1 각 단계에 AI 가 들어가는가

| 단계 | AI? |
| --- | --- |
| A 사진 → 손상 3D | **예 — TRELLIS.2** |
| B 결손 판정 | 아니오 (면 법선 기하) |
| B 채움 형상 | 아니오 (**회전대칭**) |
| C 메시 생성 | 아니오 (격자 삼각화) |
| D 채움 색 | 아니오 (최근접 복사) |
| ③ 요철 (미착수) | 예정 — 자기지도 U-Net (§5) |

manifest 표기는 `"region_filled": "회전대칭 가정 (ai_inferred)"` 이다.
**"AI 가 복원했다"가 아니라 "회전대칭 가정 하나로 복원했다"** 로 쓸 수 있는 것이 이 경로의 값어치다.

깨진 쪽(Z)만 0.843 → 0.923 으로 회복했다.

### 3.1 채움 패치 11개가 맞는 수다

결손 칸 4,909 개를 연결 성분으로 세면 **108개**인데, 그중 **91개가 1~2칸짜리**다(표본 노이즈).
진짜 결손은 상위 8개(2846 · 657 · 365 · 329 · 139 · 136 · 88 · 74칸)다.
사각형을 만들 수 없는 조각은 자동으로 버려져 **패치 11개**가 남는다.

**앞 경로의 22조각과 성격이 다르다.** 저건 한 면이 찢어진 것이고, 이건 구멍마다 패치 하나다.

### 3.2 채움이 기존 표면을 덮지 않는다

| 채움 정점 → 관측 표면 거리 | 비율 |
| --- | ---: |
| 1칸 이내 | 5.6% |
| 2칸 이내 | 18.8% |
| 중앙 | **6.7칸** |

**81%가 2칸 이상 떨어져 있다.** 진짜 구멍에 들어가 있다.
채움이 넓어 보이는 것은 결손이 실제로 크기 때문이다 — 구연부 잔존이 24~36%다.

## 5. 남은 것

### 5.1 채움면이 매끈하다 — U-Net 자리 (층 ③)

물레자국도 돌대도 없다. SLAT 경로에서는 TRELLIS 가 만들어주던 것을 이 경로에서는 잃었다.

**자기지도 U-Net 이 정확히 여기에 들어간다.** 그 유물 자신의 온전한 부위에서 요철을 학습해 채움면에 얹는다.
김소영 방식의 복사 전사보다 나은 지점이다 — 통계를 학습하므로 "복사본"이라는 한계가 없다.

전제 확인은 끝났다 ([선행 문서](%5BAI%5D%20trellis2-%EB%B3%B5%EC%9B%90-%ED%8C%8C%EC%9D%B4%ED%94%84%EB%9D%BC%EC%9D%B8-%EC%9E%AC%EA%B5%AC%EC%84%B1.md) 주기 탐지 실험).

| 항목 | 판정 |
| --- | --- |
| 아키텍처 재사용 (`PeriodicResidualUNet`) | 가능 — 출력층 zero-init 이라 학습 전엔 prior 그대로 |
| 가중치 재사용 | **불가** — 빗살무늬 전용 주기 prior. 자기지도 재학습 필요 |
| **주기 prior** | **불가** — θ 상관 최대−최소 0.082 로 평평. peak 이 없다 |
| **회전 불변 prior 로 교체** | **가능** — θ 상관 0.63 (같은 높이의 아무 각도가 좋은 donor) |
| 맵 해상도 | 64×96 에서 신호 포화. `PATCH` 를 96 → 48 로 |
| **위험** | 고주파 std 4.5mm 로 **파단선이 지배**. 그대로 학습하면 채움면에 **가짜 균열**을 그린다 |

마지막 줄이 중요하다. 김소영이 전사한 미세요철은 0.84mm 인데 우리 고주파는 5배 크다.
학습 표본에서 파단선 근처를 빼거나 고역통과를 더 좁게 잡아 **단차와 물레자국을 분리**해야 한다.

### 5.2 패치가 관측 메시에 용접돼 있지 않다

반경을 관측에서 보간해 위치는 맞지만 정점을 공유하지 않아 경계에 미세한 틈이 보일 수 있다.
**원본 무수정 규약과의 맞바꿈**이다 — 용접하면 관측 정점이 움직인다.

선택지: (a) 그대로 두고 provenance 로 설명 (b) 채움 쪽 정점만 관측 표면에 스냅(관측은 고정)

### 5.3 격자 해상도 맞바꿈

96×144 는 칸당 정점 2.7개라 결손을 **약 5%p 과판정**한다(수렴값 ~30% vs 측정 35.5%).
64×96 이 수렴점이지만 거기선 사각형을 만들 칸이 줄어 패치가 성겨진다.
**손상 GLB 를 400k 데시메이션으로 다시 뽑으면** 둘 다 해결된다(정점 약 200k → 칸당 5개).

### 5.4 투창

굽다리 투창을 결손과 구분하지 않아 메워진다. 앞 문서 §6.3 과 같은 상태.
