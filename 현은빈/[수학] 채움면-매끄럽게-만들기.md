## 1. 진단 — 어디가 문제였나

"안 매끄럽다"는 증상 하나에 원인이 넷이고 약이 다르다.

| 증상 | 원인 | 이 유물에서 |
| --- | --- | --- |
| 각져 보이는데 만지면 부드러움 | 법선(NORMAL) | 일부 — §5 |
| 계단·격자 무늬 | 표현 해상도 | **예** — §4 |
| 잔물결·오돌토돌 | 노이즈 | 경계에서만 — §3 |
| 이음새 단차 | 경계 불연속 | **예** — §2 로 같이 해결 |

### 1.1 `ssv.fill_grid` 가 확산이 아니다

`restore_pottery_self_supervised.py:146`

```python
for _ in range(80):
    missing = ~np.isfinite(filled)      # ← 이미 채워진 칸은 여기서 빠진다
    ...
    can_fill = missing & (counts > 0)
    filled[can_fill] = sums[can_fill] / counts[can_fill]   # 한 번 쓰면 끝
```

값이 한 번 들어간 칸은 `missing` 에서 빠져 **두 번 다시 갱신되지 않는다.**
확산(diffusion)이 아니라 **전진 복사(grassfire)** 다. 셋이 따라온다.

| # | 아티팩트 | 원리 |
| --- | --- | --- |
| 1 | **방사 줄무늬** | 전선 위 칸은 유한 이웃이 1~2개뿐이라 사실상 복사다. 파단 테두리의 톱니가 구멍 중심을 향해 행진하고 평균이 한 번만 걸려 안 지워진다 |
| 2 | **합류 능선** | θ폭 200° 결손은 좌우 전선이 40칸씩 들어와 가운데서 만난다. 만나는 선에서 값이 불연속이라 세로 능선이 하나 생긴다 |
| 3 | **이방성** | 어느 이웃이 먼저 유한해지냐에 따라 같은 구멍 안에서도 방향마다 다르게 채워진다 |

기존 대처(`snap_boundary` → `smooth_fixed_boundary` Taubin 3회 cap 3mm)는 증상 치료였다.
능선은 구조적 오차라 3mm 상한에 안 들어오고, 줄무늬를 등방 Taubin 으로 지우려면
횟수를 크게 올려야 하는데 그럼 형상이 뭉갠다.

## 2. #1 이중조화 풀이 — 채움면과 이음새가 한 수로 풀린다

결손 4,909칸만 미지수인 선형계다. 반복 말고 **직접 푼다** (`fill_solve`).

```python
A = L if order == 1 else (L @ L)          # L = 5점 라플라시안, θ wrap · y Neumann
rhs = -(A[mi][:, ki] @ x[ki])             # 관측 칸은 Dirichlet 경계조건
x[mi] = spsolve(A[mi][:, mi], rhs)
```

| | 성격 | 경계 연속성 | 큰 결손에서 |
| --- | --- | --- | --- |
| `order=1` 조화 (비눗막) | 면적 최소 | **C⁰ — 꺾인다** | 안으로 **꺼진다(sag)** |
| **`order=2` 이중조화 (박판)** | 곡률 최소 | **C¹ — 접평면을 이어받는다** | 벽 곡률을 **연장** |

항아리 벽은 바깥으로 불룩하므로 조화는 200° 결손을 안으로 움푹 꺼뜨리고 이음새에 꺾임을 남긴다.
**이중조화가 채움면 매끄러움과 이음새 연속성을 동시에 준다.**

### 2.1 회전대칭 근거는 유지된다

푸는 대상은 반경이 아니라 **프로파일 잔차 `r − r̄(y)`** 다.
데이터가 없는 곳의 기준이 회전체가 되므로 manifest 표기가 `"회전대칭 가정"` 그대로다.
잔차는 작아서 외삽이 폭주하지 않는다. 관측 칸은 Dirichlet 이라 **값이 정확히 보존**된다(오차 `0.00e+00`).

### 2.2 합성 격자 검증 (정답 있음, 64×96, θ폭 150° 결손)

| 방식 | RMSE | 최대오차 | \|Δr\| p95 | θ 2차차분 최대 | 구멍중앙 부호오차 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 전진복사 | 4.056 | 9.602 | 4.1867 | **2.947** | — |
| 조화 | 1.253 | 2.739 | 0.1257 | 0.112 | **−1.69mm** |
| **이중조화** | **0.542** | **1.246** | 0.2835 | 0.318 | −0.95mm |

**합류 능선이 2.95 → 0.32mm 로 사라졌다.** 조화가 \|Δr\| 은 더 낮은데 RMSE 는 2.3배 나쁜 것이
예상대로다 — **더 매끈하지만 형상이 틀린다.**

## 3. #3 관측 맵 저역통과 — 남은 거칠기는 전부 경계조건에서 왔다

#1 적용 후 거리별로 재 보니 원인이 한 곳에 몰려 있었다.

| 관측까지 거리 | 칸수 | \|Δr\| 중앙 | 최대 |
| ---: | ---: | ---: | ---: |
| **1칸** | 734 | **1.517** | 26.25 |
| 2칸 | 360 | 0.865 | 7.47 |
| 5–8칸 | 814 | 0.165 | 1.58 |
| **9칸+** | 1,657 | **0.082** | **0.83** |

**구멍 속은 이미 끝났다**(최대 0.83mm). 상위 스파이크 12개가 전부 거리 1.0 이고,
(35,57) 옆 관측 칸 두 개가 `−11.3 / −33.3` — **인접한 관측 칸이 22mm 차이**다.
채움이 만든 게 아니라 **관측 데이터가 톱니**이고 Dirichlet 풀이가 충실히 통과한 것이다.

→ `ssv.box_blur_wrap` 를 **유한 마스크로 정규화**해 NaN-aware 로 쓴다 (`obs_blur`).
결손 칸은 결손으로 남는다. 관측 **메시**는 안 건드린다 — 관측 칸의 값은
`patch_mesh` 에 들어가지 않으므로(사각형은 결손 칸 4개로만 만든다) `NFR-ETH-003` 과 무관하다.

**창 5가 무릎이다.**

| 창 | 이면각 중앙 | 테두리→관측 중앙 | 그 p95 |
| ---: | ---: | ---: | ---: |
| 0 | 2.496 | 3.97mm | 66.21mm |

대가가 테두리 0.3mm 뿐이고 **그 p95 는 오히려 줄어든다.**

### 3.1 덤 — bbox 팽창이 저절로 해결됐다

#1 만 적용했을 때 bbox X 가 0.904 → **0.917** 로 튀어나가 선행 문서 §3 의
*"X·Y 가 소수점 셋째 자리까지 같다"* 가 깨졌었다.

**0.904 로 복귀했다.**

## 4. #4 판정 해상도와 면 해상도를 분리 — §5.3 이 여기서 풀린다

격자를 키우면 면은 촘촘해지지만 칸당 표본이 얕아져 결손을 과판정하고(약 5%p) 미세조각이 늘고,
낮추면 사각형을 만들 칸이 줄어 패치가 성겨진다. **두 요구가 같은 손잡이에 묶여 있던 것**이 문제였다.

`select_regions` 은 96×144 에서 끝내고, **그 판정을 그대로 둔 채** 면만 k배로 만든다 (`upsample_map`).

- 마스크는 **k×k 블록 복제** — 채울 영역이 늘지도 줄지도 않는다. 판정을 안 건드린다는 뜻
- `filled` 는 θ 를 `grid-wrap` 으로 3차 보간 — `nearest` 로 하면 이음새가 **2.5배** 벌어진다
- **손상 GLB 를 400k 로 다시 뽑을 필요가 없다**

| k | 삼각형 | 이면각 중앙 | 셰이딩오차 p95 |
| ---: | ---: | ---: | ---: |
| 1 | 18,000 | 2.038 | 38.85 |
| **2 (기본)** | **72,700** | **1.029** | **28.11** |
| 3 | 163,620 | 0.684 | 14.42 |
| 4 | 290,908 | 0.511 | 10.56 |

**무릎이 없는 순수 손잡이다** — 격자 칸이 곧 면의 각짐이라 k에 반비례해 계속 좋아지고
삼각형은 k² 로 는다. carried 가 149,150 이라 k=2 를 기본으로 뒀다. 고화질 렌더는 3~4.

## 5. #5 테두리 법선 분리

계산하면 테두리의 90° 모서리가 평균에 섞여 **패치 테두리마다 어두운 띠**가 생겼다.

옆면에 자기 정점을 준다. 복제본은 원본과 **같은 자리**에 있고 `rim` 에 같이 들어가
`snap_boundary`·`smooth_fixed_boundary` 에서 함께 움직인다 —
**스냅·평활을 통과한 뒤 복제 정점 1,524개의 원본까지 거리 최대 `0.00e+00mm`.** 틈이 안 벌어진다.
