## 0. 두 가지 요구가 서로 당긴다

메우기에는 요구가 둘 있고, 이 둘이 **원리적으로 충돌**한다.

| 요구 | 뜻 |
| --- | --- |
| **완벽히 이어짐** | 채움면과 관측면이 **정점을 공유**해 한 면이 된다 |
| **관측 무수정** | 관측 메시를 한 톨도 안 건드린다 (`NFR-ETH-003`, 원본 보존) |

> **정점을 공유하려면 관측 표면도 다시 만들어야 한다.**
> 관측을 무수정으로 두면 채움은 원리적으로 별개 면이다.

방식 선택은 결국 이 둘 중 어디에 무게를 두느냐다.

---

## 1. 먼저 확인한 것 — 이 메시에는 "구멍"이 없다

손상 GLB(`A_normal.glb`)를 **위치 기준으로 용접**해서 위상을 쟀다.

```text
정점 94,877 → 74,470 (용접)
변 223,703 · 경계변(1회) 0 · 정상(2회) 223,681 · 비다양체(3회+) 22
```

**경계변이 0개다.** TRELLIS 가 두께 있는 닫힌 껍질을 만들어서, 파단부가 위상적 구멍이 아니라
**표면이 접혀서 막힌 능선**이다.

> trimesh 가 `watertight=False`, "경계 루프 2175개"라고 보고하는 것은
> **UV 이음새로 정점이 쪼개져 있어서**다. 실제 위상이 아니다.
> 메시 위상을 잴 때는 반드시 **위치 기준으로 먼저 용접**할 것.

이 사실이 방식 선택을 크게 제한한다 — **채울 경계 루프가 없으므로 정석(§2 A)을 바로 못 쓴다.**

---

## 2. 방식 비교

| | 방식 | 완벽히 이어짐 | 선택적 채움 | 관측 무수정 | 이 유물에 |
| --- | --- | --- | --- | --- | --- |
| A | 구멍 경계 삼각화 (Liepa 2003) | ✓ 정점 공유 | ✓ 루프 단위 | ✓ | **✗ 경계 루프가 없다** |
| B | 불리언 합집합 | ✓ | 영역 제한 필요 | 거의 | ✗ `manifold3d` 미설치 · 비다양체 22 |
| C | 복셀 합집합 → 마칭큐브 | ✓ | 영역 제한 필요 | **✗ 재샘플링** | ✓ 가능 |
| D | 격자 패치 (별개 면) | ✗ | ✗ | ✓ | 채택했다가 D+ 로 |
| **D+** | **격자 패치 + 경계 스냅 + 영역 판정** | 시각적으로만 | ✓ | ✓ | **✓ 현재** |
| E | 파단 능선을 잘라 루프를 만든 뒤 A | ✓ | ✓ | ✓ | 능선 검출이 새 작업 |
| F | SLAT 주입 (TRELLIS 가 채움) | ✗ 조각 22~168 | ✗ | 마스킹 시 ✓ | 형상 담당에서 내려옴 |

### A. 구멍 경계 삼각화 — 정석이지만 못 쓴다

구멍의 경계 루프를 삼각화하고(minimum-area 또는 advancing front), 세분·평활한다.
**기존 경계 정점을 그대로 쓰므로 정점 공유가 공짜다.** 관측도 안 건드린다.

전제가 "구멍이 위상적으로 존재할 것"인데 §1 에서 아니라고 확인됐다.

### B. 불리언 합집합

회전면 solid 와 손상 메시를 합집합한다. 위상 연산이라 결과가 한 덩어리다.
입력이 watertight 여야 하는데 비다양체 변이 22개 있고, `manifold3d` 가 설치돼 있지 않다.
설치하면 시도해볼 수 있으나 비다양체 정리가 먼저다.

### C. 복셀 합집합 → 마칭큐브

가장 견고하다. 위상에 관계없이 항상 하나의 연결된 면이 나온다.
**대신 관측부까지 재샘플링된다** — 원본 무수정이 깨지고 `NFR-ETH-003` 의 노드 분리를 못 한다.
(정점 색으로 관측/추정을 표시하는 차선은 가능)

**"완벽한 연결"이 provenance 보다 중요하다고 판단될 때 꺼낼 카드.**

### D+. 격자 패치 + 경계 스냅 + 영역 판정 — 현재

`(y, θ)` 격자에서 채움면을 만들되,

1. **영역 판정** — 결손 마스크를 연결 성분으로 나눠 채울 것만 고른다
2. **경계 스냅** — 채움 테두리 정점만 관측면 최근접점으로 옮긴다. **관측은 고정**

김소영 2026-09-08 의 경계 스냅과 같은 방식이다(*"채움면 경계 225정점을 carried 최근접 표면점에 BVH 1회 스냅"*).

### E. 파단 능선을 잘라 루프를 만든 뒤 A

이론적으로 가장 깨끗하다. 표면이 급격히 접히는 능선(파단면)을 검출해 잘라내면 진짜 경계 루프가 생기고,
그다음 A 를 쓰면 정점 공유로 완벽히 이어진다. 관측도 안 건드린다(자른 자리가 원래 경계가 된다).

**능선 검출이 새 작업**이라 미착수. D+ 가 부족할 때 갈 곳.

## 3. 어디를 메울 것인가 — 영역 판정

지금까지는 θ-h 격자의 **빈 칸이면 무조건** 채웠다. 그래서 투창(의도된 구멍)까지 메웠다.

결손 마스크를 연결 성분으로 나눠 판정한다. θ 는 한 바퀴 도므로 좌우로 이어붙여 라벨링한다.

| 기준 | 투창 | 파단 결손 |
| --- | --- | --- |
| 크기 | 작고 일정 | 크고 제각각 |
| θ 폭 | 좁다 | 넓다 |
| 갇힘 | 위아래 끝에 안 닿는다 | 대개 가장자리까지 이어진다 |
| θ 배치 | **주기적 (n-fold)** | 무작위 |

### 3.1 실측 (v15, 96×144 격자)

```text
채움 7개(4,546칸) · 투창 4개 · 미세조각 97개     (이전: 4,909칸 전부 채움)

채움  2846칸 θ폭 200.0도 h [45,95]   배신 큰 결손
채움   657칸 θ폭  80.0도 h [ 0,36]   굽다리
채움   365칸 θ폭 100.0도 h [83,95]
채움   329칸 θ폭  70.0도 h [17,38]
```

**미세조각 97개**는 표본 부족이 만든 1~2칸짜리다. 사각형을 만들 수 없어 어차피 버려진다.

### 3.2 투창 판정은 아직 확인되지 않았다

```text
투창 θ [1, 154, 240, 346]  ·  간격 [152, 86, 107, 15]도
```

**등간격이 아니다.** 신라 고배 투창이라면 주기적이어야 하는데 제각각이고,
346°와 1°는 15° 차이라 **하나가 둘로 쪼개진 것**으로 보인다.

> 크기·폭·갇힘 세 조건으로 **걸러낸 것이지 투창임이 확인된 것이 아니다.**
> 사진과 대조해 사람이 판정해야 한다. `--openwork-max-cells` · `--openwork-max-deg` 로 조절한다.

θ 등간격성이 확인되면 그때 n-fold 근거가 선다. 지금은 그 근거가 없다.

## 4. 경계 스냅 실측

```text
테두리 1,524정점 중 1,262개 이동 (상한 10mm) · 이동거리 중앙 3.52mm
상한 초과로 남긴 262개 · 거리 중앙 32.9mm
```

- **관측 메시는 움직이지 않는다.** 채움 쪽 테두리만 옮긴다
- 남긴 262개(17%)는 **큰 결손의 한복판 테두리**다. 근처에 관측 표면이 없으니 옮길 데가 없다
- 즉 스냅이 메우는 것은 **작은 결손의 이음새**이고, 큰 결손의 가장자리는 원래 붙을 데가 없다

`trimesh.proximity` 는 `rtree` 를 요구하는데 미설치라, 관측 정점(94,877개) KD 트리의
**최근접 정점**으로 스냅한다. 메시가 조밀해 최근접 표면점과 한 변 길이 안에서 일치한다.

## 5. 무엇으로 메울 것인가 (형상 근거)

메우는 *방식*과 별개로 **채움 형상의 근거**가 무엇이냐는 문제가 있다.

| 근거 | 적용 | manifest 표기 |
| --- | --- | --- |
| **회전대칭** | 물레 성형 회전체 | "회전대칭 가정" |
| 좌우대칭 미러링 | 대칭면이 있는 기물 | "대칭 가정" |
| 유사 완형 정합 | 기종이 명확 + 참고품 | "유형 정합" |
| 이산 n-fold | 투창·투공 등 주기 구조 | "n-fold 가정" |
| 생성 인페인팅 | 대칭이 없는 유물 | **"AI 추정"** |

**현재는 전부 회전대칭이다.** 이게 가장 방어하기 좋다 — 검증 가능한 가정 하나다.
생성 모델을 형상에 쓰면 표기가 "AI 추정"으로 떨어진다.
