## 6. 투창 배치 — 같은 유물에 세 가지 답

**이 문서에서 제일 중요한 칸이다.**

![투창 배치 비교](images/mcp-투창-배치-비교.png)

| 출처 | 답 | 근거 |
| --- | --- | --- |
| **v24** (기존, 적용됨) | 투창 **6개** — 위단 2 · 아래단 4 | n-fold 푸리에 뒤 **눈 판정**. 푸리에 1위는 4였다 |
| **MCP** (이 문서) | 투창 **7개** — 위단 3 · 아래단 4 | 성한 방위만 적합. 일치 99.0% / **81.6%** |
| **문헌** | **단당 3~4개** | e뮤지엄 `설명` 43건 중 透窓 언급 **13건** |

### 문헌이 말하는 것 — 13건

| 단당 개수 | 건수 | 예 |
| ---: | ---: | --- |
| **3개** | **8** | 경주 6311·6312·6313 "3개의 透窓이 2단으로 **엇갈림**" · 8475·8476 "上下段 … 각 3개" |
| **4개** | **3** | 경주 5756·5757 "4個의 長方形 1段 透窓" · 5758 "4個의 透窓을 2段 **交列**로 配置" |
| 1개 | 1 | 경주 8480 |
| **6개** | **0** | — |

**세 가지가 드러난다.**

1. **단당 3개가 다수, 4개도 실재한다.** MCP 의 아래단 4개는 근거 없는 값이 아니다
2. **6개는 한 건도 없다.** v24 의 `n6` 은 문헌 지지가 0 이고, 푸리에(4)를 눈으로 뒤집은 값이다
3. **두 단이 엇갈린다(交列)** 가 4건에 명시됐다. 그리고 문헌 어디에도
   **두 단의 개수가 다른 사례가 없다** — MCP 의 "위 3 / 아래 4" 는 이 제약을 어긴다

### 진짜 문제는 적합이 아니라 증거다

한 유물의 성한 구역에서 관측되는 투창은 단당 **2~3개**뿐이다. 그것으로 N 을 자유 변수로
맞추면 **미결정 문제**다 — 2개를 보고 3-fold 인지 6-fold 인지 가를 수 없다.
세 답이 갈린 것은 알고리즘이 나빠서가 아니라 **데이터가 N 을 안 묶어 주기 때문**이다.
더 정교한 적합기를 붙여도 안 풀린다.

### 그래서 바꿀 것 — N 을 자유 변수에서 **사전 있는 변수**로

| # | 바꿀 것 |
| --- | --- |
| 1 | **N ∈ {3, 4}** 로 제한 (6 은 지지 0, 1 은 예외 1건) |
| 2 | **두 단이 같은 N** — 문헌에 다른 사례가 없다 |
| 3 | **엇갈림(交列)을 기본 가정** — 두 단의 위상차 = 반주기 |
| 4 | 단일값 말고 **후보별 일치도**를 manifest 에 남긴다 |

자유 매개변수가 `(N, 위상 1개, 폭 2개)` 로 줄어, 관측 2~3개로도 결정 가능한 수준이 된다.

`--nfold` 는 이미 **적용** 상태이므로
[투창-n-fold-판정.md](%5B%EC%88%98%ED%95%99%5D%20%ED%88%AC%EC%B0%BD-n-fold-%ED%8C%90%EC%A0%95.md) 에
이 사전을 반영하는 것이 이 문서보다 우선순위가 높다.

> **주의.** v24 의 θ 원점과 MCP 의 θ 원점이 같다는 보장이 없다 (`실행-구조.md` §4.1 — 좌표계가 둘이다).
> 그림에서 **위치를 겹쳐 읽으면 안 되고, 개수와 간격 패턴만** 비교 대상이다.
> v24 의 간격이 불규칙하고 MCP 가 등간격이라는 **구조 차이**는 원점과 무관하다.
