# 2026-08-27 학습 정리 — 정답 데이터 없는 자기지도 U-Net 3D 토기 복원

- 작성자: 현은빈
- 학습 주제: 완형 정답 없이 한 점의 훼손 토기에서 합성 결손을 생성해 3D 형상과 빗살무늬를 복원하는 방법
- 대상 데이터: `ssu022891-001-30000_Step3.stl`
- 핵심 기술: 원통 좌표 전개, 자기지도 inpainting, 2D U-Net, 메시 재구성

## 1. 프로젝트 목표

훼손된 빗살무늬토기의 3D 스캔 데이터만을 사용하여, 손상된 형상과 표면 무늬를 추정 복원하고 VR 박물관에서 원본과 복원 결과를 비교 전시하는 것을 목표로 한다.

이번 실험의 핵심 조건은 다음과 같다.

- 훼손 전의 완전한 3D 모델, 즉 정답 데이터가 없다.
- 한 점의 토기 데이터 내부에 남아 있는 온전한 무늬를 학습 자료로 사용한다.
- 복원 결과는 역사적으로 확정된 원형이 아니라 **AI가 생성한 복원 가설**이다.
- 최종 결과물은 VR에서 사용할 수 있는 닫힌 3D 메시(STL)로 생성한다.

## 3. 핵심 아이디어: 정답 없이 어떻게 학습하는가

### 3.1 자기지도 학습 구성

정답 데이터가 외부에 없는 것은 맞지만, 학습 시점에는 동일한 토기에서 비교적 온전한 영역을 임시 정답으로 사용한다.

1. 실제 손상으로 추정되는 영역을 제외한다.
2. 남아 있는 온전한 표면에서 64×64 패치를 뽑는다.
3. 패치 위에 균열·결손 모양의 합성 마스크를 무작위로 만든다.
4. 마스크 내부 값을 지워 가상의 훼손 입력을 만든다.
5. 훼손 전 패치 자체를 목표값으로 사용해 U-Net을 학습한다.
6. 학습된 모델을 실제 손상 마스크 영역에 적용한다.

즉, 별도의 완성품 정답은 사용하지 않지만 **원본의 온전한 부분에서 입력과 목표값을 자동 생성**한다. 구현 방식은 마스크드 이미지 모델링 또는 denoising autoencoder에 가까운 자기지도 inpainting이다.

### 3.2 이 방식이 성립하는 전제

- 토기 전체에서 무늬와 표면 특성이 어느 정도 반복된다.
- 온전한 영역의 무늬가 손상 영역의 원래 무늬를 추정하는 데 도움이 된다.
- 실제 손상과 학습용 합성 손상의 형태가 충분히 비슷하다.
- 토기를 원통 좌표로 펼쳤을 때 형상 왜곡이 과도하지 않다.

이 전제가 맞지 않으면 모델이 기술적으로 자연스러운 표면은 만들 수 있어도 역사적으로 올바른 무늬를 복원했다고 말할 수 없다.

## 4. 전처리 과정

### 4.1 토기의 중심축 추정

토기의 회전축을 추정한 뒤 각 정점을 `(높이 y, 각도 θ, 반지름 r)` 형태의 원통 좌표로 변환한다. 곡면 상태의 토기를 2차원 격자로 펼치면 일반적인 2D U-Net을 사용할 수 있다.

사용한 격자 크기:

```text
높이 방향 240 × 둘레 방향 360
```

### 4.2 내·외부 표면 분리

메시의 면과 정점을 토기의 바깥 표면과 안쪽 표면으로 분류한다. 바깥쪽 반지름 맵을 U-Net 복원 대상으로 사용하고, 안쪽 프로파일은 토기 두께와 닫힌 메시 생성에 이용한다.

### 4.3 저주파 형상과 고주파 무늬 분리

바깥쪽 반지름 맵에서 높이별 기본 반지름을 빼 잔차 표면을 만든다. 다시 블러를 사용해 다음 두 성분으로 분리한다.

- 저주파 성분: 토기의 전체적인 굽음과 큰 형태
- 고주파 성분: 빗살무늬, 작은 요철, 표면 세부

현재 U-Net은 주로 고주파 성분을 복원한다. 따라서 큰 파손으로 사라진 전체 윤곽을 새로 설계하는 모델이라기보다, 손상 부위의 국소 표면과 무늬를 이어 주는 모델에 가깝다.

### 4.4 실제 손상 마스크 생성

현재 구현에서는 U-Net이 손상 위치를 탐지하지 않는다. 기하 기반 이상치 탐지와 주변 반복 패턴 비교로 만든 마스크를 U-Net에 입력한다.

```text
실제 손상으로 선택된 격자 비율: 약 7.44%
```

따라서 전체 파이프라인에서 가장 중요한 병목 중 하나는 U-Net 자체보다 **손상 마스크가 정확한가**이다. 마스크에서 빠진 균열은 복원되지 않고, 정상 영역이 잘못 선택되면 원래 형상이 불필요하게 변경될 수 있다.

## 5. 합성 손상 데이터 생성

각 64×64 온전 패치에 다음 손상을 무작위로 생성했다.

- 1~4개의 굴절된 선형 균열
- 균열 두께 1~5픽셀
- 여러 구간으로 연결된 불규칙한 진행 방향
- 일정 확률로 타원형 결손 추가

모델 입력은 2채널이다.

| 채널 | 내용 |
|---|---|
| 1 | 손상 마스크 내부 값을 0으로 지운 고주파 표면 |
| 2 | 복원해야 할 위치를 표시한 이진 마스크 |

목표 출력은 손상시키기 전의 고주파 표면 1채널이다.

## 6. U-Net 구조

2단계 인코더·디코더와 skip connection을 사용한 작은 U-Net을 구성했다.

```text
입력 2채널
  ↓
Encoder: 16채널
  ↓ MaxPool
Encoder: 32채널
  ↓ MaxPool
Bottleneck: 64채널
  ↑ ConvTranspose + Skip Connection
Decoder: 32채널
  ↑ ConvTranspose + Skip Connection
Decoder: 16채널
  ↓
출력 1채널
```

각 블록은 `3×3 Conv → GroupNorm → SiLU`를 두 번 사용한다. GroupNorm은 배치 크기가 크지 않을 때도 BatchNorm보다 비교적 안정적으로 동작한다.

## 7. 손실 함수

전체 손실은 다음 세 항의 가중합이다.

```text
L = L_masked + 0.08 × L_context + 0.20 × L_gradient
```

- `L_masked`: 합성 손상 영역에서 예측값과 원본값의 Smooth L1 오차
- `L_context`: 손상되지 않은 주변 영역을 불필요하게 바꾸지 않도록 하는 오차
- `L_gradient`: 손상 경계에서 기울기가 끊기지 않도록 하는 연속성 오차

단순 픽셀 오차만 사용하면 메워진 부분이 지나치게 평평해질 수 있으므로, 표면 요철과 무늬 방향을 유지하기 위해 gradient 항을 추가했다.

## 11. 현재 방법의 한계

1. **실제 복원 정답이 없다.** 합성 결손 성능과 실제 문화유산 복원 타당성은 같은 개념이 아니다.
2. **손상 마스크가 규칙 기반이다.** 잘못된 마스크가 전체 복원 품질을 직접 좌우한다.
3. **합성 손상과 실제 손상의 차이가 있다.** 실제 마모, 박락, 균열, 스캔 누락의 분포가 현재 합성 마스크보다 복잡할 수 있다.
4. **원통형이라는 형상 가정이 있다.** 축이 기울거나 비대칭인 유물에서는 펼침 왜곡이 생긴다.
5. **고주파 세부 복원 중심이다.** 테두리나 몸체가 크게 사라진 결손은 별도의 전역 형상 모델이 필요하다.
6. **한 유물만 학습했다.** 다른 토기나 다른 스캔 환경에 대한 일반화 성능은 확인되지 않았다.
7. **STL에는 색과 재질이 없다.** VR 전시를 위해서는 OBJ 텍스처 및 노멀 맵 복원·정합 과정이 추가로 필요하다.
8. **불확실성을 표시하지 않는다.** AI가 확신하지 못하는 영역도 하나의 완성된 표면처럼 출력된다.

## 12. 다음 실험 제안

### 우선순위 1: 손상 마스크 개선

- 곡률, 법선 불연속, 메시 경계, 스캔 밀도, 텍스처 이상을 함께 사용한다.
- 사람이 소량의 손상 영역을 표시해 규칙 기반 마스크를 보정한다.
- 균열, 마모, 구멍, 스캔 누락을 서로 다른 손상 유형으로 분리한다.

### 우선순위 2: 합성 손상 현실화

- 실제 손상 마스크를 다른 온전 영역에 복사해 학습한다.
- 선형 균열뿐 아니라 박락, 넓은 결손, 가장자리 파손을 생성한다.
- 손상 크기별 성능을 따로 측정한다.

### 우선순위 3: 신뢰도와 복수 가설 표시

- dropout 또는 ensemble을 이용해 여러 복원 결과의 분산을 계산한다.
- 확실한 영역과 추정이 강한 영역을 색으로 구분한다.
- VR 전시에서는 원본, 보수적 복원, 적극적 복원을 단계별로 선택할 수 있게 한다.

### 우선순위 4: 텍스처 복원

- UV 맵을 유지한 채 RGB 텍스처와 normal map을 별도로 inpainting한다.
- 형상 복원 위치와 텍스처 복원 위치가 정확히 일치하는지 검증한다.
- 원본과 생성 영역을 메타데이터 또는 별도 마스크로 함께 보존한다.

## 13. 전문가에게 질문할 기술적 쟁점

### 반드시 먼저 확인할 질문

1. 이 유물에서 실제 손상과 제작 당시의 비대칭·요철을 구분하는 기준은 무엇인가?
2. 손상 영역을 자동 탐지한 마스크가 고고학적 관점에서 수정해야 할 부분을 포함하고 있는가?
3. 빗살무늬가 둘레 방향으로 반복된다고 가정해도 되는가? 위치별로 무늬의 의미나 제작 방식이 달라지는가?
4. 복원의 목표가 구조적 완성, 시각적 연속성, 제작 당시 원형 추정 중 어느 수준이어야 하는가?
5. 관람객에게 사실과 추정을 구분하기 위해 복원 영역을 어떤 방식으로 표시해야 하는가?

### 3D·컴퓨터 비전 전문가에게 물을 질문

1. 원통 좌표 2D U-Net 방식과 Point Cloud, Mesh GNN, 3D implicit/SDF 방식 중 이 데이터 규모에 더 적합한 방법은 무엇인가?
2. 현재 기하 기반 손상 탐지에 곡률, 법선, geodesic 거리, 메시 밀도를 어떻게 결합하는 것이 좋은가?
3. 2D 펼침 과정의 왜곡과 θ 경계 문제를 정량적으로 평가하는 방법은 무엇인가?
4. 실제 손상 분포와 유사한 합성 마스크를 만들기 위해 어떤 통계나 생성 모델을 사용해야 하는가?
5. 정답 없는 실제 영역을 평가할 때 사용할 수 있는 지표는 무엇인가? 예: 경계 연속성, 곡률 분포, 패턴 주기성, 전문가 블라인드 평가.
6. 동일한 입력에서 복수의 타당한 복원 가설과 불확실성을 생성·표현하려면 diffusion, ensemble, Bayesian 방식 중 무엇이 현실적인가?
7. 형상 복원 후 메시 두께, 자기 교차, manifold, watertight 조건을 손실 함수에 직접 넣을 필요가 있는가?
8. 스캔 노이즈와 실제 표면 요철을 구분하기 위한 전처리 강도는 어떻게 정해야 하는가?

### 문화유산·보존 전문가에게 물을 질문

1. AI 복원 결과가 학술적 복원으로 인정되기 위해 기록해야 할 근거와 메타데이터는 무엇인가?
2. 원본 스캔, 전처리 결과, 손상 마스크, AI 생성 영역, 수작업 수정 내역을 어떤 표준으로 보존해야 하는가?
3. 유사 시대·유형의 다른 토기를 참조 데이터로 사용할 때 허용 가능한 추정 범위는 어디까지인가?
4. 복원 결과를 전시할 때 ‘추정 복원’임을 관람객에게 전달하는 적절한 시각적 표현은 무엇인가?
5. 무늬의 방향·간격·깊이가 시대 또는 제작 집단을 판단하는 근거라면, AI가 이를 평균화하거나 새로 만드는 것이 해석을 훼손할 위험은 없는가?

## 14. 결론

이번 실험으로 정답 데이터가 없는 한 점의 토기에서도, 온전한 영역에 합성 결손을 만들어 U-Net을 자기지도 방식으로 학습하고 닫힌 STL 복원 결과를 생성할 수 있음을 확인했다. 다만 현재 검증값은 합성 손상 복원 성능이며 실제 역사적 원형의 정확도를 증명하지 않는다.

다음 단계의 핵심은 더 큰 U-Net을 만드는 것이 아니라 다음 세 가지다.

1. 실제 손상 위치를 더 정확하게 정의한다.
2. 문화유산 전문가의 근거와 평가를 복원 과정에 포함한다.
3. 하나의 확정 결과가 아니라 복원 영역과 불확실성을 함께 전시한다.
