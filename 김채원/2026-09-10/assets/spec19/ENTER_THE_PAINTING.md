- 대상: 김채원 (직접 작업) · UE **5.8.2** · Quest 2 (`D-44`)
- 자산: `assets/inwangjesaekdo/runtime/` 7개 (v0.10, 장면 24,116면 · 텍스처 2장)
- 날짜: 2026-09-10

---

## ⚠ 시작 전 (팀 규칙)

1. **`vr/testproj` 를 직접 열어 작업하지 않는다.** 로컬에 복사해 백업본에서 작업하고,
   완료된 것만 저장소에 반영한다 — 공세민 공지 2026-09-09
2. `L_Museum` 은 `.umap` = **`lockable`.** 액자·트리거를 놓는 순간 이 파일이 바뀌는데
   **Git이 병합하지 못한다.** 반드시 잠그고 한다.
   ```bash
   git lfs lock   vr/testproj/Content/XRFramework/Levels/L_Museum.umap
   git lfs unlock vr/testproj/Content/XRFramework/Levels/L_Museum.umap
   ```
   → **새 레벨 `L_Inwang` 을 만드는 건 새 파일이라 충돌 위험이 없다.** 그쪽부터 하면 안전하다.
3. `git lfs install` · `locksverify true` 가 안 켜져 있으면 에셋이 포인터 텍스트로 내려온다
4. **액자에 까는 원화 이미지는 소장기관 표기·이용조건 미확인이다.** 내부 테스트까지만.

## 1. 관람자가 설 자리 — 계산해 뒀다

액자를 통과한 뒤 **정선이 그렸다고 정합된 그 자리**에 세우면 된다.
`records/entry_point.json` 에 넣어 뒀고, 값은 이렇다.

| 항목 | 값 (에셋 로컬 좌표, meter) |
|---|---|
| 눈 위치 | **X = −1.0 · Y = −1175.0 · Z = 154.3** |
| 발밑 바닥 | Z = **152.7** (눈높이 1.6 m) |
| 바라보는 방향 | **+Y** |
| 위쪽 | +Z |
| 실제 방위 | 진북 기준 **288.93°** · 수평화각 45.0° |

- 좌표계는 `runtime/*.glb` 와 같다 (pivot = 바닥 중심). **부모 액터 스케일이 1.0일 때의 값이다.**
- UE는 cm이므로 임포트 배율 100을 걸었다면 **위 값에 100을 곱한다** → `(-100, -117500, 15430)`
- PlayerStart 는 발밑 기준으로 놓는다. VR 룸스케일이면 Pawn의 바닥이 Z=15270 (cm)

> **주의.** 발밑은 아직 평지다. 근경 0~200 m 기복이 4.6 m뿐이라 (수치지형도가 서촌 시가지를
> 평탄화해 둠) 바닥이 밋밋하게 느껴질 수 있다. 임시로 절차적 잔결(최대 1.15 m)을 얹어 뒀고,
> 나무 밑동 역산이 끝나면 지형 파일만 교체된다.

## 2. 레벨 구성

### 2-1. `L_Inwang` (새 레벨) — 먼저 이것부터

1. 빈 레벨 생성 → 빈 액터 `A_Inwang_Root` 하나
2. 그 아래에 GLB 7개를 자식으로 임포트·배치. **부모·자식 전부 위치 0, 스케일 1.0**
   (pivot이 전부 같은 바닥 중심이라 그냥 겹쳐 놓으면 정렬된다)
   - `terrain_jeong` · `trees` · `house` · `fog` · `inscription`
   - `terrain_real` — 토글용, **숨김**
   - `base` — **1:1 몰입에서는 숨겨도 된다** (디오라마 받침이라 눈에 안 들어옴).
     가장자리가 뚫려 보이면 켠다
3. PlayerStart 를 위 1장의 좌표에
4. **Directional Light 없음 / Sky 최소.** 색이 전부 원화 먹값이라 라이팅을 걸면 화풍이 깨진다

임포트 설정 (틀리면 전부 어긋난다):

| 항목 | 값 |
|---|---|
| Import Uniform Scale | **100** |
| Vertex Color | 임포트 켜기 |
| 노멀맵 텍스처 | **sRGB 해제** + Compression `Normalmap (DXT5, BC5)` |
| 머티리얼 | **Unlit** + Emissive |
| 운무만 | Blend Mode `Translucent` + Vertex Color **Alpha** |

> 임포트할 때 스케일·회전 보정을 손으로 넣어야 한다면 **자산 결함이다.**
> `MeshScale`·`MeshRollFix` 를 만지지 말고 김채원에게 알린다.

## 3. 전환 — 두 가지 중 고르기

### 안 ① 가장 단순 (오늘 이거)

```
Box Collision 의 OnComponentBeginOverlap
  → 화면 페이드 아웃 (Camera Fade, 0.4 초)
  → Delay 0.4
  → Open Level  (L_Inwang)
  → BeginPlay 에서 페이드 인
```

- 장점: 30분이면 된다. 메모리 안전
- 단점: 로딩 중 **검은 화면 수 초.** VR에서 길면 불쾌하다

### 안 ② 매끄러움 (권장, 오늘 시간 남으면)

**우리 장면이 24,116면 · 텍스처 2장뿐이라 미리 로드해 둘 수 있다.** 이게 강점이다.

```
L_Museum BeginPlay
  → Load Stream Level (L_Inwang, bMakeVisibleAfterLoad = false)   ← 미리 로드

액자 접근 (거리 2 m 이내)
  → 액자 머티리얼 Opacity 를 1 → 0 으로 (원화가 서서히 사라진다)

Box Collision Overlap
  → 페이드 0.2 초
  → Make Stream Level Visible + 박물관 레벨 숨김
  → Teleport 를 진입점으로
  → 페이드 인
```

- 로딩 끊김이 없다. "그림이 사라지며 그 안으로 들어간다"는 연출이 그대로 나온다
- 액자 뒤로 실제 3D 공간이 비쳐 보이게 하고 싶으면 SceneCapture2D 를 쓰지 말 것 —
  **씬을 두 번 그리는 거라 Quest 2 (XR2 Gen 1) 에서 비싸다.** 위 Opacity 방식이 훨씬 싸다

### 되돌아오기

진입점 뒤쪽(−Y 방향)에 같은 액자·트리거를 하나 더 놓고 역순으로.

## 4. VR로 확인할 때 볼 것

Quest Link → **VR Preview** → `stat fps`

1. **1:1 스케일이 맞나** — 사람 키 1.7 m 옆에서 **산으로 보이나**
   - 대조군: 기와집 본채 폭 22.3 m · 전경 나무 실물 높이 중앙값 4.9 m
2. **먼 산이 평평해 보이나** — 이게 B안의 최대 약점이다.
   양안시차는 10~30 m 밖에서 사실상 사라져서, 1 km 밖 능선은 **그림처럼 보일 수** 있다.
   그렇다면 디오라마(A안)를 테마관 쪽에 같이 두는 걸 고려한다
3. **프레임** — 24,116면 + Unlit 에서 몇 fps
4. **정점색** — 나무·집이 회색 덩어리면 임포트가 꺼진 것
5. **노멀맵** — 경사면에 잔굴곡이 보이나. 안 보이면 sRGB/압축 설정
6. **운무 알파**
7. **바닥** — 발밑이 유리처럼 매끈한가. 그렇다면 전경 지형 역산을 우선순위로 올린다

> **장면 전체 면 수 기준이 명세 20장에 아직 "미확정"** 이다. 24,116은 *유물 1점* 기준(≤30,000)이라
> 통과지만 장면 합계 기준이 없다. `stat fps` 잴 때 그 값을 같이 채워 D-29 에 올린다.
