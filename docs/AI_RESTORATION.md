# AI 형상·색·질감 복원

## 목표

단일 사진에서 만든 손상 상태 3D를 입력으로 받아 결손 형상을 추정하고, 관측한 영역과 AI가 만든 영역을 구분한 전시 자산을 생성합니다.

이 결과는 문화재의 역사적 정답을 보증하지 않습니다. 입력과 데이터에서 얻은 복원 가설이며, VR에서는 손상 상태와 함께 비교해 보여 줍니다.

## 현행 형상 복원 경로

```text
사진 1장
  └─ TRELLIS.2
       └─ 손상 GLB
            └─ 2,048점 부분 점군
                 └─ AdaPoinTr v3
                      └─ 회전 TTA 8회, 최대 65,536점
                           └─ 밀도·격자 필터
                                └─ 관측부 + AI 추정부 2노드 메시
```

현행 구현은 [`ai/3d-to-3d-shape/completion/`](../ai/3d-to-3d-shape/completion/)에 있습니다.

## 학습 데이터

같은 유물의 손상·완형 3D 쌍을 충분히 구할 수 없어 완형 3D에서 결손을 합성했습니다.

결손 패턴은 다음 여섯 가지입니다.

| 패턴 | 의미 |
| --- | --- |
| `none` | 결손이 없는 대조 입력 |
| `bottom` | 하부 결손 |
| `rim` | 구연부 결손 |
| `side` | 측면 결손 |
| `slant` | 비스듬한 깊은 절단 |
| `ragged` | 불규칙 경계 결손 |

발표 시점에는 완형 16개 × 패턴 6종 × 변형 20회로 1,920쌍을 만들었습니다. 최종 저장소에서는 별도 테스트 형상 3개를 추가해 총 19개 형상·2,280쌍을 관리합니다.

| 분할 | 형상 | 쌍 | 용도 |
| --- | ---: | ---: | --- |
| train | 14 | 1,680 | 가중치 학습 |
| validation | 2 | 240 | 에폭과 체크포인트 선택 |
| test | 3 | 360 | 최종 보고 |

분할은 쌍 단위가 아니라 완형 단위로 수행합니다.

## AdaPoinTr 추론

AdaPoinTr는 부분 점군 2,048개를 받아 8,192개의 완성 점을 예측합니다. 한 번의 추론은 결손부 전체를 덮기에 부족해, 입력을 축 둘레로 45도씩 회전하며 여덟 번 추론하고 결과를 원래 좌표계로 되돌립니다.

TTA 결과를 모두 사용하는 대신 다음 조건으로 필터링합니다.

- 기존 관측점 밀도가 높은 위치는 원본으로 판단합니다.
- 결손 후보 안의 예측점만 보충점으로 사용합니다.
- 너무 멀리 떨어진 구름과 넓은 가짜 챙을 제거합니다.
- 투창 구조는 문헌과 형상에서 얻은 n-fold 주기를 이용해 메시화 단계에서 보존합니다.

## 메시화와 provenance

점군 전체를 다시 표면화하면 원본 형상도 변합니다. BONDI는 `(높이, 각도) → 반지름` 격자에서 결손 칸만 채우고 다음 두 노드로 출력합니다.

| 노드 | 의미 |
| --- | --- |
| `region_observed` | 입력 메시에서 관측한 원본 면 |
| `region_ai` | AI 점과 기하 보완으로 새로 만든 면 |

주 복원 대상의 관측부 V=94,877 / F=149,150은 그대로 유지했습니다. 이 분리는 “어느 완형에서 왔는가”까지 설명하지는 못하지만, 적어도 어느 면이 추정인지 식별할 수 있게 합니다.

## 비교한 형상 복원 방법

| 경로 | 장점 | 한계 | 결론 |
| --- | --- | --- | --- |
| AdaPoinTr 점군 완성 | 회전대칭을 직접 가정하지 않고 깊은 결손을 학습 | 학습 데이터와 체크포인트에 민감 | 현행 |
| 회전대칭 + 이중조화 | 근거가 명확하고 원본만으로 재현 가능 | 비회전체에 적용하기 어려움 | 대조군·보완 |
| PCA 형상 사전 | 프로파일 대부분이 사라진 경우 참조군 활용 가능 | 대상 71489에는 살아 있는 프로파일이 충분 | 보류 |

## 색과 질감

[`ai/3d-to-3d-color/`](../ai/3d-to-3d-color/)은 형상 복원 전후의 텍스처를 다룹니다.

- 사진과 표면 텍셀의 CIE Lab 분포를 맞춥니다.
- 곡률과 주파수 대역으로 마모·균열·장식을 구분합니다.
- 살아 있는 건전 표면은 보호하고 손상 마스크 영역만 보정합니다.
- 자동 분리가 어려운 영역은 SAM 2 또는 UV 브러시 마스크로 지정합니다.
- 합성 부식을 이용해 원래 색을 아는 영역에서 복원 오차를 측정합니다.

## 현은빈의 구현 범위

- 완형 후보 선별과 합성 결손 쌍 생성
- AdaPoinTr ShapeNet-55 가중치 기반 파인튜닝
- 형상 단위 train/validation/test 분할
- 정규화 좌표 누출 발견과 평가 수정
- 결손부 커버리지 기반 체크포인트 선택
- 회전 TTA와 점군 필터링
- 2노드 메시화와 관측부 보존
- 회전대칭·형상 사전 대조 실험

초기 판단과 시행착오는 [Study 브랜치의 현은빈 기록](https://github.com/eunbin-hyun/BONDI/tree/Study/%ED%98%84%EC%9D%80%EB%B9%88)에 보존했습니다. 일부 초기 결론은 후속 실험에서 바뀌었으므로, 현재 동작은 [`ai/3d-to-3d-shape/README.md`](../ai/3d-to-3d-shape/README.md)와 [`completion/결과.md`](../ai/3d-to-3d-shape/completion/결과.md)를 기준으로 합니다.
