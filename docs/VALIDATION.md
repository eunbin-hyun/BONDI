# 평가 방법, 결과와 한계

## 문서 기준

최종 발표 자료와 `master`는 서로 다른 시점을 기록합니다.

- 발표 자료는 BONDI의 문제 정의, 사용자 경험, 발표 시점 성능을 설명합니다.
- `master`의 코드와 결과 문서는 발표 이후 수정된 데이터 분할, 누출 점검, v3 모델과 메시화 결과를 포함합니다.

따라서 발표 수치와 최종 수치를 같은 실험으로 섞지 않습니다.

## 발표 시점 결과

| 항목 | 결과 | 의미 |
| --- | --- | --- |
| 완형 데이터 | 16점 | TRELLIS.2로 준비한 학습용 완형 3D |
| 결손 패턴 | 6종 | none, bottom, rim, side, slant, ragged |
| 변형 | 패턴별 20회 | 회전과 표본 변형 |
| 학습 쌍 | 1,920쌍 | 16 × 6 × 20 |
| 사전학습 F-Score | 0.082 | 발표용 주 대상에서 확인한 초기 기준 |
| 1차 파인튜닝 F-Score | 0.082 | 단순 파인튜닝만으로 개선되지 않음 |
| 결손 후보 영역 커버리지 | 5.2% → 28.0% | 회전 TTA 적용 전후 |

여기서 커버리지는 예측 점이 놓인 결손 후보 격자의 비율입니다. 완성 형상의 전체 정확도를 뜻하지 않습니다.

## 최종 저장소 평가

최종 경로에서는 데이터를 원본 형상 단위로 나누고, 결손률 구간별 F순증을 보고합니다.

| 결손률 | ShapeNet-55 사전학습 | v1 | v2 | v3 |
| --- | ---: | ---: | ---: | ---: |
| 0.00–0.20 | 0.641 | **0.899** | 0.836 | 0.895 |
| 0.35–0.50 | 0.082 | 0.438 | 0.586 | **0.936** |
| 0.50–0.65 | 0.026 | 0.229 | 0.625 | **0.918** |

`F순증`은 결손부에서 얻은 재현율과 정밀도의 조화평균입니다. 원본 관측 영역을 다시 찍는 점은 개선으로 세지 않습니다.

## 평가 과정에서 수정한 문제

### 정규화 좌표 누출

부분 점군을 완형 좌표계로 정규화하면 모델이 입력의 크기에서 원래 완형 크기를 추정할 수 있었습니다. 같은 가중치에서 정규화만 바꾸자 커버리지 순증이 0.700에서 0.102로 감소했습니다. 최종 평가에서는 부분 입력만으로 정규화합니다.

### 체크포인트 선택 기준

Chamfer Distance가 계속 낮아져도 결손부를 잘 채우는 에폭은 따로 있었습니다. 최종 v3는 validation Chamfer Distance만 보지 않고 결손부 커버리지로 ep8을 선택했습니다.

### 무작위 점 대조군

재현율만 보면 넓게 점을 뿌리는 모델이 좋아 보일 수 있습니다. `side` 패턴에서 무작위 대조군은 재현율 순증 1.000을 얻었지만 정밀도는 0.042였습니다. 재현율과 정밀도를 함께 보고합니다.

## provenance 검사

최종 메시에서 관측부와 AI 추정부가 별도 노드인지 확인합니다.

- `region_observed`: 입력 메시의 관측 면
- `region_ai`: 결손부에 새로 만든 면
- 주 대상 관측부: V=94,877 / F=149,150 무수정

이 검사는 어느 면이 추정인지 알려 주지만, 학습 데이터의 어느 특정 유물에서 형상이 왔는지는 설명하지 못합니다.

## 색·질감 검증

정답 색을 알고 있는 건전 표면 일부에 합성 부식을 입힌 뒤 복원해 원래 색과 비교합니다. 사용 지표는 ΔE_ab, ΔE₀₀, 밝기 오차, 주파수 대역 세기, 건전부 교란입니다.

금동 표본에서는 ΔE_ab가 8.16에서 2.53으로 감소했습니다. 다만 합성 부식은 실제 부식의 층 두께, 광택, 재질 변형을 재현하지 못합니다.

## 검증 범위의 한계

- 완형 3D 일부가 TRELLIS.2 생성물이므로 학습 정답에도 추정이 포함됩니다.
- 동일 유물의 실제 손상·완형 GT 쌍이 부족합니다.
- 상류 경로 차이를 검증하려던 sim-to-real 실험은 표본 규모가 작아 중단했습니다.
- 회전대칭 메시화는 굽 바닥과 비회전체에 약합니다.
- TTA 후에도 직접 예측점이 없는 결손 격자가 남습니다.
- 문화재의 역사적 복원 타당성은 전문가가 별도로 검토해야 합니다.
