# 2026-09-04 학습 정리 — Blender→Unreal 이관, Unreal 자산 VR 대응, Claude MCP 연결, TRELLIS 2D→3D로 복원 전체 흐름 익히기

- 작성자: 김신정
- 관련 Jira 작업: 없음
- 학습 주제: 복원한 유물 자산을 Blender에서 Unreal로 옮기고, Unreal 자산을 VR 환경에 맞게 조정하는 과정. 그 과정에서 Claude MCP 연결을 시도. 별도로 TRELLIS 웹으로 유물 2D 사진을 3D로 변환해 보고 PPT로 전체 복원 파이프라인을 정리
- 대상: Blender 유물 메시 / Unreal Engine 5 / VR(PC 스트리밍) / Claude Code MCP / TRELLIS 웹 데모
- 목적: 팀 스터디·기록용. "복원 결과물이 어떤 단계를 거쳐 VR 안에 들어가는지" 전체 과정을 손으로 한 번 훑어보는 것

## 1. 진행한 것

### 1-1. Blender 파일을 Unreal로 옮기기

- Blender에서 복원 작업한 유물 메시를 Unreal Engine 5 프로젝트로 가져오는 흐름을 직접 해봤다.
- 확인한 포인트
  - 내보내기 포맷(FBX / glTF)과 스케일·축(Blender는 Z-up, Unreal은 다른 기준) 차이로 임포트 후 크기·방향이 어긋나는 부분을 맞춰야 했다.
  - 머티리얼은 그대로 넘어오지 않아서 Unreal 쪽에서 다시 연결해야 하는 부분이 있었다.
  - 메시 하나가 여러 오브젝트로 쪼개져 있을 때 임포트 후 정리가 필요했다.

### 1-2. Unreal 자산을 VR에 맞게 변경

- Unreal에 들어온 유물 자산을 VR에서 보기 위한 조정 작업을 해봤다.
- 확인한 포인트
  - VR은 프레임 예산이 빡빡해서 폴리곤 수·머티리얼·라이팅 설정이 데스크톱 기준 그대로면 무겁다는 점.
  - VR 미리보기(PC 스트리밍 경로)로 실제 헤드셋에서 스케일·배치가 자연스러운지 확인하는 흐름.
  - 유물이 사용자 기준 어느 위치·크기로 놓여야 "체험"으로 자연스러운지 감을 잡음.

### 1-3. Claude MCP 연결

- 위 작업을 자동화/보조하기 위해 Claude Code의 MCP 연결을 진행해봤다.
- 연결 자체와 에디터에 명령이 전달되는 흐름을 확인했다.
- 아직 실작업에 크게 활용한 단계는 아니고, 연결·기본 동작 확인 수준.

### 1-4. TRELLIS 웹으로 유물 2D → 3D 변환

- TRELLIS 웹 데모에 유물 2D 사진을 넣어 3D 모델로 변환해봤다.
- 사진 한 장에서 형상이 어느 정도까지 잡히는지, 뒷면·안쪽처럼 사진에 안 보이는 부분은 어떻게 채워지는지 눈으로 확인.
- 우리 파이프라인에서 2D→3D 단계가 어떤 결과물을 주는지 감을 잡는 용도로 사용.

### 1-5. PPT로 복원 전체 과정 정리

- 위 내용을 PPT로 정리하면서, 유물 복원 프로젝트의 전체 과정(2D 사진 → 3D 생성 → 복원 → Blender 작업 → Unreal 이관 → VR 대응 → 체험)을 한 번에 훑었다.
- 각 단계가 어디서 어디로 넘어가는지, 어떤 산출물이 다음 단계 입력이 되는지 연결 관계를 확인.

## 2. 배운 점

- 복원 결과물이 VR까지 도달하려면 "Blender에서 잘 만들었다"로 끝이 아니라, 포맷·스케일·머티리얼·경량화 등 이관 단계마다 손이 더 간다.
- VR 대응은 시각적 조정이 아니라 성능 예산 문제에 가깝다. 데스크톱에서 멀쩡하던 설정이 VR에서는 무겁다.
- TRELLIS 같은 단발 2D→3D는 보이는 면 위주로 형상을 만들기 때문에, 안 보이는 부분(그릇 안쪽 등)은 이후 복원 단계에서 처리해야 한다.
- PPT로 전체 흐름을 그려보니 각 직군 작업이 파이프라인 어디에 붙는지 명확해졌다.

## 3. 결론

이번은 실험이라기보다 전체 파이프라인을 손으로 한 번 통과시켜 본 학습이다. Blender→Unreal→VR로 이어지는 경로와 각 경계에서 필요한 작업(포맷·스케일·머티리얼·경량화)을 파악했고, Claude MCP 연결은 동작 확인까지, TRELLIS 2D→3D는 결과물 특성 확인까지 진행했다. PPT 정리로 전체 복원 과정의 단계 간 연결 관계를 정리했다.

## 4. 다음 행동

1. Blender→Unreal 이관을 반복 가능한 절차로 정리한다(내보내기 설정, 스케일/축 보정, 머티리얼 재연결 체크리스트).
2. VR 성능 예산 기준을 잡는다(유물 1개당 목표 폴리곤 수, 머티리얼/라이팅 설정).
3. Claude MCP를 실제 이관·정리 작업(임포트 후 오브젝트 정리, 트랜스폼 보정 등)에 붙여본다.
4. TRELLIS 결과물을 복원 단계(안쪽·뒷면 보완)로 넘기는 흐름을 이어서 테스트한다.
